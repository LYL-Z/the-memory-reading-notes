# Autobiographical evidence

Read root AGENTS and the quick card in editorial/creative-charter/OPERATING-RULES.md. Keep original evidence in the existing source/index; use templates/material-card.md as a chapter working view, not a duplicate database. Record the original grade as well as FACT_CONFIRMED, RECOLLECTION, LITERARY_RECONSTRUCTION or COUNTERFACTUAL. Ordinary L1 daily scenes can be drafted without prior line-by-line approval. Where memory is incomplete, choose an appropriate uncertainty or reconstruction. Distinguish the narrator's inference from a real person's confirmed inner state; do not manufacture real evidence. Source vault is read-only. Actual third-person privacy and publication conditions remain separate from the narrator's authorization. For sensitive material use only authorized storage. Consult the detailed evidence and rights sections when needed.
