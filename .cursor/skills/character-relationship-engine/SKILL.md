# Character relationship engine

The only tier file is `editorial/character_tiers.md`.

Ranks, already fixed: protagonist; three core people (赵问竹, 父亲, 母亲); classmates with an arc; one-scene classmates; teachers; family fragments; roster names with no biography.

## When a person changes

1. Find the person page and the questionnaire line that supports the change.
2. Edit `character_tiers.md` only. If a Story Skills `characters/` file exists later, regenerate it from this file. Do not edit it by hand.
3. A thick chat log does not raise 董佳好 to core. A thin roster line does not get a personality.
4. Real names already in the vault stay. Do not invent a second naming scheme in another tool.
5. 李顺贤 is a woman. Do not copy the old function card's pronoun.

## Relationship stage

Record start, approach, conflict, gap, and what is still unknown. Unknown is a state, not a blank to fill.
