# Continuity and release

Use the version/engineering section of editorial/creative-charter/OPERATING-RULES.md and current README. Canonical manuscript is manuscript/volume-01..06 and later authorized volumes; work/final and past branch ledgers are not a parallel canon. Review dates, ages, spaces, character knowledge and world causality at suitable precision. Repeated passages need actual reading value, not automatic cutting. Run scripts/hanzi_count.py on changed chapters; update the current manifest and progress files when changing canon, and run scripts/verify_six_volume_integrated.py for the six-volume canon. Independent candidate branches, scoped PR and read-back; do not combine unrelated drafts. No export of private indexes or restricted raw material. Rights review and actual literary cold reading are separate from mechanical checks. Do not install plugins or repair the read-only original vault.
