## 2. 知情与证据分层：至少四套并行术语

### 2.1 五层法（R50 正典，推荐作为报告口径）

`editorial/volume01-final-canon-and-volume02-handoff-2026-11-04.md:46-52`：

- **Record**：照片、评价、书信、原始消息或有出处的记录，记录仍有盲区；
- **Recall**：作者现时如何记得，时间顺序和细节不强行填满；
- **Telling**：主人公在具体时间实际上对谁讲了哪一部分、刻意没讲什么；
- **Witness**：旁人实际亲眼／亲耳知晓，不把被提及等同于知情；
- **Reader belief**：读者第一次读时推测什么、见到后文真实信息时为何改变看法、哪些仍应未知。

### 2.2 五时间层（七部架构）

`editorial/longform-architecture/2026-11-07-six-plus-one-author-realignment.md:45-53`：`T_event`／`T_recall`／`T_telling`／`T_reader`／`W_world`（`REAL/RECONSTRUCTED/COUNTERFACTUAL/DREAM/FUTURE_PROJECTION`）。`W_world` 是第七部反事实分支的合法性开关："第七部梦或假设不得进入现实人物页。"

### 2.3 六栏来源标签（写作现场用）

`2026-11-08-author-voice-anti-template-and-evidence-protocol.md:30`：每个候选场景记六栏——"**人物／行动／事件时钟／来源及记录时间／置信度与冲突／读者此刻应知道什么**"，并区分 `AUTHOR_DIRECT`、`AUTHOR_RECALL`、`DOCUMENT`、`THIRD_PARTY_ACCOUNT`、`COMPOSITE`、`UNKNOWN`。

### 2.4 委托人口述精度词典（访谈台账口径）

`editorial/author-interviews/2026-11-07-author-first-answers-and-evidence-ledger.md:5`：`AUTHOR_DIRECT`（亲身行动或直接听到）／`AUTHOR_RECALL`（2026 年回忆，可能不精确）／`AUTHOR_INTERPRETATION`（本人对意义／动机的回望）／`DOCUMENT_INDEX`／`EDITORIAL_OPTION`／`UNKNOWN`／`PRIVACY_REVIEW`。同页明写"作者准许文学化创作不等于允许AI替其他真人立言"。

> 报告 02 若不统一口径，会出现"R42 说 C/E 层、B2 说六栏、playbook 说 E"三套字母并存的混乱。建议统一转写为五层法＋`UNKNOWN`。

## 3. 不可靠叙述：机制而非声明

`editorial/volume01-round49-kimi-structural-issues.md:18-23` 给出四条可核机制：

1. **自我有利转述**："007只讲做对、015想演好赞美、003想把'当代白居易'讲成称号，都是具体选择，不靠'我记忆不可靠'的免责声明。"
2. **不同听闻**："曾子沣只知历史课被提起，不知内容"。
3. **媒介边界**："011原纸可复读但不能证明爱情；017喻／伍／赵各见不同纸版，录像不能证明纸内容"。
4. **成年偏见**：002 他想只留催促与索取，旧信与母亲评价却显示感谢与幽默。

同文件 :23 的结论是硬约束："**现稿已通过证据相抵触实现不可靠叙述，不能为了强化主题再补一个全知讲述者。**"

## 4. 反模板：八种结构性 AI 感（不是词表）

`2026-11-08-author-voice-anti-template-and-evidence-protocol.md:49-58` 的高风险模式表，八行摘要：

| 模式 | 处理单位 |
|---|---|
| 每段先写主题判断，再配一个例子 | "删主题句，保有推动行为的物件／因果" |
| "不是……而是……"、三连排比连续出现 | 若无新区别就改动作或删 |
| "我现在明白……" 紧跟人物行动 | 留行动，回望移到更远处 |
| 自称"写到这里""读者会认为"或报告章节流程 | 非有意元叙事则删 |
| 每个真实人物被解释"也有独立人生" | 多写其已证在做的事 |
| 先为一场无证戏写免责声明，再重复 | 正文一次自然不确定即可 |
| 句子处处工整、结尾升华、比喻齐整 | 保留不整齐的真实记忆 |
| 跨章重拍同一事件却无新增知情 | 答不上"读者新知道什么"则删或移后 |

反例同样写在 :60："成语、长句、排比、象征、哲学性回望、幽默自夸均可以是作者真正的声口"，**严禁故意让人物"说糙一点"来模拟真人**。

## 5. 三种声部

`protocol.md:14-22`：**童年行动声**（偏手、纸、玩具、饭菜）；**高中当时声**（熟人面前强势、逞强，会做题也会偷懒）；**十九岁回望声**（"可以说'我现在仍觉得那时有一部分想法有道理'，也可以承认不知道…"）。三者"允许混叠、错位、突兀中断"，不要求每章各出现一次，也不在结尾收成三段论。

## 6. 五个工位与十维度

- 五阶段（`protocol.md:64`）：`SOURCE_CHECK → SCENE_CONSTRUCTION → DISTINCT_EDITORIAL_PASS → FACT_CONTINUITY_AUDIT → AUTHOR_REVIEW`。
- 十维度（`protocol.md:76`）："①真实性与事件逻辑、②人物共情、③对话、④情节推进、⑤环境动作、⑥语言韵律、⑦思想原创、⑧视角结构、⑨情绪节制、⑩全卷整体性"，并要求"每维不自我打高分，给**对应原句位置、保留/删除/补证决定和改后影响**"。

## 8. 章节必要性与字数：两条必须分开结算

`playbook.md:208-210` 标题即结论："**章节与字数必须分别结算**"——"总量合规不能证明节奏更好，删字也不能自动证明成熟。"

配套：

- 每章必要性问句（`playbook.md:155`）："返回一件事，必须多出新材料、关系位置或当前欲望。"
- 三钟填表（`playbook.md:153`）："每个后见材料分别填：事情发生何时；刘当时／后来何时知道；读者首次何时知道。"

- 第二部无此合约；R7 净删 6,192 汉字并如实报"不通过作者篇幅目标"（`editorial/volume02/reviews/2026-11-11-ch01-18-r7-final-author-side-literary-pass.md:9,30`）。

## 9. 事实优先与有界推演（作者层原文，优先级最高）

- `AGENTS.md:9`："不得为了降低AI感而捏造未确证的人物台词、具体分数、旅途行程或隐藏第三人的原话。**证据层级、未见原件和合成场面详细记录在editorial中，读者正文无需反复悬挂创作免责声明。**"
- `AGENTS.md:5`：未满 18 岁不写露骨性描写；"别人没确认的内心、原话和关系名称，仍不能写成已证实事实。"
- 推演三条件（引自 `hy4-ch15-ch16-final-review-and-verdict.md:13` 转引源库 `项目管理/用户订正-2026-09-11-事实优先与有界推演.md:19/:21/:40`）：可以合理推演补充；"推演不得回写成已证记忆"；禁"新事件、新人物、新日期、新关系结论"。

## 10. 三个"不要"

1. **不要把审稿报告当事实**：所有 report 都自称"不是作者的回忆，不是第三方当事人的证词"（`volume01-round50-…audit.md:3`）。
2. **不要把机器 PASS 当文学通过**：`volume01-round50-…audit.md:63` "自动化机器PASS不证明'文学最佳'"。
3. **不要接管作者记忆**：`2026-11-12-ch20-ch24-…audit.md:76` "正式出版前若作者指出不符合，应改掉，不因'文学合理'与他争夺亲历。"
