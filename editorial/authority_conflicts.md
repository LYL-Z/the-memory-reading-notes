# 两份任务书冲突时怎么执行

2026-10-31 同时给了三份文件。按终极任务书第 15 节：安全和来源隔离以终极任务书为准。图片里的「先做阶段 0」和启动指令里的「先盘点、先不要写正文」是同一件事。

| 议题 | 执行 |
|---|---|
| 先写备忘录还是先写正文 | 先盘点。本轮交付的是报告和种子，不是章节 |
| 读者正文里的推测标记 | 新工程不印。账本保留。旧的 `百万长文写作/` 仍按 9 月 11 日订正，本轮没去改它 |
| 旧六部和 1–60 章 | 不续写，不改写，不换词充新作 |
| 书名 | 工作书名暂用《刘佑林的19年回忆录》 |
| 100 万字与 84 万字 | 都不当作配额。材料密度决定篇幅 |
| 材料授权 | 2026-10-31 委托人第二次拍板：所有内容都可以使用，所有内容都可以写。母亲「家里的事尽量不写」、刘拓「不写工作吐槽」、宋俊豪「别写情感」、曾子沣「上大学前尽量少写」、朱学良「情爱不写」、高泽聪「不写糗事」、王麒睿要求化名、刘弈帆「其他人保留神秘」、杨铨的收入／现单位／自媒体禁写，都改由这一拍板覆盖。历史问卷原句仍留在人物页，书稿不再逐条停问 |
| 18+ | 未满 18 岁：不写露骨性描写；吸引、误会、羞耻、克制和后果可以写。年满 18 岁以后的场景，按委托人授权使用全部材料。露骨的性行为描写仍不写到场中人年满 21 岁之前 |
| 私密层 | 可以读，也可以进入书稿。证件号、手机号、精确门牌仍不抄进正文，因为没有叙事功能 |
| 「你就是我」 | 叙述可以用第一人称。不能因此把母亲、同学和前任没有确认的行为写成事实 |

网页版或另一份模型事先写好的构思，要等本书自己的三案冻结之后才允许对照。现在还没有三案，所以那一步未到。
