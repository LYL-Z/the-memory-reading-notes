## 证据底稿与核对

直接取材于只读个人回忆 `the-memory/高中/素材/个人回忆/刘佑林关于赵问竹的高中回忆-2026-08-12.md`、现有 `003.md`—`008.md`、`outline/volume-01.md`、`editorial/clocks.md`。

**作者一手记忆可确认**：

1. 高一的某约两周，两人座位在讲台左右一带；课间在讲台前侧及桌面用粉笔涂写。此段约两周与 `008.md` 真正同桌的两周**不能证实是同一时间**。
2. 两人曾在桌上写各自向往的大学并互猜。赵问竹明确而坚定地写 **浙江大学**；刘佑林写 **中国人民大学**、**中国政法大学**，当时虽有政治、历史兴趣与抱负，却没有唯一确定的理想大学。
3. 赵是班长，做事认真负责，也热爱聊天、玩笑与凑趣；喻翰东幽默随和、伍筱丹表达直接。刘喜欢把与赵相处的小事告诉525室友，男寝八人姓名见003及已核时钟。

**公共知识辅助**：官方校方信息可核实浙江大学及杭州、中国人民大学与中国政法大学在北京等基本地理与学科信息，可参照 [浙江大学](https://www.zju.edu.cn/)、[中国人民大学](https://www.ruc.edu.cn/)、[中国政法大学](https://www.cupl.edu.cn/)。正文没有植入当时学生未必掌握的近年院系、分数线、政策或校史，也不假设赵选择浙大的具体原因。

**仅属文学复合/重建，不得反写为确定史实**：数学作业数错本子、粉笔断裂、遮挡猜校名的具体对白、各人当日插话、五二五室友逐字调侃、学校次日擦去桌面字迹、赵核对题目与班务、第二次涂到半个字的短场面、衣物与器物的无害动作。它们将作者口述的持续相处习惯组织为文学情景，不精确确定某日发生。关于她为何选择浙大、是否有恋爱回应，仍**没有证据**，正文不代替她陈述内心。

## 构思约束与三轮检查

- **第一轮：构思**。以“粉笔可擦、志向难忘”为结构起点；主场景是讲台两边互猜大学；回声是夜晚525讲述和次日桌面擦除。第八章真正同桌的桌缝与本章讲台左右作为空间变奏，但不强置两段两周的时间顺序。
- **第二轮：成文后审校**。加长刘赵之间并非重大事件的小小往来，给赵班务、读题、与伍聊天、决定自己要去哪里等不依赖男主人公的活动；寝室各人有作业、洗漱与各自话题，避免旁人仅成起哄背景。
- **第三轮：语言与连续性审校**。移去若干“不是……而是……”的总结式结构，改为粉笔屑、纸张、缺一本作业、老师拿回讲台等行动；不把 `010《那个零》` 的原话、后续烟花、《婚礼进行曲》与历史课告白抢写入009；不把“她写一校、他写两校”升格为对二人最终命运的可靠预言。时间采用“那阵子”“后来”等人物记忆单位，非历史编年表。

## 十问审稿（严格标准）

| 问题 | 观察与本次处理 |
| --- | --- |
| 1. 语言是否达到巨匠水准 | 不做无法验证的自封。以“粉笔写到‘政’字断成两截”“讲台被老师收回”为可见动作承重；仍可在整卷编辑时进一步削减自我评判句。 |
| 2. 是否让读者共情 | 她只写一所大学，他写两所却犹豫；白天话接不上，回525却讲个不停。尴尬和少年心气有明确场景。 |
| 3. 是否有原创可记句 | “宿舍没有因为我的理想停下来等我”“第二天，那四个字就没有了。她的笔却始终没有停。”均从物与事生出，正文不堆引语或格言。 |
| 4. 是否可获得经验 | 人选择远方并不等于已完成今天的题；他人愿望不因亲密就成为叙述者的所有物。由事件呈现，不直接训诫。 |
| 5. 人物/环境是否细致 | 粉笔灰、讲台的使用权、正反面、班务本子、宿舍洗手台/练习册，地点有工作机理而非布景。 |
| 6. 语言动作情感是否具体 | 让赵以伸手挡字、明确回复、核对作业、因班务中止谈话形成反复可辨的个人习惯；寝室对白均按性格作低风险重建。 |
| 7. 铺垫是否有效 | 一校/两校的差异、前几章座位形态、共同话题，接下一章讲台文字有物理连续性，**不提前揭露“0”**。 |
| 8. 手法能否沉浸 | 白天讲台→夜晚525→次日清空的物象回环；教室群像与第一人称回忆交替，而非单调恋爱独白。 |
| 9. 事实查验与延展 | 核原作者口述、前章、时钟与大学地理；区分可证事件/文学复合，保留他人心理不可知。 |
| 10. 整体设计 | 第一部走向高一下历史课与笑声，不提未来生日、大学再见、之后未添加联系方式。009只完成“理想大学与少年志向”场面。 |
