# 第二十轮：《那个零》构思、创作与文学审稿

日期：2026-11-01

目标文件：`manuscript/volume-01/010.md`

阶段裁决：**完成正文，阶段性通过，仍未文学冻结**。本次以现有一手口述为界限，进行构思、写作、逐场景连读、语言精修和十项文学审核；“通过”不等于宣称世界文学巨匠水准。

## 先确认，不猜测

1. **有证事实**：高一的一次晚自习，赵问竹在讲台前侧写过“刘佑林是‘0’”；刘佑林当时不理解、向她和在讲台附近当值日班长的舒思宇追问。这是作者本人多次口述，也见只读知识库 `高中/素材/个人回忆/刘佑林关于赵问竹的高中回忆-2026-08-12.md`。
2. **有证背景**：赵是班长，做事认真、也爱听热闹和开玩笑；刘在熟人面前健谈，尤其喜欢与525男寝室友分享两人间的小事；舒思宇是525室友，后来作者明确称“竹席”是舒最早叫出的外号；“主席”此前已被同学使用。男寝与女寝相邻但**不在同一栋**。
3. **没有证据**：`0` 究竟是什么意思，赵当晚逐字答复过什么，舒是否真正懂、零是否引申了任何性暗示或身份判断、字写在理想大学涂画的前/后哪一夜、字何时由谁擦去，都不明。正文**不定义任何网络俚语、不推断赵的恋爱意向**，也不让旁人代她给出标准答案。
4. **文学重建**：晚自习光线/课业声、舒当值时具体互动、赵当时神态和回应的概括、其他同学向班长问题、走廊返寝路线、525众人听故事与逐字对白、后来一次普通课间借题闲聊及日常细节，均是将口述里反复出现的性格与场景组织成小说。不能倒写成当事人的确切录音、同时段日记或可外传的独立事实。
5. **材料关系**：第009章的大学粉笔字与本章“0”共用讲台，但不能强定同一日历两周，更不写为“紧接第二天”。第011章竞赛班训练、高一末退出不抢写；第012—014章烟花和《婚礼进行曲》、第018—020章历史课仍各留独立故事空间。

## 三轮文学工作记录

- **构思轮**：把`0`当作“一个知道笔画却不知道意思的字”，从讲台上的署名写到当事人追问，再进入被室友重新讲述的525夜晚，最终回到少年人面对不确定性时的感受。核心是“同一个名字在不同人手中被写、被听、被议论”，契合《时间的复数人称》而不把零强行立成宇宙隐喻。
- **成文轮**：刻意让舒思宇既当值又有作业、室友各有自己的事，避免所有角色成为恋爱起哄机器；赵除了玩笑还有学习、班务、朋友圈及独立的目标。保留“问了而没问明白”的真实结果。
- **语言轮**：连读第009章结尾，拒绝接续成“写完大学—第二天写零”的虚构时间线；多处把“她是怎样的人”“我后来才理解”删改为书、本、粉笔、翻页、收拾等动作；删除“作者为了让小说圆满而给零下定义”的审稿式话语，结尾仍停在当时的疑惑。

## 十项审稿

| 维度 | 判断与证据 |
| --- | --- |
| 1. 语言 | 保留口头语的羞赧、熟人间的互呛；避用宏大时间箴言。仍要在全卷连读时监测“后来、那个零、不知道”的密度。 |
| 2. 共情 | 会做题却听不懂同伴玩笑、明明想被问又说“没什么”、在教室窘迫而回宿舍健谈，均有明确动作和语境。 |
| 3. 原创句子 | “偏偏她写出来，我便觉得字像是从我身上借出去了一会儿。”“它把一个本来平常的晚上弄得很长。”从具体事件生出。 |
| 4. 知识/经验 | 不误以为对方的一个玩笑就等于她确认的感情；无法确证的语言允许留白，尊重记忆的限度。不是性别/俚语知识科普。 |
| 5. 环境 | 灯下写字、班务打断、值日班长前台、寝室交谈与课业穿插，空间各有工作逻辑。 |
| 6. 人物动作与对白 | 赵可以逗人、转身解决正事；舒既逗趣也处理值日；众多室友不会围成单一反应的合唱队。具体台词是文学重建。 |
| 7. 伏笔/结构 | 上接第009的讲台和粉笔，下接后来更多校园玩笑；“0”不被先验解释也不被用于证实日后流言。 |
| 8. 表现手法 | 晚自习场景、班务打断、走廊、群寝短对白及几年后回望交错；“同名不同叙述”的复数人称动机扎根在故事中。 |
| 9. 事实核对 | 使用作者口述、原只读仓库摘要、009正稿、卷一目录与时钟；拒绝为取得猎奇效果调用未经证实的“0”网络释义。 |
| 10. 全书一致性 | 第一部仍止于历史课四个人的笑；不提前写赵未来感情、网传事件或大学后结局，不扭曲男女寝室空间。 |

## 下一轮风险

一个极短真实事件展开成较长章节，有“过度回旋同一问句”的风险。此轮把多次追问处理为少年不甘心与笑场，不把每段都解释为重大命运寓意；将来全卷节奏审稿时需与009连读，调整重复而保留明确的生活场面。**没有证据确认“零”的语义，就不应在之后章节为戏剧效果倒填意义。**

本章为文学作品，正文中的人物心理只代表第一人称叙述者的观察、疑惑与回望；任何第三方内心独白未被标为事实。
