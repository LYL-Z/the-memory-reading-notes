## 一、事实与外部史料

**直接个人回忆**（`LYL-Z/the-memory`只读库：`高中/素材/个人回忆/刘佑林关于赵问竹的高中回忆-2026-08-12.md`，并见作者对话口述）：

1. 高一下某次**月考前晚自习课间**，从G2204教室窗外看到橘子洲方向的烟花，作者记得视野很好，许多同学（近乎全班）到窗边观看。
2. 赵问竹当时站在一位**好朋友的右后方**；刘佑林悄悄走到赵的后方，欣赏烟花和她的背影、短发、笑容。**不能把“好朋友”擅自指认为伍筱丹**。
3. 同一晚**随后**吴明博与一些男生起哄、关灯、用一体机播放《婚礼进行曲》，主人公借故出门，之后赵似乎脸红和沉默只是他的观察。**本章012只写到起哄将要开始前**，不将013的音乐、灯光转折与主人公离场提前写完。
4. 主人公记得赵喜欢烟花、热闹和新奇，是他观察的性格倾向；不能推定她察觉主人公站在背后、故意等他、与他确立或回应恋爱关系。

**外部事实候选**：长沙当地媒体报道**2023-05-11晚**橘子洲有一次约20分钟的焰火晚会，之前2023年元宵和五一宣布不燃放。参见 [长沙晚报2023-05-11现场报道](https://www.icswb.com/h/160/20230511/813556.html)、[红网2023-05-12报道](https://hn.rednet.cn/content/646749/56/12644896.html)、[2023年元宵节官方公告转引](https://cs.rednet.cn/content/646745/63/12269300.html)。**该晚是可能的史实匹配，不是已确证的G2204教室当晚；没有学校考试表、同学日记或影像来锁定日期**。正文因此未使用“2023年5月11日”、活动正式主题、乐曲节目、具体燃放分钟数。也未将后来的各类烟花场次混为当晚。

## 二、三轮叙事审校

- **构思轮**：在同一晚里分两章，以012《橘子洲》处理整个班级被烟花从月考复习中叫出、赵与闺蜜的独立反应、刘站在她后方；013《婚礼进行曲》再处理吴明博带头起哄、关灯音乐、逃离与铃声。013不应回头重复012半章风景描写。
- **成文轮**：以窗光/玻璃反射/声音迟到（光声传播）和拥挤的班级空间承担情绪；补赵与女生讨论题目、伍直接让位置、喻在窗边争视野、未立刻起身的同学等**小说化低风险场景**，让群像不成为恋爱观众席。
- **精修轮**：去掉数处“不是……而是……”和自我解释，保留具体站位**赵在朋友右后、刘在赵后**；不把她回望、脸红、情感承诺写在012；不凭教室位置硬写看到了湘江江面或学校楼层方向。结尾那阵不明原因的笑声仅作为十三章钩子，**不声称已听见《婚礼进行曲》**。

## 三、文学复合范围

具体晚自习试卷、小组补题、赵与未具名朋友讨论遗漏条件、喻与伍和其他同学窗边即时对白、椅脚和水杯的动作、每一束烟花的颜色与散开方式、窗玻璃倒影、主人公在人群中如何逐步绕位、当场有人数烟花次数、最后一阵笑声的发出方式等，均是在作者确认的空间/时间骨架上组织的文学情景，**不等于现场录像或逐字记录**。读者见到的是自传体小说，不是能逐句核验的新闻纪实。

## 四、十问审稿

| 标准 | 观察及问题 |
| --- | --- |
| 1. 语言 | 以灯光、椅脚、玻璃倒影、两人位置传递微情绪；避免频繁用“我后来才明白”点评。下一次整体审校需继续监测“烟花/她/我”的密度。 |
| 2. 共情 | 所有人看烟花，他因喜欢一个人而不知如何站、如何开口；少年的自在与羞怯有行为证据。 |
| 3. 可记句子 | “那时，我还以为自己只是人群里一个不起眼的背影。”既忠于第一人称记忆，也为013的集体起哄埋下转向。 |
| 4. 知识/经验 | 光与声音到达时间不同的基础物理在远景中自然呈现；月考、疫情后重新共处的校园背景具历史生活感。 |
| 5. 人物环境 | 教室纸张与灯光、窗玻璃多重反射、学校课间人流和城市焰火互相作用，不用抽象春心独白替代。 |
| 6. 情感动作 | 赵同朋友看烟花、笑、抬头、侧身；刘调整距离但不触碰，无法知道赵有没有察觉。陌生女生不被强加身份和恋爱动机。 |
| 7. 伏笔 | 最后人群笑声朝一个新方向聚集；013吴明博起哄/灯灭/音乐须直接衔接，保持同晚次序。 |
| 8. 手法 | 一个课间事件展开为月考前教室→第一束光→全班窗边→局部站位→城市与倒影→戏剧性悬停。节奏暂缓高潮而非拖写后果。 |
| 9. 材料核对 | 从源回忆、卷一时钟、009–011正文及2023长沙公开烟花报道交叉验证，不将候选日期硬化为小说日历。 |
| 10. 全书方案 | 高一赵为核心，仍保留她与朋友、学业的独立性；第一部继续走向历史课，同晚分章不无限细分。 |

**阶段结论**：第十二章完整且承接十三章的事件入口，阶段放行但**尚未整卷文学冻结**。十三章将是这同一晚的戏剧转折，勿另将“她那晚的脸”拆成第三个重复场面；原目录014的条目在后续可并入013处理。
