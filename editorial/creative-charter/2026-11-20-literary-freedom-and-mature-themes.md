# 《时间的复数人称》现行创作宪章｜文学自由、成熟题材与审稿裁量

2026-11-20｜适用于后续Ⅰ—Ⅷ卷创作、审稿和精修。与根AGENTS.md共同执行，取代旧文件中不适用于现行小说体裁的绝对化文学限制；不改变历史证据、已确认事实、权利约束、版本安全或平台规则。不是正文，不是出版授权。

## 一、体裁及原则

这是一部长篇自传体小说，不是口述史报告、证词或论文。Ⅰ—Ⅶ以真实事件及回忆为骨架，日常场景在人物逻辑自洽时允许虚构对白、动作、时间压缩、空间重建、合成相似场面及合理感官补足。Ⅷ为反事实补充层，允许不同结果、愿望完成、梦与未来、虚构世界及完整生活轨迹，不限定必须小心翼翼留白。真实事实与艺术重构在后台区分，正文不反复标注。源仓只读。

## 二、文学自由不是单一审美

| 不再设为硬规则 | 现行替代 |
|---|---|
| 一切以克制为荣 | 克制、热烈、激烈、幽默、开放、直接都可随人物和情境变化 |
| 只许留白或证词；重构段落必标 | 普通生活直接写成场景，后台记录层级；读者按体裁与世界锚点识别 |
| 只能用物件、动作隐喻 | 允许直接表达、独白、议论、长对话；物件是可选技法 |
| 不能写没有逐字回忆的普通对白 | 作者授权范围内可合理重构，不伪称一手引文或历史证词 |
| 每章必须有人生教训或成长 | 圆满、失败、悬而未决、普通日常均可独立成立 |
| 所有故事必须写对称代价 | 爽感可以来自真正成功、相爱、成家、朋友承认、事业兑现；不强迫惩罚 |
| 每处都要精确日期、每章都要倒叙 | 时间精度由文学需要决定，整体三钟明确；顺叙同样有效 |
| 只用字数、禁词、检测工具判断质量 | 以人物声口、现场、叙事容量、连续阅读、实际修改前后比较为核心 |

## 三、18+的成熟题材

本书面向成熟读者，不要因“成人题材”四字就回避正常内容。年满18岁的人物可有成年恋爱、身体意识、非露骨亲近、对欲望和羞耻的直接表达、关系矛盾、婚姻、生育选择、性健康的非色情讨论、疾病、衰老、家庭责任、职业与道德困境。旧21岁口径不再作为这些成年题材的门槛。文学表现不必把一切化作含蓄的比喻或反复告诫，不以露骨描写作为增益指标。

未成年人物不性化，正常的成长、青春期困惑、好感与年龄适当的浪漫可以写。涉及真实可识别人物时不创作色情化场景、不捏造其性史或其他重大私密事实；虚构成年人物不应是现实同学改名后的一比一替身。自主选择明确，不能把沉默、醉酒与身体反应认定为同意。18+是题材与读者定位，不是无限制许可。

## 四、事实、人物及视角

- FACT_CONFIRMED：已确认的现实事件；纠错须有真实依据，不由编辑想象替换。
- RECOLLECTION：主角有权误记、误解、自我辩护、保留情绪；不必让叙述者在每句都自证。
- LITERARY_RECONSTRUCTION：允许低风险的日常场景扩写，包括合乎情境的对白、环境和心理联想。区分第一人称的推测与对他人私密内心的事实断言。
- COUNTERFACTUAL：第八部内部可以出现不同结果与独立虚构人物的内心；同一世界人物、因果和可知信息一致，不反推现实中谁喜欢谁。世界类别以卷首框架及可重读的叙事线索辨识。

## 五、稿件工作与发表是不同阶段

构思与成稿默认在已授权范围执行，不逐句停问。对重大现实结果、第三方重大私密内容、真实人物授权冲突和作者待定的世界结局做明确记录，不把疑虑泛化到低风险的相邻场景。对可正常创作部分继续成稿，出现局部问题就做局部调整，而非缩成梗概。公开仓库即有传播风险，真人权利审查与实际授权不能用文学自由跳过。保留历史裁决原文与审稿证据，不改旧报告以制造新结论。

## 六、每轮实修的验收

读目标章及相关前后章、原始材料与当前授权；给出完整可用的段落/章稿，指出具体新增事件、关系进展、人物声口与实际差异；检查重复、时空、世界归属、事实与权利风险。审稿可保留作者原有尖锐观点和真诚圆满，不负责替每人辩护。普通场景与篇章不强制附加新证据，不过高风险内容必须有相应依据。量化账只辅助，不作文学认证。旧文件及适用范围见[跨仓效力清单](2026-11-20-policy-crosswalk.md)。
