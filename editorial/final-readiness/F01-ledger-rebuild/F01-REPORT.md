## 0. 核心发现（先看这一条）

> **③部分阅读 = 0。历史上不存在「抽样冒充全文」。覆盖率虚高 100% 来自分母，不来自分子。**

证明链条（可逐条复算）：

1. 833 条事件里，812 条路径可解析（833 − 20 条版本内路径 − 1 条影子树）。
2. 其中 **697 条带行数口径**：声明末行 − 实际末行 的差值只有两种——`0`（687 条）与 `−1`（10 条，末行空行）。**没有一条为正**；正数才是"少读"。
3. 另有 **721 条带字数口径**（含前者的部分与 7 条第七部记录），最大汉字漂移 **0.33%**，全部落在排版/标题口径差异内。
4. 因此：任何一条被判为"全读过"的记录，其覆盖范围都真的等于整个文件。**分子是干净的。**
5. 而分母是脏的：写作仓 484 份历史资料中 454 份从未被任何记录触及（`research/` 92、`editorial/` 295、`state/` 16、`outline/` 5、`evidence/` 3 全数未读）。
6. 结论：过去报告的"高覆盖率"不是谎报阅读，而是**统计时把没读的目录算进了分母之外**（或把结构统计、引文抽样当成了已读）。修分母即可，不需要推翻既有阅读结论。

一句话版本：**读过的都是真读了，只是读得太少。**

> **口径对齐（与 F05 最终报告交叉核对）**：本报告的「③部分阅读」与 F05 的「③引文逐字一致」是**两个不同维度**，勿混。F01 的③指"记录声明的覆盖范围不足"——本轮 **0 条**；F05 的③指"紧贴引文逐字一致"——**754 条紧贴引文 604 条通过（80.1%）**，未通过的 150 条主因是**行号漂移（45 条内容就在同一文件、只是不在标注行；25 条在另一文件）**，而**不是「读了一半」**。两者共同支撑同一结论：历史阅读事件真实、覆盖以整文件为单位，问题出在分母口径与引文锚点，不在"半读"。

## 2. 旧 `02_full-reading-ledger.tsv` 作废原因

旧表 1931 数据行，UNREAD 1784 / FULL_TEXT 146 / STRUCTURED_ONLY 1。作废理由：

1. **分母错**：把两仓目录树直接相加，含 `editorial/full-corpus-readiness/` 的 298 份**本轮审计产出**（是审计结论，不是待读资料），也含 `.workbuddy` 影子树与私密层条目。
2. **分子错**：FULL_TEXT 仅 146，而 `read-records.tsv` 实有 833 条全文口径记录、809 个唯一文件。旧表与唯一可信原始记录**相差 600+ 条**，是阅读记录尚未汇聚完成时的快照。
3. **颗粒度错**：把"进过目录""统计过行数"与"读过全文"混在同一个 `reading_status` 列，无法承载证据强度。
4. **不可复算**：无 `record_id`，无法回溯到具体阅读事件，也无法表达"同一章读两遍"。

本报告不复用旧表任何单元格。

## 4. 六分类判定依据

判定顺序**排除优先**，一个文件只落一类。核心原则：**「文件存在」「做过结构统计」「有三条内容记录」都不等于全文阅读**——只有"记录声明的覆盖范围 + 可解析载体"三者对齐，才算①。

| 类 | 名称 | 判定条件（全部满足才可归入） |
|---|---|---|
| ① | 全文阅读且证据核验通过 | ①载体可解析：文件存在于**记录所声明的版本内**（要么当前工作树，要么 `git show <version>:<path>`）②范围自 `L1` 起至末行，或声明 `全文/full text/all N lines` ③`\|实际行数 − 声明行数\| ≤ 1`，或字数漂移 ≤ 2% ④不在影子树/私密层/本轮产出目录 |
| ② | 已读但证据仍需补充 | 有记录且声称全文，但②③④任一不成立。当前仅两类：9 条仅写「全文（subagent 逐段）」无量化口径；1 条读的是影子树备份版 |
| ③ | 部分阅读 | 声明末行 < 实际末行（覆盖率 < 99%），或显式声明"只读前 N 行/摘要/目录"。**本轮 0 条** |
| ④ | 未阅读 | 在语料内、路径可解析、无任何阅读事件 |
| ⑤ | 按明确规则排除 | `.workbuddy/**`（影子树，唯一条目已按裁决改②）、`私人资料/**`、`lover-best/**`、`editorial/full-corpus-readiness/**`（本轮审计产出 298）、`editorial/final-readiness/**`（本轮代理产出 2） |
| ⑥ | 权限或工具受阻 | 记录或状态显式声明无法打开/无权限/工具失败。**本轮 0 条**：833 条记录中无 blocked/权限/失败语义 |

刻意拒绝的三种伪证据：

- `02B.actual_lines` 非空 ⇒ 只证明**文件存在**，不升类；
- `index-audit/`、`bidirectional-mapping/` 统计过章数行数 ⇒ 属**结构统计**，仍归④；
- 某章在别处被引用 3 条摘句 ⇒ 属**引文抽样**，仍归④。
