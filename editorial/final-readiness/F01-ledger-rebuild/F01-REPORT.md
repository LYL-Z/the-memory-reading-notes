## 1. 旧 `02_full-reading-ledger.tsv` 作废原因

旧表 1931 数据行，状态分布 UNREAD 1784 / FULL_TEXT 146 / STRUCTURED_ONLY 1。作废理由（均可复现）：

1. **分母错**：它把两仓各自的全量目录树直接相加当作分母，其中含 `editorial/full-corpus-readiness/` 的 298 份**本轮审计产出**（这些文件是审计结论，不是待读历史资料），也含 `.workbuddy` 影子树与私密层条目。
2. **分子错**：FULL_TEXT 仅 146，而 `read-records.tsv` 实际有 833 条全文口径记录、809 个唯一文件。旧表与唯一可信的原始记录**不一致 600+ 条**，说明它是在阅读记录尚未汇聚完成时生成的快照。
3. **颗粒度错**：把"进入过目录""统计过行数"与"读过全文"混在同一列 `reading_status`，无法承载证据强度。
4. **不可复算**：没有 `record_id`，无法回溯到某一次具体阅读事件，也无法表达"同一章读了两遍"。

因此本报告不复用旧表任何单元格，全部从 `read-records.tsv` + 磁盘重新计算。

## 3. 六分类判定依据

判定顺序为**排除优先**，一个文件只会落一类。核心原则：**「文件存在」「做过结构统计」「有三条内容记录」都不等于全文阅读**——只有"记录声明的覆盖范围 + 磁盘当前行数/字数"三者对齐，才算①。

| 类 | 名称 | 判定条件（全部满足才可归入） |
|---|---|---|
| ① | 全文阅读且证据核验通过 | ①路径可解析（文件此刻存在于该仓）②记录范围自 `L1` 起、声明到末行，或声明 `全文/full text/all N lines` ③`|实际行数 − 声明行数| ≤ 1` ④若有字数口径，汉字漂移 ≤ 2% ⑤不在影子树/私密层/本轮产出目录内 |
| ② | 已读但证据仍需补充 | 有阅读记录且声称全文，但上述 ③④⑤ 之一不成立：路径不可解析（20 条 volume-07）、仅声明「全文（subagent 逐段）」而无行数/字数口径（10 条） |
| ③ | 部分阅读 | 声明范围自 L1 起但末行 < 实际末行（覆盖率 < 99%），或显式声明"只读前 N 行/摘要/目录" |
| ④ | 未阅读 | 在语料内、有路径可解析、无任何阅读事件 |
| ⑤ | 按明确规则排除 | `.workbuddy/**`（影子树过期备份）、`私人资料/**`、`lover-best/**`、`editorial/full-corpus-readiness/**`（本轮审计产出）、`editorial/final-readiness/**`（本轮代理产出） |
| ⑥ | 权限或工具受阻 | 记录或状态显式声明无法打开/无权限/工具失败。**本轮 0 条**：833 条记录中无任何一条含 blocked/权限/失败语义；20 条路径不可解析属"记录写错路径"，是证据缺陷而非权限受阻，故归② |

判定中刻意拒绝了三种"看起来像读过"的伪证据：

- `02B` 中 `actual_lines` 非空 ⇒ 只证明**文件存在**，不能升类；
- `editorial/` 下大量 `index-audit/`、`bidirectional-mapping/` 报告统计过章数行数 ⇒ 属**结构统计**，未读原文，仍归④；
- 某章在别处被引用 3 条摘句 ⇒ 属**引文抽样**，仍归④。
