## 〇、先给结论（五句话）

1. **风险最大的人不是父母，是赵问竹。** 她一个人横跨 46 个章节文件，构成全书唯一的情感主线；她被写入的不是「出现过」，而是「被喜欢」「被室友性化起哄」「小测交换答案」「答应送礼又没送」「2026 五一与作者母子同游西安」。这些是她的人生，不是作者的素材。
2. **最容易被忽略的人是李顺贤。** 两处正文说这位具名小学教师「回头替我补上」十个学期的评语、且「墨色深浅差不多」。这不是文学描写，是对一名在职教师职业操守的公开指控。
3. **最不能拿「作者已授权」覆盖的是父母与宋俊豪。** 父母只有内部阅读＋非公开创作授权；宋俊豪第一份问卷就选了化名，正文至今写「鸟哥叫宋俊豪」。
4. **可定位隐私不是「一点点」，是完整的一套。** 小区名＋栋号＋六楼无电梯＋片区＋地标＋小学就读路线＋初中校名＋高中校名＋班号＋寝室号＋床位号＋父母职务，已经足以把一个人从 14 亿人里挑出来。这正好是家庭规则明令「公开发表前须再次删除」的三类线索：学校时间组合、单位线索、家族关系细节。
5. **「已经在 GitHub 上公开」这件事必须先说清楚。** 本仓 remote 是 `github.com/LYL-Z/the-memory-reading-notes`，正文与真名已随提交进入公开历史。所以现在讨论的不是「要不要公开」，而是「正式出版与二次传播前必须补什么」。历史 PR 与 fork 不会因为主支改写而自动变私有。

## 一、逐人风险分级

判据不看出现次数，看**写了什么**：
- **高**＝正文对这个人做出了可归责的事实断言（负面行为、隐私、身体、家庭、情感），或本人已明确表达相反意愿 → 不点名授权不得发表。
- **中**＝正文只写中性互动，但姓名＋学校/班级/事件组合足以定位，或写入本人未同意的私人细节 → 须化名或删细节。
- **低**＝公共身份（教师职务行为）或已获明确授权，且描述不含可归责内容 → 可保留。

## 二、未成年人问题

本书涉及的主体事件发生在 2013–2026 年，绝大多数当事人当时未满 18 岁。以下四条是硬问题，不是风格问题。

### 2.1 `V2-008`：真名＋班号＋可检索奖状

**原文**：`V2-008:5-9`「李顺贤。她教我数学，也当过我五年的班主任」「我在益阳市实验小学的86班。到了六年级……我才进1305班」；`:161`「2017年还有一张青少年科技创新大赛的证书，作品名字叫『污水废气处理机』，拿到了区一等奖。……2019年六月，另一张奖状写着征文比赛一等奖」；`:253`「庆祝新中国成立七十周年」征文。

**问题**：这不是「一个模糊的童年回忆」，而是一组**可交叉检索的证件级信息**：学校＋两个班号＋两个年份＋两个奖项名＋作品名。任何同校同届的人，或任何能查到区级获奖名单的人，都能确认「刘佑林」是谁，并顺带确认同页出现的王培森、曹卓雅、向睿馨、李漪涵、李晗、郭婉妍是谁。
**处置**：删作品名与具体奖项，只保留「得过几张奖状」；班号改为「两个数字」；校名改为「市里的一所小学」。

### 2.2 `V2-021`：未成年饮酒＋寝室违纪

**原文**：`V2-021:155`「我带了果味酒进寝室，低度数的，瓶身很好看。……帆哥先尝了一口」。

**问题**：①作者本人（时年 16–17）承认携带酒精饮料进入宿舍，属校规违纪；②把「帆哥」写成共同饮用人；③与 `V2-018:43` 的「426 八人寝、床位编号」同卷，寝室可定位。这条一旦被学校或家长读到，后果落在**所有在场者**身上，不只是作者。
**处置**：删除品牌与「带进寝室」的动作，改为「有一次我在寝室做了件不体面的事」；不写谁喝了。若要保留，须刘弈帆本人同意。

### 2.3 `V1-007:233`：赵问竹「微醺 RIO」

**原文**：`V1-007:233`「她曾告诉我，留校的某个周六晚上，吃的是泡面，配一瓶叫『微醺』的饮料。」

**核查结论（与派单描述有出入，须更正）**：
- 现稿**没有**「每周五买」，**没有**把转述写成确定行为，且明确写了「她曾告诉我」「那是她愿意告诉同学的一小截生活」。这一处的**归属性处理是合格的**，应作为全书范例。
- 但风险仍在：一名具名高中女生（时年 15–16）被写成在宿舍喝低度酒。这是**未成年人饮酒＋女生宿舍生活**的双重私密信息，且品牌可查。
**处置**：删品牌名，改「一瓶甜味的饮料」；或整段删去。**须赵问竹本人同意后方可保留原样。**

## 八、一句话总结

这本书写得好不好是文学问题；**它能不能出版，取决于它愿不愿意承认：那些被写的人，不是作者的记忆，是别人的人生。**

现在的稿子，作者已经做对了一件事——大量使用「她说」「我记得」「我不替她写」。这些是真诚的边界意识。但边界意识不能替代授权。**克制地写一个人的隐私，仍然是写了一个人的隐私。**
