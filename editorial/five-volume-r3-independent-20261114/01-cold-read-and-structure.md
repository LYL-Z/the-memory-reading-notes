# 01 · 独立冷读与结构诊断

**方法**：先读被改段与其上下文，独立形成判断；再读 #67 自附状态表与 #68 报告做反向检验。下文凡涉及"候选是否重复/是否更像 AI"的判断，尽量先给可复算的数，再给段落引文。

## 一、结论先行

1. **任务书诊断的病症基本正确，但主犯抓错了。** "同一种情节机制反复出现"在文本中的实际载体不是"别人有自己的生活"这一母题（实测未增加），而是一组**可逐字定位的模板句**。
2. **候选最真实的进步是对话化**，不是字数，也不是身体描写。对话密度 **4.4 → 6.5 段/万字（+48%）**。这是本轮唯一一项结构性改善。
3. **最大的结构问题不在 95 章总量，而在卷间失衡。** 第四部章均 3,967、第五部 4,210，不足前三部（6,821–8,473）的一半。这不是"精修不足"，是这两卷在体量上还不是同一部书。
4. **候选新增的身体感受，整体低于作者授权的上限，但形成了新套语。** 「后颈热」在 main 中 0 次，候选 5 次；「耳朵热」0→3；「脸热」0→1。这是候选**引入**的词族，不是继承的。

## 二、卷间密度断层（独立发现，任务书未提）

```
第一部 18 章  章均 7,597   ███████████████
第二部 24 章  章均 6,821   ██████████████
第三部 16 章  章均 8,473   █████████████████
第四部 18 章  章均 3,967   ████████
第五部 19 章  章均 4,210   ████████
```

第四部的内部落差更极端：`010` 仅 2,105 字，`018` 6,351 字，同一卷内相差三倍。第五部 `005` 2,229 字（#68 补到 2,550，仍最短），`008` 6,336 字。

**这意味着什么**：读者从第三部（章均 8,473、整章一整场戏）进入第四部，会突然进到"一章只够一件事、甚至一件事没讲完"的节奏。这不是文学选择的问题——第四部没有一份文件说明它要变成短章体。这是**施工事故**被当成了风格。

**我的判断**：任务书要求"总体体量不得因机械精简而明显缩水"，方向对但不够。真正的处方是**把第四、五部的章均补到 6,000 以上**，即在两卷内各增约 3.5 万字与 3.2 万字。而这只有靠"调用尚未成文的材料块"（初中 1907 班的课堂与宿舍、高一高二的物理与数学学习现场、2024 沪浙之行的具体日程）才可能，不能靠在本轮这种 150–660 字的段落里加料。

**#67 的做法正好相反**：它在第二部加了 8,542 字（章均 +356），在第四部加了 2,955 字（章均 +164）。**最需要增厚的第四部拿到的最少。** 这是资源错配，而不是文学判断。

## 三、被任务书误判的一项：母题没有增加

任务书第四节第 3 条认为"人物总被安排来教育主人公"，第 1 条认为"别人有自己的生活"式收尾反复出现。我实测（前四部，等量对比）：

| 词串 | main | #67 | 每万字（main→#67） |
|---|---:|---:|---|
| 自己的生活 | 3 | 3 | 0.06 → 0.06 |
| 有自己的 | 65 | 64 | 1.28 → 1.21 |
| 也有自己的 | 17 | 18 | 0.33 → 0.34 |
| 自己的课 | 6 | 6 | — |
| 并不是 / 并非 / 并不 | 67 / 33 / 312 | 65 / 32 / 310 | 全部持平或微降 |
| 不是（含"不是…是…"） | 782 | 848 | 15.4 → 16.1 |

**结论：候选没有加重这个病症，也没有减轻它。** 这是**继承**，不是**引入**。任何把"AI 感加重"归因于 #67 的说法都不成立。

**但**新增段落里确实有 4 处把这个母题**说出来**而非演出来，这 4 处仍应改：

- 一部 013：「她没有问我为什么在门外。**她有她的纸要送。**」
- 二部 002：「**他今天也有自己的班号要消化。**」
- 二部 005：「高一我几乎没跟他说过话。**这晚他也不欠我一句。**」
- 二部 023：「热完我看他，**他在看路，不是在看我的耳朵。**」

四句都是好的观察被一句总结封死。删掉冒号后的部分，观察仍在。

## 四、真正的重复：模板句（硬证据）

这是本轮最重要的发现。以下引文全部可在候选分支逐字检索到，行号为其所在章。

### 4.1 「打字—删掉—拇指发酸—扣手机」四件套

| 章 | 原文 |
|---|---|
| 二部 022 | 「输入框空着，我的拇指还停在键盘上，**停得发酸**。酸完我把手机扣在桌上。**扣的声音不大。不大也够让我自己听见。**」 |
| 四部 007 | 「我的拇指停在发送上，**停得发酸**。酸完我把那一行也删了。屏幕空着。……我把手机扣在桌上。**扣的声音不大。不大也够我自己听见。**」 |
| 四部 011 | 「我把那四个字删掉。删掉以后**手指还停在键盘上**，像停着就能把当年的数字等回来。」 |
| 四部 017 | 「输入框空着。**拇指酸**。酸完我把手机扣上。」 |
| 二部 022 | 「我把手机扣在桌上」＋四部 017「我把手机扣上」 |

**二部 022 与四部 007 的末两句只差一个「让」字。** 两部相隔 30 万字、跨越两个学段、两个不同的人（朱学良／母亲），用同一套句子收尾。这不是呼应，这是模板。**四部 011 与 017 两段应整段撤回**：两段都没有增加事件，只是把同一套动作再演一遍。

### 4.2 「母亲脱鞋—按脚背」五连

| 章 | 原文 |
|---|---|
| 三部 004 | 「她坐在沙发上脱鞋，一只脚从鞋里抽出来，**用手按了按脚背**。」 |
| 三部 007 | 「鞋也没换利索，一只还踏在脚后跟上。包放在沙发上，**人先坐下。坐下才把那只鞋褪掉。脚背上有一道**被鞋口勒出来的红。她用手按了按」 |
| 三部 009 | 「一只鞋还踏在脚后跟上。……**包放在沙发上，人先坐下，才把鞋褪掉。脚背上有一道红。**」 |
| 三部 015 | 「坐了才脱鞋。**脚是肿的。她按了一下，没出声。**」 |
| 三部 001 | 「她坐在床沿上，没有立刻躺下。……腰还是酸。」 |

**三部 007 与 009 的核心句逐字相同**（"包放在沙发上，人先坐下，才把鞋褪掉。脚背上有一道红"）。两次都发生在母亲下班回家。**同一动作在同一卷内出现四次以上，就从"母亲的疲惫"变成了"作者的母亲装置"。**

### 4.4 新增身体词族（候选独有）

| 词 | main | #67 | 全部出现在新增段？ |
|---|---:|---:|---|
| 后颈 | 0 | 5 | 是（一部 016、二部 003、二部 024 等） |
| 耳朵热 | 0 | 3 | 是 |
| 脸热 | 0 | 1 | 是 |
| 颈（总） | 1 | 6 | 是 |
| 酸 | 19 | 34 | 大部分是 |

「酸」的增幅 +79%。其中相当一部分是好的（"腿是麻的"用于晚自习后、"掌心勒出一道印"用于拧抹布）。但「拇指…酸」「耳朵热」「后颈热」这一族属于**廉价体感**：它们不携带信息，只携带"这里有情绪"的标记。

**判据**：好的体感句后面跟着一个具体后果；坏的体感句后面跟着一个抽象名词。
- 好：「带子离开肩膀的时候，肩上留下一圈深印。」（三部 004）——后果可见。
- 坏：「后颈热了一下。热完我又不敢回头核对。」（二部 003）——"不敢核对"是抽象。

## 五、候选真正做到了什么（必须承认的部分）

### 5.1 对话密度 +48%

| | 「」对话段数 | 每万字 |
|---|---:|---:|
| main | 225 | 4.4 |
| #67 | 341 | 6.5 |

这不是修辞层面的改善，是**叙述方式**的改善：把"后来我们确实会互相说一些鼓励的话"改成一次具体的晚自习，把"中考考砸后的失落"改成一张饭桌上的四句话。任务书第四节第 5 条要求"情感描写不得只存在于概念里"，这一项候选做到了。

### 5.2 六个可以作为全书标准的段落

以下六段我认为已达到"应当固化为此后各卷最低标准"的水平。判据不是文采，是三条：**动作承担信息 / 人物有自己的日程 / 主角的动机不体面且不被纠正**。

| 段落 | 三条判据 | 关键句 |
|---|---|---|
| 二部 001 母亲进门收城 | 全中 | 「我的城被她两下就收成了桌子。」「下一集停在锅开了的那一声上。」 |
| 二部 004 母亲出来找他 | 全中 | 「我的腿有一瞬间想往旁边让。让开就能假装还没被看见。」 |
| 二部 008 橡皮过三八线 | 全中 | 「放正中，就算不是我先开口。」「用完，放回正中，比我放的时候更正一点。」 |
| 二部 018 歪掉的爱因斯坦 | 全中 | 「眼睛还是斜的。斜着，我也没有揭下来。」 |
| 三部 007 父母夜谈 | 全中 | 「你不管的样子，和管的样子，我有时候分不清。」「我喝了一口，借口就用完了。」 |
| 三部 012 作文被念 | 全中 | 「说我儿子为了得一个优，给我加了一段我没有的时间。」 |

**这六段的共同技术**：不让任何人对主角解释他的问题。母亲不解释，父亲不解释，王培森不解释。主角自己也不总结——他只做一个动作（藏纸、退回来、放橡皮、贴歪海报、喝一口水、把本子收起来）。

**这应当是 R3 的操作定义。** 而不是"增加身体细节"或"增加字数"。

## 七、我对"AI 痕迹"的最终归因

任务书列出 5 条病症。按我的实测，真相是：

| 任务书诊断 | 实测 | 修正后的说法 |
|---|---|---|
| ① 同一种情节机制反复 | 母题未增加（65→64） | 真凶是**模板句**（4.1–4.3），不是情节机制 |
| ② 意象过密、过于工整 | 部分成立 | 「三楼」「六楼」「门缝的光」「电话挂了」已成装置 |
| ③ 人物总被安排来教育主人公 | 部分成立 | 更准确说：人物被安排来**理解**主人公（"听得出你不想让人接"、"起了也可以不停在半路"） |
| ④ 叙述者过早成为道德裁判 | 未加重（不是/并非持平） | 是继承问题；新段落反而多写"我没有问""我没有说"这类**克制的自认**，方向是好的 |
| ⑤ 情感描写过于抽象 | **显著改善** | 对话化 +48%，这是本轮真功 |

**一句话**：这一轮不是"AI 文风更重了"，而是"**AI 文风的形状变了**"——从抽象的抒情议论，变成了具体的、可复制的、带体感标记的小场景。后者更难被读者识破，但一旦识破，破坏力更大，因为它暴露的是**生产流程**，不是文笔。

这也解释了为什么二部 022 与四部 007 会逐字相同：不是作者偷懒，是生成过程在用同一把尺子量所有情感。
