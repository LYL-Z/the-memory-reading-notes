## 二、叙述顺序 vs 事件顺序（实际成书的形状）`[实测]`

```
事件时间轴（早 → 晚）
出生 2007 → 小学 2013-18 → 初中 2019-22 → 高一 2022-23 → 高二 2023-24 → 高三 2024-25 → 大学 2025-26 →（当下 2026-11）

叙述顺序（第 1 章 → 第 135 章）
Ⅰ 大学江安(大二) ──倒回──▶ 高一 G2204（18 章，落在《历史课》）
Ⅱ 高二分班 2023 ──并置──▶ 童年·小学·初中（24 章）
Ⅲ 家庭：出生 2007 ──▶ 童年益阳·六楼（16 章）
Ⅳ 初中金海 1907（18 章，正向）
Ⅴ 高二 G2205 换座（19 章，正向）
Ⅵ 高三·高考·强基（20 章，正向）
Ⅶ 大学四年（20 章，正向，止于大二秋）
```

**形状判断**：

- Ⅰ–Ⅲ 是**逆流**：从最近（大学）退到最远（出生）。这一步是有效的，因为它先给读者一个已经成年的「我」，再让读者看着这个成年人退回他还不知道怎么说话的时候。
- Ⅳ–Ⅶ 是**顺流**，一路向前，不再回跳。
- 于是全书是「**两段逆行 + 四段顺行**」的钩形，不是环形，也不是螺旋。

**这与设计文档的差异必须记录**：

| 设计（2026-11-07 / 11-08） | 实际（2026-11-14 落地 / PR#84） |
|---|---|
| Ⅵ《复数现在时》：回到 2026 正在整理史料／写书时，重访 Ⅰ–Ⅴ | Ⅵ《未写完的纸》：高三 |
| Ⅶ《那些我没有成为的人》：反事实分支、梦、未来投影 | Ⅶ《远方不是结尾》：大学四年，完全写实 |
| Ⅴ《远方不是结尾》：大学与南洋理工 | Ⅴ《换座之后》：高二 G2205 |

即：**书名整体前移一部，最后两部被现实材料替换，反事实与「复数现在时」两层在成品中不存在。**

这不是错误，但它意味着：**读者拿到的是一部「开头非线性、结尾线性」的自传体长篇**，而不是设计文档所描述的「七部互相反证的多可能世界」。若作者要恢复设计意图，最低成本路径是在 Ⅶ 内部插入 2–3 章写作现场（见 `11_...audit-preparation.md` 第八节）。

## 四、伏笔与回收：已成立／未成立 `[实测]`

1. **钥匙**：Ⅲ-004 母亲把钥匙挂在我书包侧袋，「丢了我们两个都进不了门」→ Ⅶ-002 与曾子沣立下「出门带钥匙／门不锁死」三句话规矩。同一个物件，从「被照顾」到「互相约束」。

## 五、不可靠叙述的机制分类（按现行文本）

### 有效的三种

1. **物件被改造**（Ⅶ-015 裁照片）。叙述者改动了物理证据，读者看着他改，也知道他为什么改，还知道他保留了原图但理由是「怕别人要完整尺寸」。这是把自欺做成了可见动作。
2. **评价被自己的行为反驳**（Ⅶ-004「总裁气质」）。别人给的标签 → 追问来源 → 自己找到一个例子 → 发现那个例子正说明相反的事。不需要旁白。
3. **记忆的可错性写在事件里**（Ⅰ-018 谁先笑）。不写「我可能记错了」，而写「最会逗人的那个人自然最容易在记忆里抢到第一个镜头，事实却未必配合」。

### 失效的三种

1. **无对照的推测**（Ⅱ-019 式）。整章 2 处对话、8,004 字，其余是「她好像……」。不可靠叙述需要读者手上有第二个数据源。
2. **旁白替读者结算**（Ⅶ-003「这些事我都是后来慢慢知道的。知道以后我发现，我从来没有问过他这些。」Ⅶ-001「我从前也在讲台上同赵问竹写过大学的名字」）。前者是结论，后者是与前后动作无连接的硬插呼应。
3. **破框元叙述**（Ⅶ-005「写到这里我想起网球课」等 12 处）。这不属于不可靠叙述，它是作者手滑。

### 必须守住的界限（引现行裁定）

- `2026-11-14-editorial-verdict.md`：**不为了制造诺兰式矛盾而保留已被作者裁定为记错的两个伪证版本**。不可靠叙事不等于主动违背较新的、较可靠的作者记忆。
- `2026-11-13` 作者裁决：`W_world` 的 `COUNTERFACTUAL` 层不得回流事实库充当物证。
- `AGENTS.md:8`：诺兰式技巧必须改变读者能够合理作出的判断，而不是乱序、同一事件重演三遍、或故意隐匿公平所需的关键知识。

## 六、与三个核心未解项的关系

1. **「0」**：Ⅰ-010 给了读者一个空着的符号，Ⅱ 出现了同形不同义的用法，`contradictions #14` 明令不合并。**保持不闭合是正确决定**，但需要在下一轮确认 Ⅳ 是否意外泄露过解释。
2. **那声笑**：Ⅰ-018 处理得当。风险在于 Ⅶ 若揭示「她也曾喜欢过他」（见下），Ⅵ/Ⅶ 会诱惑作者回头「补上」笑的意思。**建议：即使采纳揭示，也不解释那声笑。**
3. **她是否喜欢过他**：见 `11_..._audit-preparation.md` 第五节。这是全书唯一一处「事实层已确认、正文层一律未知」的裂缝，且裂缝最宽处正好在第七部这一最晚的回望卷。
