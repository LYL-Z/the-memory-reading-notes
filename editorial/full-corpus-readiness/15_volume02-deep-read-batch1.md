## V2-001《一个人的客厅》

| 维度 | 内容 |
|---|---|
| **事件时间 / 叙述时间** | 童年（小学前至小学低年级，益阳资阳区六楼）；叙述为成年回望，含「现在翻到童年照片」的明确当下层 |
| **章节叙事功能** | 全书起点：确立「一个人分饰多角」的能力与它的代价。这是书名「复数人称」的第一次具象化 |
| **人物及关系** | 「我」（同时扮坏人、队长、报信者）；母亲（结尾进门） |
| **具体场景** | 客厅：米白色转角皮沙发＝城墙，茶几玻璃面绕一圈＝绕过鹅羊池，电视柜格子＝坏人的房子，阳台玻璃门＝城门。纸上画城，市政府第一（居中）、银行第二、医院第三、警察局第七（因为喜欢七） |
| **行为冲突** | 坏人要逃／队长要抓；「我」同时是两者，故必须替双方各找一个输的理由 |
| **心理与身体细节** | 掌心铅笔灰冲不干净；膝上的木地板印；袜子底是灰的；「纸按在胸口，像按住一张不该被看见的卷子」 |
| **情感进展** | 从得意的掌控 → 发现「一个人说了算也会碰上不听话的下属」→ 勉强接受「谁也不算彻底赢」 |
| **人物独立性** | **母亲是本章最强的他者**：她进门先看茶几（杯子偏了一掌、笔袋横着、窗帘还在晃），但「她没有问窗帘」；「先洗手。纸放下。」；她把杯子推回原处、笔袋摆正，「我的城被她两下就收成了桌子」 |
| **不可靠叙述** | 叙述者当场承认：「也可能她并没有说这两个字，是我后来给那段等待加上的催促」——这是全章少数几处自我校验（注意：这句在 001 里出现在**通知书**段落，属 V7-001；此处不混用） |
| **非线性功能** | 无时间跳跃；是全书时序的**最早端之一**，为后文「导演权」主题埋根 |
| **与其他章节衔接** | 直接连 Ⅴ-008（拍摄表）、Ⅶ-008/009（导演署名）；与 006（三人拍摄）构成「一人／三人」的对照 |
| **有效重复** | 「我给自己规定了这条规矩，想了想，还觉得很公平」——把自我立法写成孩子的骄傲，后文多次复现此模式 |
| **无效重复** | 无明显冗余。唯一可议：中段「城也有不听话的地方」与「坏人的车坏了」两处都在讲同一个道理（规则被自己的疏漏破坏），可考虑合并 |
| **事实依据／重构** | 客厅陈设、绿色儿童摩托车、蓝色马克杯、蓝色笔袋有照片依据（文中自述「旧照片里」）；具体对白与追逐过程为 L1 重构 |
| **文学语言问题** | 个别句子偏解释：「一个故事要是处处照我先前的办法走，很快就没得玩了」——这句让读者失去自己发现的机会 |
| **需知识库补强** | 鹅羊池广场石鹅群像的实物依据；资阳区住宅「秀水俪园后门—九栋」的路径（`contradictions #25` 住址层级待核，正文已给出可识别路径，**需确认是否越界**） |

**最重要的一句**：「我一边问一边换方向，生怕两个角色站在同一处，分不清谁拦住谁。」

**最重要的问题**：结尾母亲那句「演完了也得吃饭」极好，但母亲进门后的三段（看茶几／让洗手／收城）稍长，第四段（「晚饭时我没有再讲追车」）已可收束。

**最重要的问题**：无重大结构问题。这是全书最好的章节之一，建议作为「第二部质量标准」。

## 批次 2 的结论

1. **「第二部人物功能化」判断撤销。** 曹卓雅、王培森、向睿馨、李霞都以「有自己的记忆、自己的班、自己的活动」出现，且作者明确拒绝替他们编造。
2. **「第二部缺场面」判断撤销。** 007 有完整三天行程与一个下午的拖延现场；008 有冷战、橡皮、台阶画图、成长手册十栏。
3. **新增一类值得保护的写法**：用「他人不记得」来给叙述者的记忆设上限。这是全书最有效的不可靠叙述机制之一，且比「我可能记错了」高级得多。
4. **仍待核**：009–024 共 16 章未读。第二部后半（父亲讲述、一百三零五之后的初中过渡、食堂、过年的路、垃圾桶、老师怎么写我、右前方、名单之外、四二五、小林子、有人听我讲）尚未验证。
