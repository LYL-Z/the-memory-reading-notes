## 2. 三条必须先纠正的口径

### 2.1 董佳好：「V2 全卷对抗／四次讨厌你」不成立

- 正文实际：**V5-018:281**「我讨厌你刘佑林。」＋`:291` 复述一次，**共 2 次**。
- 该章**不出现「董佳好」**，只用「语文课代表」（`:253/281`）。
- 语境不是「V2 全卷对抗」，而是 V5 密室回忆：她拒绝为「谁先发现线索」提供标准答案。
- 结论：**位置错记（V2→V5）、次数错记（4→2）、人物指称错记（点名→职务代称）**。本批档案按正文改正；建议 team-lead 在汇总时同步，避免其他卷章引用错误。

### 2.2 颜子杰：正文确实 0 次；两笔 99 元只在事实仓

- `grep -o 颜子杰 volume-*/*.md /tmp/v7/*.md | wc -l` → **0**。
- 任务书提到的「朋友圈帮做作业 99 元」与「群聊替长沙理工学生做 99 元」，是**事实仓的两条不同接单**（台账 #50），不是正文情节。
- 两笔不能合并：2026-06-07 朋友圈（工业大模型，6h/3.5h）vs 2026-06-15 群聊（《人工智能基础B》，8–9h）。都写 99 元，但对象、工作、时长不同。

### 2.3 刘逸凡 ≠ 刘弈帆：不是异写，是两个人

- **刘弈帆**：G2205 物理课代表；V2 与 V6 共 22 次（017/018/021/023、008/010/011/020）。
- **刘逸凡**：G2205 数学课代表；只在 **V6-012/013** 出现 24 次，是替叙述者把赵问竹叫到二班门口的人。
- 事实仓 `人物标准库` 也把两人分列。**不要在校对时合并**，也不要把「刘逸凡」当成「刘弈帆」的错字。这一条是本批最容易误伤正文的地方。

## 3. 四个结构性发现

### 3.1 赵问竹 V3 为 0：不是遗漏，是时间不可能

第三部是家庭卷（2007—2019），赵问竹 2022 年才进入叙事。她在 V3 的 0 次不是「写丢了」，而是**她尚未登场**。

- 全七部口径：46/135＝**34.1%**。
- 排除 V3：46/119＝**38.7%**。
- 建议所有对外统计同时给两个分母；只给 34.1% 会被误读为「第三部漏写核心人物」。

### 3.2 命名不对称：母亲被还名 3 次，父亲 0 次

| 人 | 法定名 | 正文次数 | 位置 |
|---|---|---:|---|
| 母亲 | 何永红 | **3** | `V2-004:41`、`V2-014:103`、`V3-001:221` |
| 父亲 | 刘必胜 | **0** | — |

「被命名（刘佑林）→被还名（何永红）→自命名（夏思成）」这条母题，**在父亲身上是断的**。他不是没有被命名，而是文本从未给他那个时刻。这不是事实缺失（法定名已确认可写），是叙述选择。可深化处见 `父亲.md` §6-1。

### 3.3 关系图谱口径倒挂：19 次的人有完整线，173 次的人没有

- 阳隽豪：正文 19 次，事实仓有完整分支（高一疏远→高二同寝→KPL→高三还练习）。
- 宋俊豪：正文 173 次，事实仓无完整分支（台账 #237）。
- 颜子杰：正文 0 次，事实仓有完整人物页与时间线。
- 结论：**图谱按材料可得性建，不按正文重要性建**。任何「按出场次数排人物重要性」的做法都会错。

### 3.4 「V3 家庭卷」同时是父亲/母亲的高峰与赵问竹的空白

- 母亲 V3 11/16 章、父亲 6/16 章；赵问竹 0/16。
- 这说明第三部不是「群像卷」，而是**家庭内部视角卷**。它把父母从「我爸妈」变成「有青年史的人」，代价是高中线完全退场。
- 结构上这是正确的；但若全书要做「七部情感连续」，第三部与第四部之间需要一个**过渡锚点**（例如 V4-018 的「那时候我还没认识赵问竹」已经承担了一半）。

## 4. 事实分级说明（本批统一）

| 级 | 含义 | 例 |
|---|---|---|
| **F1** | 有原始材料直接支持（本人问卷/信件/证件/聊天原话/可核事件） | 父亲 1985 年看电视；母亲电信工单；赵问竹 G2202 |
| **F2** | 多份二手互证，或编辑整理稿，未逐条对原件 | 父亲「不太会说，事情倒是做了」（母亲转述） |
| **F3** | 单一来源、未独立核 | 赵问竹大学专业（仅母亲转述） |
| **U** | 未决／两说并存／无实物 | 上海谁开车；出生手环；分 7 组；C 语言挂科 |
| **L1** | 文学重构：有事实骨架，场景/对白为写作 | 父亲下棋对话；赵问竹「嘲笑你」 |
| **L2** | 文学虚构/填补：无源细节，但已在文中自标「我记得/我猜」 | 夜审流程；茶桌动作；西安山路细节 |

**原则**：L1/L2 不是错误，是小说的方法；错在**把 L2 当 F1 引用**。本批档案对每一处都标了级。
