## 一、II-019 独立复核

### 1.1 这一章的机关在哪

机关不是「我认错人」这个情节，而是**名字出现的顺序**：

| 行 | 原文 | 叙述层 |
|---|---|---|
| `:7` | 「右前方有人低着头。」 | 现场（高二上，开学第一天） |
| `:9` | 「一身校服，背对着我。既没有招手，也没有转过脸来，没做任何值得我单独记住的事。我却看了第二眼。」 | 现场 |
| **`:11`** | **「赵问竹。」** | **独立成行，无引号、无「我以为」，排版上等同于一个确认** |
| `:13` | 「这三个字冒出来的时候，我自己都吓了一跳。不是看见了她本人，我知道她在二班。名单上有她的名字，有我的名字，分在不同的地方，早上已经看得清清楚楚。」 | 现场＋自我质疑 |
| `:19` | 「可这一次我只看见背影。」 | 现场 |
| `:23` | 「我认出的其实不是她，是那个角度；角度一换，人就回到陌生人里。」 | 回望（解释） |
| **`:77`** | **「后来我才知道，她叫董佳好。」** | **回望（距 `:11` 相隔 66 行）** |
| `:79` | 「知道名字以后，回忆就很容易犯一种懒。好像在第一眼看到背影时，我便在心里清清楚楚叫出了这三个字。」 | 元叙述（点破机关） |

**误导发生在 `:11` 到 `:77` 之间那 66 行。** 这 66 行里，人物一律称「她」「右前方」，不再出现任何名字。读者在 `:11` 已把「赵问竹」这个名字绑在这个背影上，`:13` 的反驳被读成「我想多了」，而不是「此人非赵问竹」——因为 `:13` 反对的是「看见了她本人」，不是「这个背影是赵问竹」。**这是全书最精妙的一处语法歧义：否定的是「看见本人」，不是「身份判断」。**

上轮审稿人被骗成「董佳好＝赵问竹」，正是从 `:11` 到 `:77` 这 66 行里没有第二个名字可用。

### 1.2 结论：判断成立，但 09 号报告的理由不成立

09 号报告写：「整章 2 处对话、8,004 字，其余是『她好像……』……不可靠叙述需要读者手上有第二个数据源。」

**这句话与文本不符。这一章有第二个数据源，而且是全书最完整的一处。**

| 位置 | 第二数据源 |
|---|---|
| `:187-201` | 课堂上老师讲到年轻时喜欢的人，有人朝「我」看、有人笑；「她后来回忆，那时看见有人朝我笑，有人回头，她很疑惑。她原先并没有把我当作一个会有这样一段旧事的人。」——**同一事件的另一份证词** |
| `:217-247` | 「还有另一份记忆。」——整节是董佳好版本的 2023 年秋天：「她印象里的男生很瘦，坐得直，姿势端正，看起来认真得不得了；他坐在第三大组第二排，几乎不讲话。」 |
| `:225-239` | 叙述者逐条比对两份记忆：「她却给我找出一副坐得笔直的样子」「可她说的是认识我以前」「她看到的姿势不需要经过我批准才能成立」 |
| `:243` | 「我看了她的背影那么久，竟始终以为自己在观察另一个人。后来她说起我，给出的第一幅画面却是我的背影也罢、正面也罢，总之没有那么多我自己舍不得丢掉的故事。」 |

这不是「无对照的推测」，这是**双向的、结构对称的误认**：我看她，看错了；她看我，也看错了；两处误认都用对方的证词纠正。**比 09 号报告所认可的三种「有效」更完整。**

所以：**II-019 是全书最成功的不可靠叙述——结论对；「缺第二数据源」的理由错。**

### 1.3 但它有三处自我拆解

成功的机关被三句话自己解释掉了：

| 行 | 原文 | 后果 |
|---|---|---|
| `:79` | 「回忆就很容易犯一种懒」 | 把机制命名。读者从此知道自己在读一份被事后污染的回忆——**机关从暗箱变成说明书** |
| `:207` | 「我还想过，若她知道我初次见她时觉得她像赵问竹，会怎样说。」 | 把「误认」这一事实直接说出来。此句之后，任何读者都不会再被骗第二次 |
| `:271-275` | 「几年后，在四川大学的教室里，我也曾望着一个并不认识的女生的背影，想起赵问竹。……我知道自己见过这种情形」 | 第三次重复同一动作，并说明「我知道」——把母题讲成了定理 |

**代价**：`:11—:77` 的 66 行陷阱只对第一次阅读有效，且只对读得快的人有效；读到 `:207` 时，机关已完全解除。这不是失败，是**一次性装置**——它牺牲了重读价值，换取第一次阅读时的真实误认。

**判断**：保留。但 `:207` 建议删（它是唯一一处纯粹的「说破」，`:79` 与 `:271` 尚有情节功能）。

## 三、六类机制

### M1 记忆偏差·有物证（可裁决）

**特征**：错误被外部证据（照片、文件、他人记录）推翻，且证据在文本内出现。

**唯一完整案例**：`V2-021`。它的链条是完整的六步——

1. 陈述（`:5`）：四二五，且给出床的位置、上下铺、洗漱动线。
2. 纠正（`:9`）：电话里对方说四二六。
3. 抵抗（`:9`）：「我说门牌我进出一年，不会看错。」
4. 物证（`:13`）：「照片来了，门上的数字我放大了看。四二六。六的那一笔在灯下有点糊，可不是五。」
5. 合理化尝试（`:15`）：「也许是我把隔壁那一间记成了自己的；也许别人说的是另一年。」
6. 命题（`:17`）：「床在我脑子里，门牌在照片里。两样都是真的，它们不在同一个数字上。」

`:187` 的收束是全书对「记忆错误」最准确的表述：
> 「改正一个数字并不难。真正麻烦的是，把原先那间被我说得十分确定的屋子拆掉，仍然愿意相信自己在里面同别人一起过过日子。」

**这一类是「展示」，不是「欺骗」**——读者在读到之前并不知道门牌是几号，所以没有被骗，只是看着叙述者被骗。它的价值在可信度，不在悬念。

### M2 记忆偏差·无物证（不可裁决）

**特征**：两份证词都成立，文本明确拒绝裁决。

三个层次分明的样本：

| 样本 | 处理 | 判语 |
|---|---|---|
| `V3-012:195-223` 母亲说作文贴过墙 | 母亲给出高分辨率细节（「一整面墙」「找你的名字，找了半天」「贴在第一排的最上面」），「我」只能承认「连当年的公告栏分成几块都想不起来」。结尾不裁决：「是我记错了，还是她记多了。」 | **处理正确**。高分辨率细节＋低分辨率反方＝读者自己也会倾向母亲，但文本不替读者决定。 |
| `V3-001:211` 相机是谁的 | 「我妈说，是外公借的。外公说，是单位同事的。两个人说法不一样，这件事就这样放着了。」 | **处理正确**，但只有一句，机制未展开。 |
| `V4-017:7-13` 朱学良站第三排 | 叙述者先想纠正，再自我驳回：「我若因此宣布自己比他更懂得那年毕业，反倒是另一种糊涂。」 | **处理正确且升格**：把「记忆之争」转成「谁有资格替别人记住」的伦理问题。 |

**这一类是本书最成熟的不可靠叙述**：它不制造悬念，制造的是**认识论上的礼貌**——承认别人可以记得不一样。

### M3 他人转述当作亲历

**特征**：叙述者描述自己不在场的场景，细节饱满，读者读作亲历；随后（或同段）自标这是转述或推断。

| 位置 | 补出的细节 | 自标 |
|---|---|---|
| `V3-002:7` | 「她带了一对香、几个橘子。车到山脚，石阶就开始了。台阶窄，中间凹下去，雨天会积水，那天是干的。她走一段，停一段。停的时候把橘子换一只手，手腕上勒出一道红。」 | 同段：「她后来不说膝盖。她上楼要歇一歇，**那是我看出来的，不是她那天讲的**。」 |
| `V2-019:221` | 「很瘦，坐得直，姿势端正……第三大组第二排，几乎不讲话」 | 前置标注：「多年后，董佳好讲起……」 |
| `V2-009:13` | 2002 年河水上涨时一村人的反应 | 前置标注：「父亲后来把理由写得很清楚」 |

**这一类里 `V3-002:7` 是范本**：它先让读者看见奶奶爬石阶，再在第四句坦白「膝盖是我看出来的」。**坦白的位置极准——在读者已经形成画面之后，而不是之前。**

### M4 时序错置

| 位置 | 错置内容 | 纠正方式 |
|---|---|---|
| `V1-014:3` | 把「橘子洲烟花夜」（`V1-013`）与「期中考试后另一晚」并成一晚 | 章首第一句直接分开：「那不是橘子洲放烟花的晚上……可它们不是同一件事。」 |
| `V1-008:3` | 「两周」的起点 | 「究竟从哪一次换座开始，我已经说不清了。」 |
| `V7-015:255-265` | 记忆中「上山」的照片实际是「下来以后」 | 不纠正照片，纠正**记忆的形成过程**：「重建出来的版本，会慢慢变成我以后『记得』的版本。」 |

`V1-014:3` 是**结构性纠错**：它纠正的不是叙述者，是**读者**。读者刚在 `V1-013` 结尾被「光从窗户退到门口」那段弄糊了，`V1-014` 第一句就告诉他：你刚才把两晚并成了一晚。这是全书唯一一处「读者的错误被明确命名」的开头。

### M5 自我美化

| 位置 | 美化 | 拆解 |
|---|---|---|
| `V1-002:273-275` | 把父亲写成缺席者 | 「我已经在他回答之前，安排好一个没有同行的父亲。」 |
| `V7-004:183-197` | 把「总裁气质」当好话收下 | 「实际上说的是一个人在倒下以后还试图替站着的人做决定。」 |
| `V2-019:195,213` | 想被注意 | 「想被人注意，是一回事；被人拿自己讲过又不愿意讲完的事注意，是另一回事。」＋「我不肯承受别人对它同样的好奇，倒很像我平日最熟悉的那种双重标准。」 |

**共性是「不需要旁白」**：三处都由一个具体场景自己翻转，叙述者只在最后补一句判语。这是本书最稳定的手法。

### M6 物件改造

只有一处，但它是全书结构上的支点：`V7-015:27-55`。读者看着叙述者裁照片、改文件名、拒绝覆盖、存成两份。**自欺被做成了可见动作**，且保留了物证（`":53` 于是同一个画面有了两份"）。这一处与 `V3-002` 的双版本证词构成同构：**两个版本都留着，谁也没删。**

### M7 未标记复制（无效）

**特征**：同一材料出现两次，文本不承认这是两次，读者只能归因为作者写重了。

三例见上表 #20-22。它们的共同点是：**机制本来可以成立，但没有标记**。
- `V2-008:103/:141`——若加一句「这话她说过两回，我两次都当成新的」，立刻变成有效的记忆重复。
- `V2-018:193`／`V4-012:117`——若确认是同一老师的同一句评语，须改写；若是巧合，须让叙述者注意到巧合。

## 四、有效／无效的分界（三条判据）

| 判据 | 有效 | 无效 |
|---|---|---|
| **① 是否有第二数据源** | 人证（`V2-019:187`）、物证（`V2-021:13`）、另一时间层（`V1-014:3`） | 无。读者手上只有一份材料 |
| **② 差异是否被命名** | 「奶奶的版本里，她是做主的人」（`V3-002:161`）；「床在我脑子里，门牌在照片里」（`V2-021:17`） | 只有重复，没有命名 |
| **③ 揭示是否在读者已判断之后** | `V2-019`：判断在 `:11`，揭示在 `:77` | `V3-013:393`「也许我记错了」：判断尚未形成，揭示已到，等于没有 |

**三条全中 = 有效；缺 ① 或 ② = 无效含混；缺 ③ = 弱效（不构成误导，只是自谦）。**

- **有效 16 处**（#1-17 中除 #16 半有效外）

- **无效 5 处**（#19 `V3-013:393`、#20-22 三处 M7、#18 弱）

### 5.2 易被误判为「有效」的两处（须防）

1. **`V2-019:207`**——「若她知道我初次见她时觉得她像赵问竹」。这句看起来是深化，实际是**把机关说破**。它之后，`:11` 的陷阱永久失效。若下一轮要「加强不可靠叙述」，最该删的就是这一句。
2. **`V6-020:95`**——「有人提一桩自己记得很清楚的事，坐在旁边的人却说你记错了」。这是**总结陈词式**的处理：把全书反复出现的记忆争执，在最后一章归纳成一句家常话。它读起来温暖，但它**替读者结算了**——读者不必自己发现「每个人记得不一样」，因为叙述者已经说了。

## 六、全书形状

把 22 处按卷排列，得到一个清晰的曲线：

```
V1 ████░░░░░░  4 处（时序错置 2、自我美化 1、物证 1）——以「纠正读者」为主
V2 ██████████  8 处（身份误认 1、门牌 1、双证词 2、记忆争执 2、复制 1、空间 1）——最密
V3 ██████░░░░  5 处（补细节自标 1、双证词 1、无物证 1、弱自疑 1、复制 1）——最成熟
V4 ██░░░░░░░░  2 处（他人记忆 1、复制 1）
V5 █░░░░░░░░░  1 处（记忆争执，未裁决）
V6 █░░░░░░░░░  1 处（集体记忆，总结式）
V7 ██████░░░░  5 处（评价反驳 1、物件改造 1、记忆与文件 1、…）——最自觉
```

**三个判断**：

1. **V2 最密，V3 最成熟，V7 最自觉。** V2 靠数量（八处），V3 靠质量（`V3-002:7` 的同段自标、`V3-012:223` 的拒绝裁决），V7 靠命名（`V7-015:265` 把全书机制写成了句子）。
2. **V4-V6 是低谷。** 这三年（初中、高二下、高三）几乎没有不可靠叙述，只有零散的记忆争执。这与 `09` 号报告的「Ⅳ-Ⅶ 顺流，不再回跳」一致：**顺流段落不需要不可靠叙述，因为读者没有需要被纠正的先前判断。**
3. **全书没有一处「恶意的不可靠」。** 所有误导都指向「我」自己，没有一处是叙述者故意骗读者以获取同情。这是本书的道德底线，也是它比一般「不可靠叙述」小说更温和的原因。
