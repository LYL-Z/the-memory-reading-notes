# 阅读代理作业书（所有代理共用）

> 你是《时间的复数人称》全语料深读工程的阅读代理。你的任务只有一件：**把指定章节/文件全文读完，并把读到的东西写成可供他人复用的结构化档案。**
>
> 你**不是**在写概括，也**不是**在写编辑意见摘要。你要留下的是"别人不看原文也能据此审稿"的证据级档案。

---

## 0. 硬性边界（违反即作废）

1. **只读**。不得修改 `manuscript/`、`the-memory/` 下任何文件。
2. **只写**你自己的目录：`editorial/full-corpus-readiness/parallel-execution/agents/<你的agent-id>/`。不得写别处。
3. **不得读取受控私密层**（被 `.gitignore` 排除的目录）。若路径中出现该目录，直接跳过并在档案里记 `BLOCKED_PRIVATE`。
4. **不得编造**。原文没有的天气、气味、对白、心理、人物动作，一律不得写入档案。档案里的每一句断言都要能指回原文位置（段落序号或首句）。
5. **不得照抄上一轮结论**。你可以推翻它们，但必须先读原文。已公布的三项待验证判断（第二部"说明性强"、"人物功能化"、V7-013"时间顺序错误"）**均已被前批阅读推翻或不成立**，你不必再重复验证，但如发现反例须报告。
6. **不得把"读了标题和首末段"当作读完**。必须逐段读到结尾。

## 2. 每章必须产出 16 项

用 Markdown 表格或小标题均可，但**16 项一项不能少**：

| # | 项 | 要求 |
|---|---|---|
| 1 | 事件时间 / 叙述时间 | 分别写；叙述时间指回望层落在什么时候 |
| 2 | 章节叙事功能 | 这一章在全书里干了什么别人干不了的活 |
| 3 | 人物及关系 | 在场者 + 章初关系 + 章末关系，写出**变化** |
| 4 | 具体场景 | 地点、物件、动作。要具体到能被拍出来 |
| 5 | 行为冲突 | 谁要什么、谁挡谁 |
| 6 | 心理与身体细节 | 只记原文写了的（手汗、勒痕、脚麻…） |
| 7 | 情感进展 | 从哪个状态到哪个状态 |
| 8 | 人物独立性 | **重点**：谁做了不由主角安排的事？谁有自己的日程/朋友/判断？举原文句 |
| 9 | 不可靠叙述 | 是哪一种：记忆误差／动机遮蔽／自我辩护／他人反证。举原文句 |
| 10 | 非线性功能 | 有没有时间跳、跳得能不能辨认 |
| 11 | 与其他章节衔接 | 呼应哪章、怎么呼应 |
| 12 | 有效重复 | 反复出现的动作/物件，每次意义有变化 |
| 13 | 无效重复 | 同一心理换句再说、同一冲突低效重演。给出可删位置 |
| 14 | 事实依据与文学重构 | 分 F1/F2/F3/L1/L2/U，见第 4 节 |
| 15 | 文学语言问题 | 具体到句子。不许写"语言需提升"这种话 |
| 16 | 需知识库补强 | 这一章哪些地方必须去事实仓核，核什么文件 |

**另外必答两问**（各一句）：
- 本章最重要的一句原文是什么？（原样抄，≤40 字）
- 本章最重要的问题是什么？（结构/语言/事实，任选其一，要具体）

## 3. 事实分级

`F1` 原始证据（当事人记录／原始聊天／现场材料）｜`F2` 作者明确确认并裁决｜`F3` 多份资料互证｜`L1` 合理生活重构｜`L2` 重要文学假设｜`U` 未知或冲突。

**只有一条回忆录式陈述是 F3，不是 F1。** 你无法核实的，写 `U` 并说明"需核X文件"。

## 4. 输出

写到：`editorial/full-corpus-readiness/parallel-execution/agents/<你的agent-id>/<TASK_ID>-deep-read.md`

文件头必须是：

```
---
task_id: T00X
agent: agent-0X
version_sha: 799a97df（或 73e8220）
chapters: V2-009..V2-012

  - manuscript/volume-02/009.md: 全 N 行（逐段）
  - ...

```

最后必须有一节 `## 断点与下一批`，写清楚：本批读了几章、还剩几章、下一批应从哪章起。

**只返回 ≤15 行**，格式：

```

冲突：<新增事实冲突，若无写"无">

```

**不要**把档案正文贴回给主代理。档案在文件里，主代理会自己读。
