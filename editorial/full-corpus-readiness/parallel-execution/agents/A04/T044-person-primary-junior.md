# T044 小学与初中同学人物档案（证据级）

## 0. 边界、口径与一条纠错

### 0.1 硬边界

- 事实仓 `D:/The Memory/The Memory` **全程只读**，未写入、未改名、未移动任何文件。
- **未读** `私人资料/`、`隐私/`。凡素材页指向「（私密原始材料未公开）」处，本档案只记「存在该材料」，不推断其内容。
- 未使用任何联网核验结论替代仓内陈述；仓内标注【实证·联网核验】者，本档案一律降记为 F3 并注明来源性质。
- 本文所有引文均标出「文件 → 小节/题号/行」定位。凡不能定位者，不写。

### 0.2 事实分级口径（依 `FACT-LEVEL-RULING.md`，强制）

| 本档案用法 | 对应形态 |
|---|---|
| **F1** | 可回原件：合影名单逐字转录、奖状实物转录、朋友圈截图逐字转录、名单文件截图 |
| **F2** | 当事人本人第一人称原话（问卷逐字、本人手写评价、本人当场口述整理稿）；**内容若为多年后回忆，标注「F2-回忆层」** |
| **F3** | 他人转述、人物页整理、索引页、单条回忆录式陈述、用户对第三方的概括 |
| **L1** | 合理生活重构（正文中的动作、对白）——**不得回填为事实** |
| **L2** | 重要文学假设（关系走向、心理替代、梦境） |
| **U** | 孤证或来源不明，须显式「待核」 |

三条自加约束：

1. **小说正文一律不充当事实证据。** 凡引自 `manuscript/` 者，标 `L1`，且只用于「正文利用现状」字段，不进入「已确认经历」。
2. **他人问卷 ≤ F3**；本人问卷 ≤ F2。二者不可混用同一等级。
3. 「人物页说某人如何」是 **F3**，即使该页写得很确定。

### 0.3 `CROSS_STAGE` 两种含义，本档案分开标

> 这是本任务最容易出错的地方，先立定义。

- **`CROSS_STAGE-A`（同校同学段连续）**：与主角在**同一所学校**跨两个及以上学段。本次 0 人。
- **`CROSS_STAGE-B`（人物被跨学段记录）**：该人物自身在小学/初中/高中/大学各段均有材料，且与主角的关系线跨段延续。本次 12 人。
- **`CROSS_STAGE-C`（跨段再现，仅单点）**：只在一个时间点（如一条评论）跨段出现，无连续材料。本次 3 人。

**重要否定结论**：`赵问竹` 属 `CROSS_STAGE-B`，但**不是**主角的小学或初中同学。她小学在**湘潭县百花学校**、初中在**青竹湖湘一外国语学校（长沙开福区）**，与主角小学（益阳实验小学）、初中（金海中学，雨花区）**无同校记录**。两人第一次同校是 2022 年麓山国际高一。凡把她说成「小学同学」「青梅竹马」的写法，均无材料支持。

### 0.4 一条必须写进档的纠错

上一轮有代理据「本人留下文字少」断言某核心人物「没有独立声音」，并把小说中其主动行为判为 L2。**本条纠错在本批 16 份档案中反复得到反证，故置于正文之前：**

| 反例 | 本人第一人称材料 | 他者观察到的主动行为 | 正文是否已表现独立性 |
|---|---|---|---|
| **夏恺宪** | **0 份**（全库无一句本人原话） | 3 次主动到场／发言（2018 生日照、2023 生日宴偕母出席、2025 生日评论「二弟生日快乐」） | 是（V2-020 明写「不一定谁说话最管用」） |
| **孙思玥** | **0 份**（全部来自朱学良转述） | 晚自习与朱学良讲话被抓、罚站；月考出分「最淡定」；常与「彭」同处 | 部分（V2-022、V4-004） |
| **朱学良** | 1 份 56 题问卷（F2） | 主动注意到主角名次、邀其到家、生日宴上「不照我的意思讲」、中途被叫走 | 是（V4-013 全章以此为核心） |
| **王培森** | 1 份 57 题问卷（F2） | 垫草稿纸、追上来说「你别理他们」、门口等、劝「别总拿出来给别人看」 | 是（V3-010／011） |

**结论（供主代理引用）**：

1. 「本人第一人称材料少」只说明**素材形态**，不构成「此人在故事里没有独立性」的推论。
2. 「他人观察到的主动行为」是独立证据源，等级为 F3，**不等于弱证据**；它证明的是行为，不是动机。
3. 「小说未表现人物独立性」与文本不符：V3-010、V3-011、V4-013 三处都写了不由主角安排的动作与判断。
4. 正确表述应为：**「该人物本人材料薄」**（对素材的描述），而非**「该人物功能化」**（对正文的批评）。两者不可互换。
