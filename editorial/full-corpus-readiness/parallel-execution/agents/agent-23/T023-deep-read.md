### 6.2 五章的共性结构（一条可复用的编辑线索）

五章共享**同一个四拍子**，且这是第五部的骨架：

1. 我带着一套**方法**进场（条件要写全 / 计划要合理 / 规则要先定 / 路线要最优 / 题目要唯一解）；
2. 场景里有一个**不配合的人**（男生坐回去 / 同桌「先把卷子放对地方」/ 睡觉的同学 / 舅舅「先别急」/ 侧身朝墙敲床板）；
3. 我用**解释**试图挽回（「这不科学」/「这两种晚睡完全不同」/「那怎么叫小组讨论」/「路又不是我一个人在走」/「猜到了也不等于唯一答案」）；
4. 解释被**一个动作**截断（老师走去后排 / 上课铃 / 他回座位 / 母亲叫我放手机 / 寝室长「讲完睡」）。

四拍子本身极稳。**风险在于第 3 拍**——五章里主角的辩解句式高度相似（都是「A 与 B 是两个不同问题，不能因为 B 做得不好就否定 A」）。若连续阅读，会感到同一句话说了五遍。建议在 011 或 014 中删掉一次完整的辩解，只留半个。
