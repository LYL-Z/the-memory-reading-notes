**性质判定**：这 21 条不是「编造事实」，是**把概括、判词、文学化转述放进了引号并挂上行号**。后果有两层：

**修法**：引号只留给逐字原文；自己的概括一律去引号，改为「据 `file:line`，大意是……」。这一条改起来是纯文字工作，但要**逐条过**。

## 3. 三类错误的逐类判定

### 3.1 把代理报告当一手证据 —— **未发现（0 例）**

```bash
grep -rn "cross-volume\|cross_volume" volume-*/     # 0
grep -rn '`volume-0[0-9]/V[0-9]' volume-*/          # 0
```

`_SUMMARY-V03/V05/V06` 与 `_STYLE-V06` 只作**交叉索引**（「详见 `_SUMMARY-V03.md` §一」），不作为事实来源。这一点做得干净。

**但有一个次级风险**：`V06-004:18`、`V06-005:18` 的顶针率引用 `_STYLE-V06.md`，而 `_STYLE-V06.md` 与这两章出自**同一代理、同一轮**。自我引用不算错，但不能当「独立复核」。

### 3.2 把「不知道」写成「不存在」 —— **基本没有，1 条口径需精确**

抽检 6 条零命中断言，逐条跑反例：

| `V01-003`「上交/手机管理」在 `高中` 零命中 | = **0** | 成立 |
| `V01-005`「女生宿舍/女寝」全库零命中 | = **0** | 成立 |

### 3.3 文学重构 vs 事实断言 —— **反向（把事实当重构）未发现；正向（把重构当事实）集中在引号层**

- 反向：抽查 V07-020、V06-004、V06-005，未见「事实仓明载却标 L1」的例子。
- 正向：见 §2.2 的 21 条——但注意，**问题不在结论，在证据形态**。例如 `V02-007` 说「我那时更喜欢做镜头里的主角」与事实仓「爱赢、爱被看见」一致——这个**判断本身站得住**（`刘佑林.md:142`「比较在意高低输赢得失」确实支持），坏只坏在它给了一个不存在的逐字引文。**判对、证伪**。
