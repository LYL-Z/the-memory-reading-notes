**性质判定**：这 13 条不是「编造事实」，是**把概括、判词、文学化转述放进了引号并挂上行号**。后果有两层：

1. **可复算性归零**——下一轮 `grep` 引号里的字会得到 0 命中，进而怀疑整份档案。
2. **个案有实质风险**：`V07-019:37` 把「用户聊天总结称」压缩成「修热学、线代、C」，二手来源被洗成一手陈述，这正好命中您点名要抓的第一类错（虽然来源不是代理报告，而是二手转述）。

**修法**：引号只留给逐字原文；自己的概括一律去引号，改为「据 `file:line`，大意是……」。这一条改起来是纯文字工作，但要**逐条过**。

### 2.3 一句要表扬的

`V07-020` 整章 17 条事件来源，15 条主动标 `L1/L2`，只有 2 条称 F3，且该 2 条可核（`赵文邦.md:101` Q30「总是玩关羽」属实）。**这是「宁可标虚构也不冒充事实」的正确做法**，建议作为其余章的模板。

## 3. 三类错误的逐类判定

### 3.1 把代理报告当一手证据 —— **未发现（0 例）**

```bash
grep -rn "cross-volume\|cross_volume" volume-*/     # 0
grep -rn '`volume-0[0-9]/V[0-9]' volume-*/          # 0
```

`_SUMMARY-V03/V05/V06` 与 `_STYLE-V06` 只作**交叉索引**（「详见 `_SUMMARY-V03.md` §一」），不作为事实来源。这一点做得干净。

**但有一个次级风险**：`V06-004:18`、`V06-005:18` 的顶针率引用 `_STYLE-V06.md`，而 `_STYLE-V06.md` 与这两章出自**同一代理、同一轮**。自我引用不算错，但不能当「独立复核」。

### 3.2 把「不知道」写成「不存在」 —— **基本没有，1 条口径需精确**

抽检 6 条零命中断言，逐条跑反例：

| `V01-003`「上交/手机管理」在 `高中` 零命中 | = **0** | 成立 |
| `V01-005`「女生宿舍/女寝」全库零命中 | = **0** | 成立 |

### 3.3 文学重构 vs 事实断言 —— **反向（把事实当重构）未发现；正向（把重构当事实）集中在引号层**

- 反向：抽查 V07-020、V06-004、V06-005，未见「事实仓明载却标 L1」的例子。
- 正向：见 §2.2 的 13 条——但注意，**问题不在结论，在证据形态**。例如 `V02-007` 说「我那时更喜欢做镜头里的主角」与事实仓「爱赢、爱被看见」一致——这个**判断本身站得住**（`刘佑林.md:142`「比较在意高低输赢得失」确实支持），坏只坏在它给了一个不存在的逐字引文。**判对、证伪**。

### 4.1 但在同一段「消歧文字」里抓到两个错

`V05-001:51` 原文：

> 本章同时出现「王麒皓」（**高一，G2209**）与后文「阿澈」（＝王麒睿，G2205）……**第五部又从不并置**。第五部 001 只出现王麒皓、不出现阿澈；**004 起只出现阿澈**。

**(b)「从不并置 / 004 起只出现阿澈」是假的。** 实测第五部：

```bash
cd manuscript/volume-05
grep -c "王麒皓" *.md   # 001:5、004:1
grep -c "阿澈"   *.md   # 004:2、005:8、009:24
```

`004.md:87`：「…我便想起**王麒皓**也干过类似的事，忍不住插一句…」
`004.md:37`：「前排有人叫**阿澈**，问下午那张英语卷…」
`004.md:130`：「旁边的**阿澈**笑得伏在桌面上…」

**同一章里，阿澈在现场做事，王麒皓在回忆里出现。** 这才是最该报警的情形——读者在同一页遇到两个音近的名字，一个在场、一个不在场，而文本不给任何提示说这是两个人。映射把「最危险的一章」写成了「安全的分配」，**结论方向反了**：它以为风险在 001，实际风险在 004。

## 5. 一个跨文件的计量冲突：顶针有两套尺子

台账 `10:195` 与 `T050` 的口径是「后句开头 2–4 字＝前句结尾」，得 **Ⅵ 37.5%、V6-018 71.3%**。

|---|---:|---:|---:|
| V6-018 | **71.8%** | **43.8%** | **28.0pp** |

**同一章可以是 71.3%，也可以是 43.8%，两个数都能「复算」。** 现在台账与映射各说各的，谁也没说明用的是哪把尺子。这不影响定性结论（Ⅵ 仍是断层，Ⅵ 之外仍 ≤3%），但**「71.3%」这个数字不能与「29.4%」并列引用**。

建议：把 `dingzhen.py` 定为唯一口径，回填台账的 37.5/71.3，或在台账注明「本数用 A10 判据，与 `dingzhen.py` 不可比」。
