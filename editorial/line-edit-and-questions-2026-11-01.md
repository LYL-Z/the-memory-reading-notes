# 《时间的复数人称》第一至四章第四轮行文精修与待核实问题

审稿身份与创作身份分离记录：这一轮不是“终审已通过”的声明，而是把读起来像审稿意见的句子，移回一个真实的人当时能看见、听见、感受到的东西里。日期和史料分歧仍留在三套钟。对象：Draft PR #1，`editorial/chapter04-20261101`；不触及知识库，不合并 main，不写第五章。

## 结构与文学判断

- **四章顺序保留**：江安大学寝室中的白杯→益阳茶桌与第三只杯→高一男寝525的一年→月考后回头写四人组。第三章先走到高一年末、第四章退回第一次月考后，是有意的叙事重访，不是年表错误；但第四章必须保留“第一次月考后”的清楚标记。
- **四个正在被看见的“我”**：大学室友面前的骄傲与闪躲、父母面前的争先与依恋、525男生面前的善谈与受众人推波助澜、四人组里喜欢负责也想受肯定的人。题名中的“复数人称”不能靠概念解释，应在这些矛盾的行动里自然成立。
- **当前文学结论**：开篇有真实物件和独特事件支撑，结构有条件成立；仍有口吻、虚构对白及情感主次问题。绝不许承诺“已经达到世界文学顶峰”或将前四章标作冻结。

## 本轮已落到正文的微修

1. **001《左边的位置》**：“刘总/总裁”一段改成室友间自然的称呼差异，削弱人物介绍式的解释；保留江安夜晚的等待、游戏失败与历史课悬念。汉字 **5,176→5,196**。
2. **002《晚饭后的桌子》**：第二口茶不再插进“我不打算把味道说成一种名字”这种写作现场的自白，让温度、迟咽与口感延迟承担情绪。汉字 **4,906→4,925**。父亲“太快就不算会”及这晚的杯子、钥匙、鞋拔是文学重构，仍须核验生活气质，不能变成他真实逐字名言。
3. **003《525》**：宿舍门牌补足门的具体所在；传言扩散由“我没有一个一个去问”的防御性自证，改为我经过男生座位时听见笑声的心虚。递纸与正式演出是否同晚写成单一清楚的未知，而非先说“另一回”再反悔。尤其：**撤回没有口述证据的“赵问竹主动想看”动作**，保留我未给她看。此前已校正的室内两洗手台/两淋浴间、楼层洗衣房、男女寝不同栋事实保持不动。汉字 **9,885→9,985**。
4. **004《月考之后》**：结尾原有“喻翰东不是为了接话、伍筱丹不是专门指出错误”等评论有些像论文论点；改让组员接玩笑、改题、从讲台回桌面，以及组长不会做题时怕被看见，共同构成差异。汉字 **6,183→6,232**。该章大段讲题对白、分组当天搬书细节皆是小说合理重构，而非可从知识库逐句确认的历史现场。

**计数**：四章由 **26,150→26,338** 汉字，分别净增 **20、19、100、49**，没有任何一章净减。对模糊与不实归因的替换是局部的，并非删除已核实亲历事件。

## 还不能文学冻结的四件事：请作者按记忆回答

**A｜第三章《竹林杯》**：她（赵问竹）当时是否真的主动提出“给我看看”这张纸？你确信她在旁边听到、看到过什么，还是你只是担心她会知道？此前正文写了她想看，证据不足，本轮暂收回；如果这确是你记得的动作，可重新写进成文。

**B｜第四章四人组**：第一次月考后初成组时，赵问竹、喻翰东、伍筱丹的真实语言风格分别是什么样？例如赵问竹早期是否经常直截了当地追问解题步骤，还是熟了之后才会这样；伍筱丹说话直接吗；喻翰东开玩笑是否像稿中那样？请优先指出**一个最不像的句子或人**，不必逐段批注。

**C｜第二章茶桌**：父亲确实说过“加油，相信你能行”，但“太快就不算会”“喝就是了”等是作者代拟的对白。这些像你父亲平日会说的话吗？一家人在茶桌是坐谈、品茶，还是有更特定的顺序与口头禅？如果不像，给一两句真话即可修整全章。

**D｜第三章525的集体气氛**：在“你喜欢赵问竹”传遍隔壁、对面寝室时，你记得一件**最能体现八个人不同性格**的真实小动作、绰号或者互相调侃吗？提供一个有场景的片段，就能替换掉一段现在偏概述性的传言描述。

这些问题旨在补足特定的真声音，不是对小说删减想象力。作者记不清的保留不确定，不从他人的眼神或一份评价中推导双向爱情。

## 下轮文学设计建议

- **001/002**：给人物说话留空，不再另加人为的金句；左边书架、茶桌的第三只杯子已经足以组织意义。读者应先感到“我想留在这里”，再自行读出“我求陪伴”的意义。
- **003**：本章长是合理的，最难的是让525八人各有不同需要。下一轮扩写的前提是作者给出有根的寝室互动，不可为了达到超长而虚构室友具体说过的私人话。竹林杯录像作为传播媒介是独特的文学装置，保持“纸被改变意义／录像被剪辑传播”的对照，不过度点破。
- **004**：赵问竹首先是一名认真负责的班长和独立的学习者，其次才是叙述者眼里的情感重点。她高一上与作者并不太熟，避免写出春季才有的亲密。其亲笔评价的确证明她注意过他的优点与不足，**并不证明喜欢他**。她的问、忙、静，优先靠小事件显出，不靠“最美”“温柔”等空泛形容。
- **全书**：坚持历史课原话在第一部后段才揭晓；具体中考分数与后来的笔记本/联系状况继续延后。文学修订的判断标准应是对话能听见人物、场面有人在做事、前后章伏笔不抢答，而不是排比有多少、箴言有多少。

**决定**：四章继续未冻结。A—D至少校准会显著改变情节的A与人物口吻的B，才能做真正的重场面精修；下一轮仍先改这四章，不启动第五章。


## 2026-11-01 作者已回复 A—D：前轮问题处理结果

- **A 已确认**：赵问竹第一时间主动想看《竹林杯》纸张。第四轮为了防止擅自赋予她索纸行动而撤销的句子，在本轮根据口述恢复，并扩展“竹+林”、作者不敢给看及后续误会的心理线；仍不写她已接受/拒绝某段感情，也不伪造转述路径。
- **B 已确认**：赵问竹正事直接、熟后温柔玩笑；喻翰东幽默开放、爱分享、不拘规矩；伍筱丹直接火辣。第五轮已据此精修004，具体新场面和语句仍属小说化重构。
- **C 已确认**：小时候父亲的严谨与人生经验令作者敬服；高三、大学后家中谈话逐渐更能平等争论；第二章以成年回望分开两种时间，不贬损父亲衰老，保留他严肃时的话语分量。
- **D 已确认并审慎处理**：交接作业引发的短暂身体接触与回寝起哄。第三章只写少年在作业本上的手指片刻、叙述者自己当晚向室友讲述以及群体玩笑的失礼一面；不在公开文学稿逐字重述当时针对未成年人的性化粗俗猜测，亦不称此为赵问竹的意愿。

**开放问题**：竹林杯误会究竟由谁怎样转述、她本人听见了什么及当时的实际反应，仍须更多可靠口述才能进一步具体化；作者明确“没给她看”不等于她不知道或喜欢。第三章扩写不锁定递纸与正式舞蹈在同夜。前四章均未冻结，005不启动。


## 第六轮追加口述：纠正第五轮关于纸与流言的过早因果

- **纸在教室的确切顺序**：汪在晚二铃响递给刘；刘先看、给喻翰东看原版；刘改竹为草；赵问竹笑着主动索纸、伸手，被刘笑着挡住（有手臂接触）；刘将改版交身后伍筱丹，刘伍相视而笑。第五轮旧稿中“赵刚收到纸就要看、喻所见版本不明”均已撤回。
- **流言的得知时刻**：直至高二上，刘才听汪智文转述女生宿舍里曾有严重失实传言。原指称涉及现实第三人且无法独立核验，**不能作为已经证实的“某人恶意造谣”写入公开小说**；不刊载原话和实名指控。刘的愤怒与对同学小圈子、嫉妒和干涉的理解可以作为主观叙事写出。
- **对关系的影响**：纸的误会在高一当时未直接影响刘、赵相处；高一下末另有事件累积导致变化，这些事件尚待作者提供。第五轮“传谣→立刻疏远”的暗示被纠正。赵问竹的信任是作者的回忆判断，不可升格为对她全部内心的客观确证。
- **文学任务**：使读者记得“纸只拐了一个弯，事情却隔了一年才传到他耳里”的时间错位；003可设高二上短暂回望，随后返回525演出。004微补她对同学热闹的好奇，与公事认真、熟后玩笑相容。

**状态**：前四章未冻结；不写005。下一轮追问事实缺口而非催写阴谋人物。
