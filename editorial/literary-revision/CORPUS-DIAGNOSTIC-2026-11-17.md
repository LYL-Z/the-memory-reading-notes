**两条必须纠正的旧判断**：

1. 「Ⅵ-018 是全书唯一一次链断」**不成立**。Ⅵ-018 的连接率是全书最高（39.2%），不是最低。若它表达「断」，那断的是内容，不是句式。旧稿把「连接率低」当成艺术成绩，方向反了。
2. 「顶针是全书文体装置」**不成立**。它是**第六部单卷装置**。这既可能是刻意（高三＝机器式重复），也可能是失控（同一句式连续 20 章）。**必须逐章判定，不能整卷统一处理**——整卷统一降率会抹掉可能存在的设计。

## 五、复算脚本

```python
import io,re,glob
def m(t):
    s=[x for x in re.split(r'(?<=[。！？…])',t) if len(re.findall(r'[\u4e00-\u9fff]',x))>=4]
    tl=lambda x:''.join(re.findall(r'[\u4e00-\u9fff]',x)[-2:])
    hd=lambda x:''.join(re.findall(r'[\u4e00-\u9fff]',x)[:2])
    p=len(s)-1; link=[i for i in range(p) if tl(s[i])==hd(s[i+1])]
    return 100*len(link)/p if p>0 else 0
```
（连接率＝相邻句对中「前句末 2 汉字 == 后句首 2 汉字」的比例。另一指标「参与句占比」单列，不与本表同表比较。）
