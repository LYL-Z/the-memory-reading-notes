# 讨嫌

最先使我注意到朱学良的，不是吵。

是他对一件我看得很郑重的事，可以很轻易地放过去。

那天几个人围着一张桌子说题。谁先拿来的练习册我不记得了。桌上有几支笔，压着一块橡皮，题算到一半，旁边有人忽然报了个答案。我觉得不对，把本子拿近，指着前面一个条件讲。朱学良站在旁边，听了一会儿，伸手把题翻过去，手指在桌沿上敲了两下，似乎另有事情要去做。

“你看完没？”我问。

他说看完了。

“那这个怎么算？”

他又看了一眼，说你慢慢算呗。

这句话落在我耳朵里，多少有点不尊重数学。我已经把解法拆开，正准备告诉他为什么第一种答案错，他却要走，好像题会自己长出结果。我催他别动，他回头看着我，表情不见得有多耐烦。

“要上课了。”

我朝门口看去，走廊里确实有人往回跑。他把椅子往后一推，本子推还给我，说下回再讲。旁边一个同学探过头看了眼那道题，又缩回去，说了句“下节课问也一样”，跟着往门口走。

我又要说什么，上课铃已经响了。那句准备好的解释留在我嗓子里，直到老师进来才彻底咽下去。我坐回去，把他没听完的那部分写在草稿纸上，算给自己看。答案很清楚。我有点得意，又有点没意思：题对了，原先那个听的人早不在桌边——后来我才知道，他那是赶着去操场拿球。那道题我后来又做过一遍，用的是他没听完的那种解法。做对了。纸上多出来的步骤，没有第二个人看过。

这样的事，隔几年由我自己回忆，很容易写成“我认真，朱学良活泼”。两个词就完了，连谁当时真正要干什么都省掉。可他离开那张桌子，确实因为铃响了；我留在那儿不肯停，也未必全是为了求知。我们谁也没专门想伤害谁，却已经在对方眼里显得有点不耐烦。

后来他说一句笑话，我常不知道该不该接。

朱学良有熟人。课间他能从这排走到那排，和前面的人聊刚才一道题，转头又同另一个人商量体育课打不打球。有些人隔得远，照样喊他。他不必先向我解释自己同谁关系近，也不会因为刚刚站在我桌边，就把下一个课间分给我。

我那时候刚从益阳来，自认也不是一个不会同人打交道的孩子。小学有自己的朋友，有人听我讲电影，也有人同我玩角色扮演。我喜欢主持，喜欢把一件事情安排得周全，若是熟人愿意听，我能讲出一大套。到了金海，却不能轻易把原来那些人的位置安排给谁。那群人各自早有事情，谁也没空等一位从益阳来的学生慢慢熟起来。

最初我有点羡慕朱学良。

后来他自己说，那时候“比较想出头，就喜欢上去展示”。物理课上老师问谁来做，他举手，粉笔在黑板上走，做到中间一步画岔了，底下有人笑，他也笑，下来还跟旁边的人比划那一步是怎么想歪的，说完就跑出去打球。我把那道题抄回草稿本，从头做了一遍，他画岔的那一步，我一次就写对了。写完我看着那行字，倒没有多高兴：题做对了，和站到黑板前面去，本来就是两回事。我看着他被叫到、答完、坐下，心里不大舒服：觉得自己也会，甚至能讲得更全。可不舒服归不舒服，我还是没有举。

我不太肯承认这点羡慕。

所以当他又在旁边说笑、又把我的一句正经话轻轻带过去时，我很容易把不舒服说成一句“你好讨嫌”。

这是我比较擅长的说法。它不需要认真讲理由，也不算真的骂人。说完如果对方笑，我就跟着笑；如果他问哪里讨嫌，我又可以摆出认真讨论的架势，逐条证明他刚才有多少地方没想周全。

朱学良似乎不太把这样的证明当回事。

我只记得他有时候会把话接回去，有时干脆去做别的事。一个人对自己正在干什么有兴趣，未必必须同另一个人辩到底。

有一次课间，我在写一道历史题，旁边有人聊起刚讲过的一件史事。他们的说法有个小地方不准确，我听得出来，却没马上插话。那时朱学良正和他们站在一起。他回头看我一眼，问：“你是不是又有意见？”

我说当然有意见。

“那你说。”

我本来还犹豫，听见这样一句邀请，反而立刻来了劲。我把课本翻过去，找到年代，又找了一句能证明前后因果的话，讲得很长。几个人听到中间便去做自己的事：一个去接水，一个低头翻自己的本子，还有人拍了拍朱学良的肩，先走了。朱学良倒还站着，隔一会儿问我一句。我以为他终于肯认真听，讲到更后面才发现，他问的有些东西并不是为了求解，纯粹想看看我还能讲多久。

我气笑了。

“你这个人怎么这么讨嫌？”

他也笑，问我这回又哪里讨嫌。

我答不上来。刚才分明是自己讲得痛快，讲到后来还怕没有人听。被人这样绕了一圈，确实有些丢面子，却也未必真想让他走。

那天的细节是否完全如上，我现在说不准。可能是历史，也可能是政治；可能最先提问的另有其人。记忆里那种相处却十分清楚：我一本正经，他偏不肯配合我的郑重；我想让他承认我讲得有理，他却总能把气氛拉回课间。别人笑的时候，我一开始也许恼，过一会儿反而加入。

我们就这样逐渐能说上话。

有一次我把“讨嫌”说得比平时响。

那时旁边还有别人，我刚讲完一件自己很得意的事，朱学良接了一句玩笑。我当即反驳，声音抬得很高，又补上一句，你怎么这么讨嫌。几个人笑了，靠窗那个还笑出了声，笑完又赶紧低头装作在看窗外。我也笑，等着他回我一句更厉害的，好让我继续斗下去。

他却没有马上接。

他低头把本子合上，转身去另一边拿东西。只是这样一个很普通的动作，放在我的记忆里，却像有人提前结束了我预备好的一段对话。我追着问，怎么不说了？他答了句没什么，继续收自己的东西。我忽然不太有兴致，也装作去看本子，暗地里想刚才是不是说得太重。

我不肯轻易道歉。

在我们这些男生之间，互相说句讨嫌不算多严重。他要是真的不高兴，完全可以当场回我，凭什么叫我先认错？我把这一套理由在心里讲得很完整，讲完又忍不住往他那里看。几分钟以后，他走到另一张桌子边上，跟人说起中午那场球，语气已经很自然，我的解释却一个字也没说出去。

下一节课前，他从我座位旁边经过。

我本来准备问他刚才还气不气，临到嘴边改成一句，这题你算出来了吗。他看了看，问哪题。我把本子翻过去，指给他。他扫一眼，说等会儿再看。我很不满意，怎么又等会儿？可他已经走到前面，同别人商量另一件事。我只能把问题留着，等下一次再提。

后来那道题究竟有没有一起算完，我不记得了。

我只记得，有时候一声讨嫌说出去，别人可以接，也可以不接。我在这种小事上还没学会同对方商量，便已经先替自己准备好了十几条不必道歉的理由。真正让我们继续熟起来的，不是那些理由多么正确，而是第二天我仍敢去问他题，他也仍会叫我小林子。

有过这样一阵子：我已经不大想知道他每次课间到底去找谁了，见他从门前经过，仍会抬头看一眼。他也没有因为上回那句玩笑，就专门在全班面前向我解释。我们不像电影里的两个角色，争过一次，下一场便必须和好。我不高兴时照样不高兴；下回他来借一样东西，我也并非每次都愿意爽快地给。

有一回，他拿走了放在桌角的一支笔，用完才还。我接过来看了一眼，笔帽扣得不紧，忍不住说：“你下次借之前说一声。”

“我刚才不说了吗？”

“你拿了以后才说。”

他笑了一下，把笔帽替我扣紧，放回原来的地方。我本来还准备继续追究：究竟什么时候说才算征求同意？见他已经坐回去，手上还在翻自己的书，又觉得当场争这个毫无意思。等到下一次我从他那边拿橡皮，手伸出去一半，才想到要先问一句。

他说拿呗。

我拿了，也没谢谢得多么郑重。那时我们尚未正式坐到一张桌子上，已经开始借用彼此那些不太贵重、又各自十分在意的小东西。这样的日子不会留下某一次伟大和解的纪念照，只有笔帽、橡皮和下课铃反复换到另一边去。

真正的友情往往没给人安排一个正式的开始。没有谁站到讲台前宣布，现在我们两个不再互相讨嫌了。一天早晨，他从门口经过叫我一声，我答应；另一天，他坐到旁边，问我某科考得怎样。等到真的同桌，桌面中间隔着的那点距离，才给了我们许多新的争论机会。

同桌前，我喜欢把本子一摞一摞放好。

有一回他要在中间借个地方，把自己书本往我这边挪。我看见草稿纸被压住，伸手抽出来，说你往旁边放。他问旁边是哪边。我说你那边。他把书放回去，一会儿又为了拿东西伸过来，胳膊肘把我那摞本子碰歪了，又伸手给我推正。我先是不高兴，后来发现两个人用一张桌子，谁也不可能把自己的边界守成一堵墙。胳膊肘互相挨着，老师讲题时还得一起朝同一块黑板看。

他有时帮我递本子，我也会把错过的板书指给他看。

这些事越普通，越难在多年后单独拎出来。一次帮助不值得专门感谢，一次斗嘴也不必非得和解。下课铃响，我们照样站起来，去食堂或者去走廊，回来时两个人的椅子还在原来的位置。直到后来有人问，我们到底怎么熟的，我才发现自己找不出哪一个下午可以用作答案。

更奇怪的是，熟了以后，我说他讨嫌的机会未必变少。

他讲一件笑话，故意在最有意思的地方停住，我急着问后面呢。他说不讲了。我就说讨嫌。体育课后他兴致很好，拿刚才一个球说了半天：球从谁脚下过去，又在谁那里停住，他讲了三遍。我数着他重复的次数，听到第四遍，把草稿本合上，说讨嫌。他停下来看我一眼，笑了，接着往下讲。原来这两个字挡不住他，他只是换了个语气，继续讲他的球。连他真帮我做了点事，我有时也会嘴硬，先挑一处不够妥当。别人听见，若不了解前面那些日子，会以为我们一直相处不好。

朱学良却没有在那份回忆里说我们有过什么严重的矛盾。

我问他闹过矛盾没有，他答得有点犹疑：“没有吧应该。”我本来想把这个回答当作我们关系一直很好的证明。可就在同一张问卷上，被问到我们之间一件记得最清楚的事，他写的是——“你老是说我讨嫌”。原来在他那里，最先留下来的，竟是我嘴里的那两个字。没有严重争执，不妨碍一个人曾经觉得另一个人话多、认真得讨厌；两个人后来能坐一张桌子，也不会让那些小摩擦从来没有发生过。

他还有一句评价，尤其使我不大满意。

“直率，严肃，认真，有时却又有点幽默，比较有原则的一个人，基本上不咋和我一起搞事情。”

我首先看见的是前面几个好词。直率，严肃，认真，有原则。逐项读下来，感觉他差一点就在给我颁一张校内荣誉证书。我甚至想把那句话留到介绍主人公时用：这是另一个人眼中的刘佑林，有证人，有年份，写得还算客观。

直到后半句。

“基本上不咋和我一起搞事情。”

我把那半句又读了一次。为什么是不咋？我们同桌过，一起在教室里胡扯过，课间说笑过，我还去过他家。难道这些都不算“搞事情”？若换我自己作答，完全可以一口气讲出几件共同做过的小事，把友情写得比他那几个字热闹得多。我差点打开输入框，问他到底怎样才算搞事情。

手指停在屏幕上时，忽然想起当初自己也是这样。我说讨嫌，心里或许以为只是一句顺口的玩笑；他却把它记到多年以后。现在他说“不咋搞事情”，我又立即觉得他没给我们的相处打足分数。两个随手说话的人，谁也没打算每一句都填进对方的档案；轮到我来写书，却开始逐个字审核，连“基本上”都不肯轻易放过。

于是我继续往下读。

有一年我问他：如果十九岁的我请你实事求是说一句话，你最想说什么。

他答：“我长的真帅吧。”

我愣住，忍不住笑。

前面已经问过几十个班级细节、人物关系、考试和毕业，到这里他忽然不谈我了，先把自己夸了一遍。那句笑话不用我替他补心理过程，也不必解释是故意岔开话题还是确实觉得自己帅。我能想象他一边填表一边想，最后丢出这句话，仿佛对我这种严肃的发问已经很熟悉，知道总要留一点地方，别让所有答案都像考卷那样庄重。

我还在笑，光标已经停到下一道题。

屏幕上那行“不咋和我一起搞事情”仍在。我原本要问他的几个反驳，反而没那么急着发出去了。现在就让他说一句自己帅，又有什么关系？那个人从前在1907会被我叫讨嫌，如今也有自己的话，想怎么接便怎么接。

我把手机扣在桌上，起身去接水。走过走廊时，楼下操场上有几个人在打球，球撞在地上的声音一下一下传上来。我站了一会儿，没有下去。水接满了，我端着杯子回桌前，屏幕已经暗下去。那行字不再亮着，我也没有再把它翻出来。楼下那几个人还在打球，声音一直传到上课铃响。

等下回真见面，我估计还是要问他，当年到底是哪一次觉得我讨嫌。不过他要是回一句“不记得了”，我也不能再把他的回答判成错题。

叙述者自身新增动作（非他人，仍属 L1 叙述层）：按他没听完的解法重做题、抄回草稿本重做、合上草稿本、起身接水、端杯回桌前。

**判断**：这些动作让配角拥有独立于主角的行为——他赶着去打球、他继续讲他的球、旁人各自做自己的事——正是「场面化」的核心；但必须诚实标为文学重构，不能声称没有新增，也不能当作真实经历引用。

### 刻意保留段落

- 「你是不是又有意见？」「那你说」「你这个人怎么这么讨嫌？」对白组（全章最生动场面）。
- 「那天的细节是否完全如上，我现在说不准。可能是历史，也可能是政治」——自我限定，处理无源场面的正面样本。
- 借笔对白：「你下次借之前说一声」「我刚才不说了吗？」「你拿了以后才说」「拿呗」。
- 「真正的友情往往没给人安排一个正式的开始」——主题句。
- 「有时候一声讨嫌说出去，别人可以接，也可以不接」以及「十几条不必道歉的理由」——自我诊断。
- Q31 评价原话、Q32「没有吧应该」、Q39「我长的真帅吧」——他人原话逐字保留，不替他补心理、不把「没有吧应该」写成双方共识。

### 三处前后对照

**对照一：开篇（元叙述框架 → 生活场面进入）**
```diff
-“你老是说我讨嫌。”
-朱学良把这句话写回来时，我盯着屏幕看了很久。
-他没有说我恨过他，也没说我们打过一架。前面问的是两个人从不熟到熟……他交来的就这六个字。
-我读完先笑了。再往下想，竟有一点不服气。老是？哪有老是……
-我想发消息反驳，又不知道该拿哪件事作证。
-第二天在教室门口遇见他。他喊小林子。我应了……这句是跟他学的。学完我自己也觉得空。
+最先使我注意到朱学良的，不是吵。
+是他对一件我看得很郑重的事，可以很轻易地放过去。
+那天几个人围着一张桌子说题。谁先拿来的练习册我不记得了。桌上有几支笔，压着一块橡皮……
```

**对照二：讲题桌边（概述＋追加解释 → 可见冲突、他人反应、后果）**
```diff
-他把本子推还给我，说下回再讲。
-我又要说什么，上课铃已经响了……题对了，原先那个听的人没在这里。
+我朝门口看去，走廊里确实有人往回跑。他把椅子往后一推，本子推还给我，说下回再讲。旁边一个同学探过头看了眼那道题，又缩回去，说了句“下节课问也一样”，跟着往门口走。
+……题对了，原先那个听的人早不在桌边——后来我才知道，他那是赶着去操场拿球。那道题我后来又做过一遍，用的是他没听完的那种解法。做对了。纸上多出来的步骤，没有第二个人看过。
```

**对照三：结尾（纯心理领悟 → 生活动作收束）**
```diff
-等下回真见面，我估计还是要问他，当年到底是哪一次觉得我讨嫌。不过他要是回一句“不记得了”，我也不能再把他的回答判成错题。
+我把手机扣在桌上，起身去接水。走过走廊时，楼下操场上有几个人在打球，球撞在地上的声音一下一下传上来。我站了一会儿，没有下去。水接满了，我端着杯子回桌前，屏幕已经暗下去。那行字不再亮着，我也没有再把它翻出来。楼下那几个人还在打球，声音一直传到上课铃响。
+
+等下回真见面，我估计还是要问他，当年到底是哪一次觉得我讨嫌。不过他要是回一句“不记得了”，我也不能再把他的回答判成错题。
```
