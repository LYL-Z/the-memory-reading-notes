# 第六部顶针句调制规程（V6-DINGZHEN-PROTOCOL）

> 适用：《时间的复数人称》第六部 20 章。R2 文学总修订·HY-A09。
> 核心不是"降低顶针率"，而是**按段落长度分区**：短链是文体，长链是故障。
> 判据写死在 §2，判例原文收在 §3，任何人可复算、可反驳。

六卷在 2% 以下，第六部 22.4%。这不是版本差异，是**装置差异**：第六部有一层"注意力过载"的叙述声，链子是它的语法；其他五卷没有这层。

由此两条禁令，写在此处以免下一轮编辑犯错：

1. **不得外溢。**不因为第六部用了链，就在其他卷"统一文体"。其他卷的 0–2% 是正确值，不是待修值。
2. **不得降平。**不因为"全书要统一"就把第六部压到 2%。第六部的目标不是接近其他卷，是让链子只在它该在的段落里。

## 1. 问题陈述：同一个装置，两种结果

顶针在第六部同时承担两件事：

- **写流程**：检录、排队、抄题、洗鞋、走路、搬桌。链条模拟"人被流程推着走"，主语不必重新起，因为人也不必重新决定。
- **写注意力的黏连**：夜里反复排同一句话、盯一个数字、等一个人出来。链条模拟念头咬住上一句不放。

但同一个装置在长度越界后会翻转成故障：**链子开始自动生成内容**。这时句与句之间没有真实关系，只有修辞胶水（"……的意思是""……结束在""……的原因"）。读起来像把一个算法套在散文上。

判据因此不是章均连接率，而是**段落长度 × 链密度**（§3、§4）。

## 2. 判据（写死，可复算）

1. 去掉标题行；以 `。！？!?…` 切句；去掉所有非汉字字符，得到纯汉字串。
2. 只保留长度 ≥3 汉字的句子（避免"嗯。""行。"污染分母）。
3. 相邻两句记一次**顶针连接**，当且仅当 `prev[-2:] == next[:2]`（只计双字）。
4. **连接率 = 连接数 / 相邻句对数（n−1）**。
5. **长全链段**：段落 >200 汉字，且段内连接率 ≥50%。这是"故障段"的机器代理指标。
6. 另报：最长连续链、>400 字段落数、正文汉字数。

本口径与 team-lead 实测一致：Ⅵ-004 本脚本 21.8%（交办 21.6）、Ⅵ-012 26.8%（26.7）、Ⅵ-014 14.8%（14.7），误差 ≤0.2pt。

### 脚本（`dingzhen_v6.py`，同目录）

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""V6 顶针率实测脚本（HY-A09 自写，可复算）"""
import json, os, re, sys

HAN = re.compile(r"[\u3400-\u4dbf\u4e00-\u9fff]")

def strip_headings(text):
    """只取正文：去标题；遇独立成行的 --- 截断（其后为交稿附录）。"""
    body = []
    for l in text.split("\n"):
        if l.strip() == "---":
            break
        body.append(l)
    return "\n".join(l for l in body if not l.startswith("#"))

def clean(s):
    return "".join(HAN.findall(s))

def split_sents(text):
    parts = re.split(r"[。！？!?…]+", strip_headings(text))
    return [c for c in (clean(p) for p in parts) if len(c) >= 3]

def paragraphs(text):
    out = []
    for block in re.split(r"\n\s*\n", strip_headings(text)):
        n = len(clean(block))
        if n:
            out.append((n, block))
    return out

def chain_len(flags):
    best = cur = 0
    for f in flags:
        cur = cur + 1 if f else 0
        best = max(best, cur)
    return best

def analyze(path):
    text = open(path, encoding="utf-8").read()
    sents = split_sents(text)
    n = len(sents)
    flags = [sents[i][-2:] == sents[i + 1][:2] for i in range(n - 1)]
    cnt = sum(flags)
    paras = paragraphs(text)
    long_chain = 0
    for size, block in paras:
        if size <= 200:
            continue
        s = split_sents(block)
        if len(s) < 4:
            continue
        f = [s[i][-2:] == s[i + 1][:2] for i in range(len(s) - 1)]
        if sum(f) / len(f) >= 0.5:
            long_chain += 1
    return dict(path=path, hanzi=len(HAN.findall(strip_headings(text))),
                sents=n, links=cnt, rate=round(cnt / max(n - 1, 1) * 100, 1),
                longest=chain_len(flags), paras=len(paras),
                over400=sum(1 for x, _ in paras if x > 400),
                max_para=max((x for x, _ in paras), default=0),
                long_chain_paras=long_chain)

if __name__ == "__main__":
    files = [a for a in sys.argv[1:] if not a.startswith("--")]
    rows = [analyze(p) for p in files]
    if "--json" in sys.argv:
        print(json.dumps(rows, ensure_ascii=False, indent=2)); raise SystemExit
    print("file\thanzi\tsents\tlinks\trate%\tlongest\tparas\tover400\tmax_para\tlong_chain")
    for r in rows:
        print("{}\t{}\t{}\t{}\t{}\t{}\t{}\t{}\t{}\t{}".format(
            os.path.basename(os.path.dirname(r["path"])) + "/" + os.path.basename(r["path"]),
            r["hanzi"], r["sents"], r["links"], r["rate"], r["longest"],
            r["paras"], r["over400"], r["max_para"], r["long_chain_paras"]))
```

## 3. 判例：什么该留，什么该拆

### 甲 · 可用（Ⅵ-018 段 4，67 字，连接率 ~100%）

> 夏思成吃饭的速度比我快。比我快的人吃完就看我。看我的眼睛里有一点想问分数的光。想问分数的光他忍住了。忍住了的表弟把杯子转了一圈，说："那你晚上干什么？"

三个链接把"被看"这件事拉长成一段神经质的注意。重复本身就在写"他一直在注意我"。删掉任何一环，注意的黏度就掉了。**这是文体，保留，甚至可以主动加。**

### 乙 · 故障（Ⅵ-018 段 9，366 字，连接率 ~100%）

> 我打完那一局。打完那一局把屏幕暗下去。暗下去的设备留在桌上。留在桌上的意思是它不属于我的口袋。不属于口袋的夜晚结束在洗脸和躺下。躺下的时候胃是饱的。饱的胃里有餐馆的菜，有白天的两场，有还没到来的物理和英语。还没到来的科目我没有在这个夜里排成仪式。不排成仪式的原因是日子本身还没走完。没走完的人把眼睛闭上。（……）

每一句都咬着上一句的尾巴，但**句与句之间没有真实关系**。"留在桌上的意思是它不属于我的口袋""不属于口袋的夜晚结束在洗脸和躺下"——这两个"意思是""结束在"是修辞胶水，不是逻辑。链子在自动生成内容，不是内容要求链子。

### 总规则（四条，按序执行）

1. **链接数 ≤3：保留，甚至可以主动加。**它是叙述者注意力过载的表现，是这一卷最好的东西之一。
2. **链接数 ≥5，或段落 >200 字且基本全链：必须拆。**拆法不是改成平铺直叙，是**把假连接换成真连接，或直接断开**：删掉"……的意思是""……结束在""……的原因"这类只服务链子的黏合剂，让句子各自站着。
3. **单句测试：删掉链接词后这句话还成立吗？**成立 → 假链，必须拆；不成立 → 真链，保留。
4. **拆完字数不得减少。**假链省下的字，要用同一段里被黏合剂挤掉的实物、动作、声音补回来（"暗掉的屏幕、放好的水、两个还没睡死的大人"这种本来就好的具体物，拆链后应当更醒目，不是消失）。

### 补充：旧判断作废

旧稿曾写"Ⅵ-018 是全书唯一一次链断"。实测推翻：018 = 39.2%，是**全书最高**，不是最低。引用 018 一律按此更正。018 由 team-lead 亲自改写作样板，本批次不动。

## 5. 三条硬原则

### 一 · 机械处保留

判据：删掉主语后句子仍成立，说明主语本来就不重要——流程的标志，链子可留。

- 012："第一下没剪断，第二下断了。断口很尖，我用指甲把尖的地方按平。"剪吊牌是手的工序，链条就是节奏。
- 004："压住还是慢慢渗进一页例题。例题的图花了。花了的图我对着黑板重新画。"水渗纸是物理连续。
- 018："发僵的手指把笔帽扣上。扣上的笔放回那个和证件在一起的口袋。"收笔动作链，正确。

### 二 · 情绪断裂处必须断

判据：这一句是不是"人突然意识到什么"？是，则上一句的尾巴不能交给下一句。

四个高危位置：被人看见／被人说中；看见某人；一个数字或一句话落地；心里塌一下后的第一句。

- 012（改）：原"椅子响了一下。椅子响说明她站起来了。站起来的几步我数着。数着的心跳比步子快。"→ 改后只在"她站起来了"独立成段，链子停在"出现在门口的一刻"之前。
- 004（改）：原"多余的东西我仍然喜欢。喜欢留在草稿背面"→"多余，我也还是喜欢，留着，留在草稿背面"。把链压回句内，句子就不再咬上一句。

### 三 · 单段 ≤400 汉字，分段点选在换气处

不按字数对半切。分段点必须是场景切换、对话开始、时间跳转、情绪落地。允许连续 80–150 字的短段制造急促感（等待、考试、跑道）。反例：019 的 1,262 字单段把考场、走廊、滑梯、父母签字压在一起，读者没有换气的地方，链子也无处可断。

## 6. 七种手法

| # | 手法 | 做法 | 前后对照 |
|---|---|---|---|
| 1 | 去尾 | 删上一句的重复尾巴（"热完""说完""笑完"） | "我的耳朵热了。热完我说是。"→"我的耳朵热了。热从耳根烧到脖子。我说是。" |
| 2 | 换头 | 下一句换指代/换视角 | "熟说明她的下午已经有内容。内容不是在等我的袋子。"→"那种熟说明她的下午已经有内容，而那内容不是在等我的袋子。" |
| 3 | 合句 | 两句并一句，消掉句界 | "老板把一块退回来。退回来的硬币在掌心很烫。"→"老板把一块退回来，硬币在掌心很烫。" |
| 4 | 删胶 | 删"……的意思是""……结束在""……的原因"，让句子各自站着（**治故障段的主手法**） | "留在桌上的意思是它不属于我的口袋"→"设备留在桌上，不属于我的口袋。" |
| 5 | 加物 | 在断裂处插外部细节（物、声、光），承接视线而非承接词 | "她停住，手没有立刻接，嘴先开了。"前加"有个老师抱着一叠卷子从我们旁边过去，看了我一眼，没有问。" |
| 6 | 对白豁免 | 人物语言里的顶针保留 | 刘逸凡："承担完别来谢我。谢我我会烦。"父亲："办事是你自己的脚。脚出去以后，家里帮不上。" |
| 7 | 重复豁免 | 同一句式的刻意重复是内容 | 013"我不好意思收"三次；012 章名句"礼物还没送出去" |

**配比（本次实操）**：012 去尾 11、换头 9、合句 6、加物 8、分段 33（44→77 段）；004 去尾 9、换头 7、合句 5、加物 4、分段 23（88→111 段）。净字数 012 +5、004 +31。

## 7. 哪些章不该整章降率

### 006 八十三（28.9%，0 故障段）——不动

链全在"第一"与"八十三"的自我辩论上："八十三没有把第一吃掉。它把第一放进一个更大的楼里。"这是全章的心理动作，不是描述。压到 15% 会把一个反复验算自己名次的人改成一个平静的旁观者。

### 008 有人笑了（26.6%，0 故障段）——不动

被嘲笑写成短促的注意：楼梯、窗口、食堂队伍里"隔一阵就有人说一遍"。短链模拟的是耳朵一直在等那句话。拆开就变成"我听见了几次嘲笑"的汇报。

### 017 把教室搬过去（35.7%，3 故障段）——只拆故障段，不整章降平

"搬走的不是桌子的腿，是人。人从原来的楼里出来……"主语一直是上一个人留下的宾语，这是"被搬运"的主题句法。整章降率等于把"被搬运"写成"我在搬家"，主题反了。只拆那 3 个 >200 字且全链的段落（多为抒情收束处），短链全部保留。

### 018 没考完的夜里（39.6%，4 故障段）——短链留，长链拆

考试日的时间表本身就是链：进场、发卷、收笔、对答案、吃饭、下午数学、晚上一局输掉的游戏。人在这两天没有自主节奏。但 4 个长全链段（如 §3 判例乙）是算法在自动续写，必须拆。目标不是 15%，是"故障段清零、章率自然落到 30% 左右"。

### 009 有人在门外做饭（31.1%，2 故障段）——主体保留

七成是父亲洗菜、热锅、盛汤的连续动作，是全书少数把"照顾"写成工序而非抒情的段落。只拆那 2 个长全链段（多为向母亲解释自己的部分）。

## 8. 验收清单

- [ ] 净汉字数 ≥ 原章（`hanzi_count.py` 口径）。
- [ ] 无段落 >400 汉字；分段点在换气处。
- [ ] **长全链段 = 0**（>200 字且段内链率 ≥50% 的段落清零）。
- [ ] 无元叙述："这一章／下一章／前文／后文／读者／本节"。
- [ ] 最长链 ≤3，除非属于"对白豁免／重复豁免／物理连续"并在附录说明。
- [ ] 事实零改动；新增仅限普通生活细节与他人日常动作。
- [ ] 附录六项齐全（字数、新增场景、新增他人动作对白与 L1 声明、刻意保留段落、三处前后对照、新事实风险）。
- [ ] 未把第六部句式带到其他卷。

## 9. 已知局限

1. 判据只认双字、不看句内，因此"合句"可在不改一字的情况下降低读数——有被滥用的风险。对策：合句只用于原文本就是一个连续动作的两句。
2. 判据不区分叙述与对白，人物语言里的顶针会被计入（012 现存 3 个连接全在刘逸凡对白内）。
3. 判据不跨段。跨段顶针（上段末句 → 下段首句）视觉上更刺眼但不计。下一轮可加"跨段权重 ×1.5"。
4. "长全链段"用 200 字 / 50% 两个阈值做代理，边界样本（如 190 字全链）会漏判。它是提示器，不是裁决器；最终判据是 §3 的四条总规则。
