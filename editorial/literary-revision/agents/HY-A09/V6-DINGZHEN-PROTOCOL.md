# 第六部顶针句调制规程（V6-DINGZHEN-PROTOCOL）

> 适用对象：《时间的复数人称》第六部 20 章。R2 文学总修订·子任务 HY-A09。
> 目的不是"降低顶针率"，而是让顶针**只出现在它该在的地方**。
> 判据写死在本文第 2 节，任何人可复算；所有结论都附实测数字，不凭语感。

---

## 1. 问题陈述

第六部 20 章的相邻句顶针率分布极不均匀：三章接近 0（已重写），其余多在 17%–40%，最高 39.6%。同书其他部（Ⅴ-014 = 0.4%，Ⅳ-009 = 0.5%）几乎不出现这种句式。

顶针不是单纯的修辞偏好。它在三种情况下是**对的**：

- 写**流程**：检录、排队、抄题、洗鞋、走路、搬桌子、关窗。链条模拟"人被流程推着走"，主语不需要重新起，因为人也不需要重新决定。
- 写**惯性**：夜里反复排同一句话、反复检查同一个拉链。链条模拟念头咬住上一句不放。
- 写**人物语言**：刘逸凡说"承担完别来谢我。谢我我会烦。"父亲说"办事是你自己的脚。脚出去以后，家里帮不上。"这是他们的说话方式，不该被编辑统一。

它在一种情况下是**错的**：

- 写**断裂**。看见某人、被人戳中、心里塌一下、忽然听见一句话——这些时刻，句子必须断开，因为人的意识在这里本来就是断的。**断裂本身是内容。** 把断掉的地方补回成链，等于把一次真实的失语改写成一段流畅的解说。

因此本规程的核心不是"降率"，是**分区**：先判这一句属于流程还是属于断裂，再决定留链还是断链。

---

## 2. 判据（写死，可复算）

1. 去掉标题行；以 `。！？!?…` 切句；去掉所有非汉字字符，得到纯汉字串。
2. 只保留长度 ≥ 3 汉字的句子（避免"嗯。""行。"这类对白污染分母）。
3. 相邻两句记一次**顶针连接**，当且仅当 `prev[-2:] == next[:2]`（只看双字，不计单字）。
4. **连接率 = 连接数 / 相邻句对数（n−1）**。
5. 另报：参与顶针的句数占比、最长连续链、正文汉字数、段落长度分布（>400 字段落数、最长段）。

本口径与 team-lead 的 R2 实测口径一致：004 本脚本 21.8%（交办单 21.6%）、012 26.8%（26.7%）、014 改后 14.8%（15.1%），误差 ≤0.5pt，源于切句边界的微小差异，不影响任何判定。

### 脚本（`dingzhen_v6.py`，与本文件同目录）

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""V6 顶针率实测脚本（HY-A09 自写，可复算）"""
import json, os, re, sys

HAN = re.compile(r"[\u3400-\u4dbf\u4e00-\u9fff]")

def strip_headings(text):
    """只取候选稿的正文：标题行去掉；遇到独立成行的 --- 即截断（其后为交稿附录）。"""
    lines = text.split("\n")
    body = []
    for l in lines:
        if l.strip() == "---":
            break
        body.append(l)
    return "\n".join(l for l in body if not l.startswith("#"))

def clean(s):
    return "".join(HAN.findall(s))

def split_sents(text):
    parts = re.split(r"[。！？!?…]+", strip_headings(text))
    return [c for c in (clean(p) for p in parts) if len(c) >= 3]

def paragraphs(text):
    out = []
    for block in re.split(r"\n\s*\n", strip_headings(text)):
        n = len(clean(block))
        if n:
            out.append(n)
    return out

def chain_len(flags):
    best = cur = 0
    for f in flags:
        cur = cur + 1 if f else 0
        best = max(best, cur)
    return best

def analyze(path):
    text = open(path, encoding="utf-8").read()
    sents = split_sents(text)
    n = len(sents)
    flags = [sents[i][-2:] == sents[i + 1][:2] for i in range(n - 1)]
    cnt = sum(flags)
    pairs = max(n - 1, 1)
    involved = set()
    for i, f in enumerate(flags):
        if f:
            involved.update((i, i + 1))
    paras = paragraphs(text)
    return dict(path=path, hanzi=len(HAN.findall(strip_headings(text))),
                sents=n, links=cnt, rate=round(cnt / pairs * 100, 1),
                inv_rate=round(len(involved) / max(n, 1) * 100, 1),
                longest=chain_len(flags), paras=len(paras),
                over400=sum(1 for p in paras if p > 400),
                max_para=max(paras) if paras else 0)

if __name__ == "__main__":
    files = [a for a in sys.argv[1:] if not a.startswith("--")]
    rows = [analyze(p) for p in files]
    if "--json" in sys.argv:
        print(json.dumps(rows, ensure_ascii=False, indent=2)); raise SystemExit
    print("file\thanzi\tsents\tlinks\trate%\tinvolved%\tlongest\tparas\tover400\tmax_para")
    for r in rows:
        print("{}\t{}\t{}\t{}\t{}\t{}\t{}\t{}\t{}\t{}".format(
            os.path.basename(os.path.dirname(r["path"])) + "/" + os.path.basename(r["path"]),
            r["hanzi"], r["sents"], r["links"], r["rate"], r["inv_rate"],
            r["longest"], r["paras"], r["over400"], r["max_para"]))
```

用法：`python dingzhen_v6.py manuscript/volume-06/*.md`

## 4. 三条硬原则

### 原则一：机械处保留

判据：如果删掉主语之后句子仍然成立，说明主语本来就不重要——这是流程的标志，链子可以留。

- 例（012 保留）："第一下没剪断。第二下断了。断口很尖。我用指甲把尖的地方按平。"剪吊牌是手的工序，链条就是工序的节奏。
- 例（004 保留）："压住还是慢慢渗进一页例题。例题的图花了。花了的图我对着黑板重新画。"雨水渗纸是物理过程，链子模拟的是液体的连续性。
- 例（018 保留）："发僵的手指把笔帽扣上。扣上的笔放回那个和证件在一起的口袋。"考场收笔的动作链，正确。

### 原则二：情绪断裂处必须断

判据：这一句是不是"人突然意识到什么"？如果是，前一句的尾巴不能交给下一句。

四个高危位置（出现即检查）：

1. 被人看见/被人说中（"你吃味了""你今天脸很紧"）
2. 看见某人（她转笔、她站起来、她出现在门口）
3. 一个数字/一句话落地（"没有一行写着第一名""收到"）
4. 心里塌一下之后的第一句（沉默、耳鸣、看地砖、看鞋）

- 例（012 改）：原"椅子响了一下。椅子响说明她站起来了。站起来的几步我数着。数着的心跳比步子快。快的心跳里她的身影出现在门口。"
  改后只在"她站起来了"处留一个短句独立成段，链子在"出现在门口的一刻"彻底停住。
- 例（004 改）：原"多余的东西我仍然喜欢。喜欢留在草稿背面，不留在这一次的分数里。"
  改为"多余，我也还是喜欢，留着，留在草稿背面，不留在这一次的分数里。"——把链条压回一个句子内部，句子就不再"咬"上一句。

### 原则三：单段 ≤400 汉字，分段点选在换气处

- 不按字数对半切。分段点必须是：场景切换、对话开始、时间跳转、情绪落地。
- 允许连续短段（80–150 字）制造急促感，尤其在等待、考试、跑道上。
- 反例：019 有一段 1262 字，把考场、走廊、滑梯、父母签字压在一段里，读者没有换气的地方，链子也就无处可断。

## 5. 七种可操作手法

| # | 手法 | 做法 | 前后对照 |
|---|---|---|---|
| 1 | 去尾 | 删掉上一句的重复尾巴（"热完""说完""笑完"） | "我的耳朵热了。热完我说是。"→"我的耳朵热了。热从耳根一直烧到脖子。我说是。" |
| 2 | 换头 | 下一句换指代/换视角开头 | "熟说明她的下午已经有内容。内容不是在等我的袋子。"→"那种熟说明她的下午已经有内容，而那内容不是在等我的袋子。" |
| 3 | 合句 | 两句并一句，用逗号/分号消掉句界 | "老板把一块退回来。退回来的硬币在掌心很烫。"→"老板把一块退回来，硬币在掌心很烫。" |
| 4 | 加物 | 在情绪转折处插一句外部细节（物、声、光），承接视线而不是承接词 | "她停住，手没有立刻接，嘴先开了。"→此前加"有个老师抱着一叠卷子从我们旁边过去，看了我一眼，没有问。" |
| 5 | 换序 | 把结论提到前，动作降到后 | "我缩回手。缩回以后，自己的卷子反而写错了。"→"我缩回手。缩回以后……"（保留，因是动作）；反之情绪句一律先结论 |
| 6 | 对白豁免 | 人物语言里的顶针一律保留 | 刘逸凡："承担完别来谢我。谢我我会烦。"父亲："办事是你自己的脚。脚出去以后，家里帮不上。" |
| 7 | 重复豁免 | 同一句式的刻意重复是内容，不降 | 013"我不好意思收"三次；012"礼物还没送出去"作为章名与收束 |

## 6. 哪些章不应该降率

反直觉但必须写清楚，否则下一轮编辑会把这些章改坏。

### 017 把教室搬过去（35.7%，全书第二高）——不该降

理由是语法层面的：这一章写的是**人被搬走**。桌子被搬、书被搬、人被队伍带走，全程没有一件事是"我"决定的。"搬走的不是桌子的腿，是人。人从原来的楼里出来……"这种链条正是主题句法：主语一直是上一个人留下的宾语。把它改成散句，等于把"被搬运"写成"我在搬家"，主题就反了。

可改的只有两处：最长链（6 环）里有一环是比喻（"纸明天大部分用不上。用不上的也有人带着"），可断；以及两个 767 字的超长段，必须分段但不拆链。

### 018 没考完的夜里（39.6%，全书最高）——只微调

考试日的时间表本身就是链：进场、发卷、收笔、对答案、吃饭、下午数学、晚上游戏。人在这两天里没有自主节奏，链子是诚实的。需要断的只有三处：对答案（情绪）、父母不问作文（情绪）、表弟说话（关系）。这三处断掉，率会自然落到 32% 左右，不必更低。

### 009 有人在门外做饭（31.1%）——保留型

七成篇幅是父亲洗菜、热锅、盛汤的连续动作。这是全书少数把"照顾"写成工序而不是抒情的段落。链条在此处等于"生活自己会继续"。只需在"门缝里先出来的是油烟"和母亲进门两处断。

### 001 换了一层楼（9.5%）——已合格

低于 15%，无需干预。最长链（5 环）出现在母亲系扣子、父亲倒水、摆鞋的晨间流程里，正确。

### 014 四百米（14.8%）——已合格

检录、别针、起跑器、第二个弯，链子在跑道上是对的；枪响之后必须断，现已断。

## 8. 已知局限

1. 判据只认双字，且不看句内（分号、逗号连接的长句不计入）。因此"把两句合成一句"可以在不改一个字的情况下降低读数——**这可能被滥用**。本规程的对策是：合句只用于原文本就是一个连续动作的两句，不得把两段不同性质的内容强行粘合。
2. 判据不区分叙述与对白。人物语言里的顶针会被计入。本次两章分别有 3–8 个连接落在对白内，属应保留项，读数因此偏高。
3. 判据不跨段。跨段顶针（上段末句 → 下段首句）在视觉上更刺眼，但不计入。若下一轮要更严，可加"跨段权重 ×1.5"。
4. 连接率只是症状指标。真正的判据是第 4 节的三条原则，机器只能提示，不能裁决。
