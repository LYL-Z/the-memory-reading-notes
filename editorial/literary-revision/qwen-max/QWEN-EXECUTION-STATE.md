4. 用户三次强调：**要看真正写出了哪些原来不存在的文学场景**，不要评分数字、不要「诺奖级」口号。
5. 正文**干净可阅读**：无 markdown 加粗、无英文、无直角引号、无工程标记。重构边界只写在 REVIEW 档案里。（作者本轮裁决优先于 AGENTS 的段内标签要求）
