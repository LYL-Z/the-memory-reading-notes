## 一、三段新增（全部 A 类，来自母亲自己填写的问卷）

### 新增 1：她不是从那个秋天开始的（约 1,150 字）——本章最重要

**材料（母亲卷，F1，均为她本人书面作答）**：

| 题目 | 她的答案 |
|---|---|
| 中学 | 洢泉中学 |
| 喜欢／最怕 | 语文／数学 |
| 晚自习 | 灯光昏黄，笔尖沙沙 |
| **童年印象最深** | **插田被蚂蟥咬** |
| **什么时候觉得日子难** | **上山砍柴** |
| 兄妹 | 二人，她排第二；哥哥把甜果子分给她、挨骂时护着她 |
| 更亲谁 | 外婆；赶集带上她，回来留好吃的 |
| **饭桌上最常见的菜** | **外婆做的腊肉** |
| **小时候向往** | **去草原骑马；当女兵** |
| 十八九岁 | 想离开家乡出去闯一闯，对婚姻想得不多 |

**这一段的必要性**：原稿的母亲从 2007 年秋天开始存在。她的全部内容是「上班、怀孕、洗小衣服、被主管催报表」——**她是一个即将成为母亲的人，不是一个已经活了二十五年的人。**

**（1）两个答案都不是故事**

> 「我以为她会写一件事，一件有头有尾、能讲出来的事。她写的是：插田被蚂蟥咬。」
> 「两个答案都很短，都不是故事。**一个是腿上的一条虫，一个是肩上的一捆柴。**」

**（2）同一具身体的两种用法**——不升华，且当场拒绝感慨：

> 「十几岁的时候，她插田，弯腰，腿泡在水里有蚂蟥；她上山，砍柴，捆好，挑下来。那时候她的身体是用来干这些的。」
> 「二十五岁那年秋天，她的身体在做另一件事：站在方凳上够柜顶，肚子顶到柜门，弯不下腰……」
> 「**同一个人，两副用法。**」
> 「**我不觉得这里面有什么可感慨的**——乡下女孩十几岁下田砍柴，二十五岁生孩子，这是那一带大多数女人的路线，她走的是最常见的那一条。**她自己写的时候也没有加一个字的形容词。**」

**（3）两种腊肉**——把两条独立的 F1 材料在原稿已有的物件上对撞：

原稿行 63 奶奶蛇皮袋里有腊肉，行 75 挂在阳台钉子上、不能晒、挪到阴面用报纸挡着。母亲问卷写她从小吃的是**外婆做的腊肉**，而原稿行 199 外婆隔一天送一次汤。

> 「所以那年冬天，我们家阳台上有两种腊肉。」
> 「我没有吃过。**我那时候只会喝奶。**」
> 「她们两个人一个在厨房，一个在阳台，谁也没有把两块肉放在一起比过……它太小了，两块腊肉而已。」
> 「可我现在想起来，那是两个女人各自把自己娘家的味道搬进同一间屋子。**她们谁也没有说自己带的更好。她们只是各挂各的。**」

**这是本章对婆媳关系的唯一处理：不写冲突，写两块并存的肉。** 与 Q4 收窄完全相容。

**（4）草原与军装**——拒绝写成梦想落空：

> 「一个在洢泉中学上晚自习、怕数学、腿上有过蚂蟥的女孩，想去的地方是草原，想穿的衣服是军装。」
> 「**我不打算把这写成一个梦想落空的故事。**她自己填的时候，语气很平，没有一句可惜。」
> 「**想当女兵的人后来在办公室催报表，这不是失败，这是长大以后的样子。多数人都是这样。**」
> 「2007年秋天在阳台上一件一件抖小衣服的那个人，**身体里装过草原和军装**。她抖衣服的时候没有想这些，她想的是哪件有黄渍、明天能不能干。」
> 「那两样东西没有消失，也没有实现。**它们就是在那儿，跟她一起上了六楼。**」

### 新增 2：星期一，晴（约 520 字）

**材料（母亲卷 Q34，F1）**：出生 **2007-11-05，星期一，晴**；爸爸奶奶外公外婆都守在医院。

**接口是原稿现成的矛盾**：具体几点，外婆说天刚亮、奶奶说七点多、父亲说八点，**三个说法差两小时**。

> 「四个大人守在医院里，守了一夜，结果连孩子是几点出来的都说不齐……可是一个跟他们谁都没关系的东西，那天有没有太阳，反倒被记住了，还被写了下来。」

**叙述者给出一个不煽情的解释**：

> 「**钟点在产房里面，天气在产房外面。**里面的人盯着人，外面的事只有进来的时候看一眼。外婆天亮的时候来过一趟，奶奶七点多出去买过早点，我爸八点进门——他们各自记住的，是自己那一刻看见的天色，然后把它当成了我出生的时间。」
> 「**所以最不容易记错的，反而是最不要紧的那一样。**」

**收束落在一个具体的、可推与不可推的边界上**：

> 「那天确实出了太阳……这些我可以推，因为那是那个季节那一天的常态。**我推不出来的，是那道光有没有照到我脸上。**」
> 「我妈说……光照在对面床的搪瓷杯上。搪瓷杯在对面床。我在她这边。」
> 「**所以我大概没有晒到。**」

**这是全书「档案装置」的第二次实写**（第一次在 V3-007 新疆段）：一行填表式记录比四张嘴可靠，但它干净得「像别人家的事」。

## 二、跨章重复修复（本轮同时改动 V3-002）

**盐罐挪位置**在本章行 81 与 V3-002 各出现一次，**且都写「我妈后来找盐，找了两天」**——同一细节两章重复。

**修法**：本章（2007，时间在前）保留原样；**V3-002（小学以后）改为明确的第二次**，并去掉重复的「两天」：

> 「我妈后来找盐，**又找了一回**。不是第一回。我刚出生那年她来……这一次她走，又挪了一次。」
> 「你奶奶**来也挪，走也挪**，反正那个罐子不能待在原来的地方。」

**并给出一个不升华的解释**：

> 「那个厨房不是她的。她来做客，做完了要走，能留下的东西不多——一冰箱写着字的饺子，一台洗干净的抽油烟机，还有一个被挪了位置的盐罐。**前两样会被吃掉、会用脏。只有最后那样，能一直在那儿。**」

**一次重复被改造成一个跨越十年的母题。**
