## 4. 对后续 AI 最重要的不可混淆边界

### 已有历史创作决策

- 第一部已经承接高一主要故事；此前让第三部大量重讲高一四人组的旧六部规划不可原样执行。
- 第二部回到益阳童年与父母，是此前已明确提出的方向，但其中具体时间跳跃及场景还没有形成正式定稿。
- 第一部结尾的笑不等于赵问竹口头答应，后续不得强行设定她真实内心。
- 先前的“甲：2026桌子为时间锚；乙：重要关系独立行动；丙：真实冲突证词”是一套仍值得使用的方法，不要求每章全部同时出现。

### 本轮新的**建议**，并非作者已冻结承诺

- 保留六部曲为首选架构，允许实证不足时合并第五、第六部。
- 第三部题名《换座之后》仅是建议；所有分卷字数只是容量估算。
- 将 **事实时间、认知时间、叙述时间、读者时间** 分别维护。
- 每次回跳必须改变事实认识、人物选择或阅读意义；禁止同义解释的复播。
- 自传主人公允许不自知、理解错误、自我防御，但现实中的他人不得被当成可随意编造的叙述工具。
- 每部必须有**不依赖赵问竹的独立故事**；其他人物拥有自主性。
- 引用名家、古诗文、外语与物理概念等应从有来源的真实生活生长，不替场景宣讲哲理。

### 事实层需要持续查证的地方

- 桃园三结义“饭店／家中、孩子自发／长辈提议”是同一人物不同时间的记忆或订正，不能制造伪证人或把已订正事实写成永远不可知。
- 2022年致父母的信、父亲的经历与相册说明要区分少年感受、历史行为、照片在场，不能误作彼此推翻。
- QQ群事件、竹林杯纸与后来的传闻在时间和证据上彼此独立，**没有已证实的单一因果链**。
- 西安五日同游和赵本人同意，不自动证明恋爱关系或其内心动机。
- 大学、新加坡、学业与人物评价有原始材料，但不能据此虚构没有记录的具体对话或心理。

## 5. 供执行 AI 使用的强制验收问句

- **先问内容**：没有小说主题，这个真实人自己还在做什么？
- **再问行动**：这一场发生了什么不可替代的选择和后果？
- **再问叙事**：2026作者“知道”的东西，是否偷偷灌进了当年的少年？
- **再问读者**：新信息让读者改变了什么判断，还是仅仅重听一次旧感悟？
- **再问伦理**：哪句来自亲历、哪句来自他人原话、哪句只是推测？
- **最后问篇幅**：若删除本章，它在六部曲中的独立文学功能是否真的损失？
