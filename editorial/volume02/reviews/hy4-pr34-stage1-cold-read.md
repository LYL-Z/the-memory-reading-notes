## 二、整体初判（裸读）

**十二章里有至少六种确实不同的生活质地**：① 童年一人分饰多角的客厅（001）；② 分班榜单前不肯承认的高中（002／003／010）；③ 奶奶与父母各自的劳作与饭桌（004／009）；④ 小学教室的桌面、评语与同学各自的记忆（008）；⑤ 童年三人组的镜头、饭菜与记忆不对称（006／011）；⑥ 球馆里身体先于解释的四年（012）。005 的寝室往返、007 的相册与作业，是前几种之间的过渡质地，不是完全独立的新生活。

**读者能否认出真实而复杂的人？** 能认出四个：叙述者（好胜、话多、拘谨、偷懒、爱解释、自我辩护并存，靠动作而非标签）、父亲（009）、奶奶（004）、王培森（008）。向睿馨在 011 有了一次自己的记忆排序。赵问竹在第二部仍主要作为"名字／评价纸／被看的方向"存在——她的独立行动几乎全在第一部；这是**跨卷分工**，不是本卷的失败，但读者若只读第二部会觉得她薄。戴教练在 012 有了头像、点赞、长跑、哭脸与赠拍，但仍无一句他自己的话。

**结构上最值得警惕的**：十二章几乎每章都以一件小物件或一句克制的话收尾，且都带"没做完／没说出口／还在继续"的调子。单章成立，连读会有签名感。001／002／003／005／010 五章共享"想做而没做"的心理机制；004／008／009 三章靠他人材料立住，反而最不像同一种抒情。**这正是"十二种不同的生活"这个问题的真实答案：不是十二种，是六到八种，其中三四种被写了两遍。**

**但我不认为这构成本轮必须修改的理由。** 前十一章是 PR #31 的联合终稿，已多轮收敛；012 是 PR #34 在 PR #33 基础上增补 477 字后的终轮稿。裸读里我没有发现事实错误，也没有发现相对前版明显退步的段落。相反，012 的新结尾把"得先挪过去"的格言换成了捡球的具体动作，008 新增的曹卓雅"转回去忙自己的事"与球馆／班号并置段，007 新增的「即便真站在一所大学门前」假设语气，都是**文学增益**。

## 三、重点三章的裸读观察（待事实核对后定性）

- **007 武汉相册**：地名大多明确归于"相册"（25「相册里有两岸夜景和灯光秀」、31「相册里还留下了武汉大学、黄鹤楼和东湖绿道」），33 段用了「即便真站在一所大学门前，我那时也未必愿意……」的假设语气，21 段用「我和父母好像一起出过一次远门」，29 段「我现在说不准那几顿饭是谁先选的」。**裸读未见"我逐站亲访"的直陈**。但 25「那年出门时只顾看新鲜的地方」、41「父母也不需要在每张照片里站在我旁边，来证明这一趟是陪我去的」、133「我当时只管高兴」都在暗示整体在场——这是"是否同行"与"是否每一景点同行"的差别，须查特殊锁与相册原件后定性。
- **008 配角独立生活**：王培森有中性笔不出墨、纸条下五子棋、楼道追逐、座位轮换、墙上涂鸦／风扇声／小卖部、毕业合影与夹道送别；曹卓雅有喜欢写作文、别的朋友、"心里不好受"、以及 PR #34 新增的「有时我想接着讲，她却已经转回去忙自己的事了」。**两人都有自己的生活，且不是靠一句"也有独立人生"声明出来的**。
- **012 动作链是否推动人物**：脚（31、33、37）→重心（33、57）→捡球（13、47、119）→沙袋（57）形成一条可追踪的身体线；戴教练的鞋尖／军装头像／点赞／长跑／哭脸／赠拍各自有位置；刘拓 Q42 从开头的"一行字"到 117 段"父亲平日工作忙，替我问的倒是这么一件不太了不起的小事"有增量；郑森 Q31 整行引用后，109 段「我当然先盯住『很有天赋』……看见『说话一针见血』，又想：这到底是夸我还是有些话我说得太直了？」把"被夸"写出了不只一种反应。**这些细节在裸读里确实推动了人物，不是象征陈列。**

## 四、三问的裸读初答（终审后可能修订）

1. **十二章有没有讲出十二种不同的生活？** 没有严格意义上的十二种，是六到八种；但其中重复的部分承担了不同的读者知情（002 放榜／003 考前夜／010 考试两天是倒叙与骨架，不是同一场的重拍）。**"十二种"不是这部小说的承诺，B2 秩序本来就靠非线性回看。**
2. **读者能否认出真实而复杂的人？** 能认出叙述者、父亲、奶奶、王培森、向睿馨；赵问竹与夏恺宪在第二部仍偏薄，但前者由第一部承担，后者是材料缺口。
3. **进一步改写是否真的比保留现稿更好？** 裸读初答：**大概率不更好**。现稿的问题（章末签名感、若干自我总结、配角薄）多是结构性的、需要新材料才能解决，不是句子级润色能修的；而现稿的好句密度与生活厚度已经在多轮精修后达到一个稳定状态。若没有事实错误，继续改只会把"不整齐的真实记忆"磨成另一种工整。
