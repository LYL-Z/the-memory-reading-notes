# notes_003《灯在头顶》

## 一、结构决定（按主控 2026-11-12 指示）

- **只写具体的夜，不重演整条线**。V1-002:159–169 已经总结过“怕黑—留母亲—奶奶回乡—能独睡—父亲回来”，本章不再把这条弧线走一遍。
- 因此本章是**一夜为主、三夜为副**的写法：
  1. 主夜：关灯→第一次出门→倒水→第二次出门（冷/脚冷）→母亲坐到床沿→她靠着床头睡着→天亮关灯。
  2. 副夜一：发烧那一夜（母亲原文口述“小时候最头疼的是夜里发烧、半夜要照顾”）。
  3. 副夜二：敲奶奶的房门（房里已无人）＋独自过夜把全屋灯打开。
  4. 副夜三：路灯坏了、把窗帘全拉开。
- 奶奶回乡、父亲在安化各只用一句背景，不写“父亲回来后改变”，也不写“终于能独睡”的结论。

## 三、硬约束执行

- **怕黑那几夜零引号对白**：主场景全部用动作、光、声音、间接引语（“把我睡不着这件事说给她听”“让我睡”）。没有编任何一句枕边对话。
- 未写体温、未写灯泡瓦数。
- 白天场景（晚饭、早饭、母亲打电话、买夜灯）保留自然对话，因为那不是“怕黑那几夜”。
- 不心理诊断：全文不出现“焦虑”“分离焦虑”“缺乏安全感”等词；只写看见的东西与做的动作。

## 四、文学复合（LITERARY_COMPOSITE）

1. 主夜的整条动作链（倒水、热水瓶包毛巾、母亲坐床沿睡着）——依据“借口要母亲陪”的既有自述，具体过程合成。
2. 小夜灯、把床挪到窗下、路灯、日光灯、蒙纸扎洞——均为普通家庭照明处理，合成。
3. 母亲在电话里说“也不知道像谁”——合成台词，用于写“被背后谈论”的感觉；**不指向任何真实通话**。
4. 睡前程序（书包、鞋、水杯、兔子）——依据 Q42 的“秩序感”，具体项目合成。
