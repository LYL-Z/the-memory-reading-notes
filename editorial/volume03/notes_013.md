# 013《校门口的小卖部》事实与不确定项（第二轮：改为六年级主轴）

> 内部记录，不进正文。**本章已按主控意见重写**：小卖部的品类与李老师禁令，第二部 008 已经写过，本卷不重新介绍；一年级只留一段指涉。

## 一、结构

- **主轴**：六年级（1305 班）开学第二周，空了四年的铺面重开 → 柜台换人、价格变化 → 赊账本 → 涨价与合买 → 少找钱 → 冬天与临时关门 → 修路、绕后巷 → 毕业前关店 → 校门口的空 → 路修好后的便利店与回访。
- **一年级**：全章两处、共约一百字——①「这个位置也开过一阵……李老师不准我们买」；②吃的时候想起「有人在这里递给我两根」。不重述品类、不重述规矩、不写凑钱分勺。

## 二、用到的可核事实

1. 小卖部「好像只有一年级和六年级有」（王培森 2026-09-06 问卷 Q17）→ 本章只用「六年级重开」这一半，一年级压成指涉。
2. 校门口小路后来改成柏油路、店里搬走（Q18）→ 结尾。
3. 六年级 1305 班、班主任李霞（bible；本卷 008/013 共用）→「新班主任是李霞，教语文，不管这些」。
4. 主角在一至五年级 86 班、李顺贤班主任（bible）→ 一年级的「李老师」只出现一次，不解释。

## 三、文学复合（正文不标注）

- 老板的形貌、铁皮钱盒、剪刀、小太阳、硬皮赊账本、价目表（手写、玻璃下压着）——全部复合。
- 赊账与划账、高年级学生欠账、「抢就不卖」、看摊两分钟、少找五毛又退回——复合。
- 涨价（一块一包）、合买一人五毛、清货纸盒、围挡上「小卖部没了」的字、烤肠三轮车、面包车摊——复合。
- 后巷买货、老板「不晓得」以后开不开——复合。
- 抽屉里的五毛硬币、坏电子表、写不出字的笔——复合。

## 四、未知／未写

- 关店的真实原因（拆迁／租约／学校）：正文只写门上贴「拆迁」，并让「上午有人来检查、下午又开」留白。
- 店名：不写。
- 便利店的品牌：不写。
- 与（第二部 008）的小卖部段**零重复**：本章不出现「一根葱」「麻辣」「小罐」「塑料勺」「凑钱分勺」，脚本已核（各词命中 0）。
