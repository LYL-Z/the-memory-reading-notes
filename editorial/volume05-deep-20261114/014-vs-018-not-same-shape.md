# 第五部 014 与 018 是否结构同型

**结论：任务书的判断只对了一半；错的那一半更重要。**

## 一、不对的部分

| | 014《那晚的海龟汤》 | 018 密室 |
|---|---|---|
| 结构 | **双游戏复合**：海龟汤 + 打牌，两场并列，后半段重心已在牌局 | 单一事件：解谜一条线 |
| 主角位置 | 出题规则的**审问者**（"你先说清楚，手机是不存在，还是声音不是手机发出来的"） | **抢功者**（"差点向他们解释这叫前后呼应"） |
| 结局神经 | **接受无标准答案**："若所有答案当晚便被讲完，第二天大家可能就没有那句'昨天你们太吵了'可以互相取笑了" | **被忽略**：工作人员说"后面还有人在等"，不给他判决 |

一个是"我非要答案、最后发现没有答案也好"，一个是"我有功劳、没人有空听"。这不是同一个结构。

## 二、对的部分——而且比任务书说的更严重

014 里有一处，与 002/003/004 是**同一个收尾手势**：

> 「我张口，想给他从第一轮开始讲。寝室外面有人喊关门……回头时，对方已经拿着水杯去洗漱了。」

「他想说 → 被别的事挡住 → 话没出去」。**这已经是第五部第五次。**

所以真正的病灶不是"014 与 018 同型"，而是**这个手势在第五部被当成了万能收束**：002 楼梯口、003 阳松经过、004 追两步、014 洗漱间、018 走廊找东西。五章共用。

## 三、已改

014 那一处改为**他确实讲了，但讲错了对象**：

> 「我张口，想给他从第一轮开始讲。讲了两句，他嗯了一声，说那你下回早点出牌。
> 我停下来。他要的不是复盘，是一句结论。」

区别在：他不是被挡住，是**发现对方要的东西和自己给的不是一回事**。这比"没来得及说"更伤，也更真实——高中男生之间的大量错位不是被打断，是答非所问。

## 四、018 不动

018 的"被忽略"是它自己的功能，且与"抢功"配套（他抢功 → 没人有空听 → 功劳归零）。它与 014 的"接受无答案"构成两种不同的人生课，且都不是由别人讲授的。**保留。**

## 五、由此得出的规则

第五部此后不得再用"他想说，被某件事挡住，话没出去"作为章末收束。可用的替代：

1. 他说了，对方答非所问；
2. 他做了，事情办成了但没人知道是谁办的；
3. 他改了主意，且没有向任何人解释改主意的原因；
4. 一件实物留在原地，人已经走了。
