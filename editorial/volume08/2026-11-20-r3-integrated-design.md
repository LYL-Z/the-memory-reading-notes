## 2. 第八部创作契约

现实主线的补充层：历史遗留回顾、转折点改写、遗憾补全、未来预想与主观情感。不同世界允许出现相互排斥的事实，它们只在各自世界成立。以真正发生过的细节为出发点，不以幻想证明真实他人的内心。现实史料继续FACT_CONFIRMED（FACT别名）/RECOLLECTION/LITERARY_RECONSTRUCTION/COUNTERFACTUAL分层；另给假设世界类型REAL/ALTERNATE/DREAM/FUTURE_PROJECTION。后台记账，不在正文反复出示证据。

文学并不需要不断自我节制：允许人物直接陈述感情和愿望、愤怒、虚荣、争胜、幽默、疲劳、身体经验；允许幸福完整发生。不要每次圆满都强制附加悲剧；不要每场冲突都安排朋友说教。成熟主题以年龄相符的表现与非露骨亲密呈现；需要独立成人题材时建立完全虚构的成年角色，不以真实同学为色情原型。高中走读线必须保留家庭安排与独立房间，不借架空性化未成年人物。

## 3. 宏观结构和容量

建议混合三层：现实母线（19岁叙述者或更晚回望者）→完整反事实生活弧→远未来、高维交汇和开放收束。30万 CJK 是工作值，25—35万初步区间；36—48章参考。按主线最长第二部172,099字，第八部的“最长”诉求意味着需超过该值，而Grok提出的12—18万只适合作为早期试写/下限讨论，不采用为整部目标。按现有七部合计825,901字，完成后约108—118万字；不改变正式主线账。内部容量建议仍用3/6/7/5/6/3万六篇分配，允许重新配重。

## 4. 四条核心弧

### W1 同一盏灯，两扇房门（2024—大学后）

分叉：两家改变走读安排。在家长知情监督下的独立卧室与共用学习空间，从看房到交还钥匙。A 生活：热水、忘钥匙、家务、父亲买菜、母亲来访；B 竞争：成绩、讲题、谁要独处、一起备考反而效率不同；C 关系：非性化的少年好感、试探、明确表达、各自边界、同学对走读的看法；D 后果：高考、异地、同城、独立成长。大学后成年关系可发生自然变化，但不虚构真实人物性史。至少三变体：长期相伴、逐渐分开、同城选择。可保留一个无强迫悲剧的幸福版本。

### W2 迟到三年的夏天（毕业咨询活动）

分叉：礼堂碰面后主动把未完成的话讲完。嘈杂展台、各自专业规划、去见老师、重新走过教学楼；告白必须给对方明确选择和完整的回答。成功版本铺开毕业暑假、同学聚会、家庭介绍、异地生活；拒绝版本共享相同前段，之后分岔。不要把未拒绝、酒后反应、沉默当成答应。感官的功能是现场具体性，不是色情化真实人物。

### W3 回益阳（大一学年后暑假）

分叉：回母校遇见同学，对方主动提出同行。若改为第一学期结束则是寒假，待作者裁定。家乡路线、父母、旧日生活、奶奶的记忆、两人所见的成长环境不同；共同吃饭、看旧片或长谈。住宿与房间安排以清楚边界处理，不把同房等同于性行为。重点：被选择的主人公是高兴、慌张还是不知怎样承担后续？替代走向：长期联系、一次重要的告别、只成为更亲近的朋友。可用共同到站与多年后的接站形成回响。

### W4 两所大学之间的夜晚（大学交流）

分叉：虚构跨校活动后朋友传来邀约。白天讨论学业、晚上对话；中间人可能转述不清，但会由见面双方明确澄清。近实时对白既能写智识碰撞又能写旧事与不同城市生活。A 当夜决定继续联系；B 不建立关系但互相理解；C 继续相爱至读研/工作；D 多年后另一城市再次见面。主题是如何从过去关系走向新的共同生活，而非只制造暧昧。

## 5. 超越爱情的三类历史与未来

历史：高一告白/不告白，分班，初中选择，父母陪伴不同；学业与事业：人大、政法、物理、AI、创业、未实现的成功及普通职业；未来：父亲年轻时的同龄人、老年与十九岁数字自我、不同职业和家庭世界的同席，直到2078以后。候选清单见上轮归档。至少保留两条有独立叙事功能的非爱情主弧，避免把一切成功都作为获得某人的手段。

## 6. 世界线施工法

| 字段 | 说明 |
|---|---|
| world_id / parent / fork | 世界编号、母世界及最小分歧 |
| T_event / T_person_knows / T_reader | 事件、人物获知、读者获知分别设计 |
| T_recall / W_world | 回忆/想象生成时间、世界类型 |
| invariant / divergence | 仍成立的真实背景、该世界具体变化 |
| trigger / echo | 进出世界的物件、环境、句子，必须有差异 |
| knowledge_delta | 重访新增的可知信息或情感意义 |
| agency / consequence | 各自选择、行动与后果 |
| risk / source | 后台事实出处、隐私与发表边界 |

设计原则：同一世界内部因果可以复盘；世界之间可含蓄串扰，但卷首框架和后文可辨锚点让读者分清现实/假设类别。不可用模糊事实层伪造“真相”。三种机制待选：纯反事实现实主义、文学与超现实混合（建议）、科幻多宇宙。物理学只作严谨的术语或文学公设，不能把量子多世界写成现实层已证明可穿越。

## 7. 第三轮样例：从模板到行动

以下为候选片段，完全架空，不是回忆证据。

旧机制（示意）：考试之后他想起那间合租屋，才意识到两个人都应该有自己的生活。

新机制：

> 门锁坏了。她试了两次，把钥匙递给我。
> 
> 我拿过去转了半圈，没动。她说你别硬拧，断在里面晚上我们谁也进不去。
> 
> 我其实已经准备好说这锁的结构怎么回事。她拎着菜从我身后过去，敲隔壁的门，问阿姨有没有房东的电话。
> 
> 等开锁的人来了，我还蹲在那里。她在楼梯上坐着背英语，背到第三个词问我，要不要先下去买饭。
> 
> 我说马上就好。
> 
> 她把书合上：“你先看看几点。”

该片段把讲理、胜负欲、能不能解决生活问题交给具体行动。并不强制在结尾说“我明白了”。可以发展为一条学业压力与家务分工线；不将虚构对白回填源库。

## 8. 精修验收

- 章节至少有实际行动变化，不靠语义重复增厚；允许重要世界连续叙事，不为炫技每两页切换。
- 感官重现须服务于场景与信息变化，不能把所有紧张统一成呼吸、手指、光线或停顿；允许喜剧、口语、议论、长对白。
- 爽感检查：什么此前没有发生，此刻实际实现了？完成之后有什么生活？不强制设置对称惩罚。
- 读者重读能够辨认世界；人物自己的目标、知情与选择均成立；现实重大事实未被改写为历史证据。
- 每轮交付前后差异、具体段落或完整章、字数与结构说明；本轮设计不得冒充整部实修或全库深读。
