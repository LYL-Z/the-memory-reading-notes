# 复合时域假说 CTH（小说工作名）｜融合后的科学骨架

不把六套原创理论堆在一起。**选一个本体假说、一套可测量机制、一套通信协议，其他机制只有经单独验证才成立。** 这是虚构科学，不是实际研究成果；前沿知识可随章节更新。作者是物理学学生，必须尊重真实数学和可计算条件。

## 1. 现有物理地基
留数定理：∮_C f(z)dz = 2πi Σ_k n(C,z_k) Res(f,z_k)，解析性、极点位置、方向与绕行数需明确。复对数的普适覆叠 exp: ℂ→ℂ\{0}；0是被排除的对数分支点，不是所有叶相交的普通点。可借有限分支函数 z^(1/m) 的分歧或另设小说“汇聚锚”，不能说log z已证明所有历史在0重合。
相对论：Δτ=Δt√(1-v²/c²)（惯性匀速）；弱场 Δf/f≈gh/c²（近地面1 m约1.09e-16，一天约9.4 ps）。
量子演化 U(t)=exp(-iHt/ℏ)，逆操作不等于回到昨天；量子开关可有操作序干涉，仍不自动构成过去通信。迹保持局部量子通道不改变远方约化态；条件后选的相关性不能当成单端消息。Page–Wootters、Deutsch固定点、Lloyd后选择、量子参考系、虫洞与全息是理论/模拟；不推出现实跨世界通道。2026 NIST光钟论文是理论预言/可实验范围，而非已观察时间旅行（Sorci et al., PRL 136 163602, https://doi.org/10.1103/qhj9-pc2b）。

## 2. 三层原创机制
CTH-1 历史地址（GPT RCD、Claude HCH、Grok HTA/时剪）：图 G=(V,E)，节点 (w,x,τ,a) = 历史标记、局部时空、固有时、预先定义可检验记录锚。局部几何可具有覆叠的数学结构，是否存在连通边是原创公设；用整数绕行/路径字作为模型地址不是说拓扑不变量唯一识别真实宇宙。源历史既往事实不能通过新接口改写；另一世界不同的坐标过去不等于源世界过去。允许分支已有或新增事件的模型，但本次选择“源不改，目标新增事件在其局部后续演化”；不同时采纳HCH的所有事件预定与可任意改写。
CTH-2 几何相位（Claude、Grok、GLM）：有效记录构型空间 Q 上设U(1)联络 A，路径相位 φ=∮A·dq（无量纲弧度）；干涉测的是两路径相对相位，φ模2π，局部非零/全局非平凡需区分。虚构额外耦合 κ 与锚的匹配 g(w,a) 形成小残差 δφ=κ g s(t)+ε，其中 κ单位rad，g及驱动s无量纲，ε是实测噪声。零点可候选同步锚，但不是所有人思想造成场，也不靠中国节日人口直接定律。先有实验上可控的同步时钟/记录源，再讨论自然共时峰。源历史封闭是独立公设，不能由局部联络为纯规范直接推出。
CTH-3 互证通信（Kimi MWC、RCD、Qwen）：定义可计算代理距离 D_ij=指定公共记录集经固定编码器与资源预算的条件描述长度上界，bit；方向相关、非严格度量，不声称精确柯氏复杂度。若无有效转换，D=∞，但实际距离估计仍有不确定。假想每次通道的容量上限 C_ij=C0*2^(-D_ij/λ)，C0 bit/run，λ bit，编码纠错后有效消息 n≤ηC_ij。D=0时为C0；D→∞时趋0；跨域耦合κ=0时C0=0。此衰减是拟合公设而非Shannon定理。用擦除信道 E_η(ρ)=ηρ ⊕ (1-η)|e><e| 模拟假想跨域接口，取η∈[0,1]；局部已知物理仍成立，跨域新边必须明确承认超出已知理论。
GLM的谱核 K(Δτ)=∫ρ(E)exp(-iEΔτ/ℏ)dE 可作为归一化谱的特征函数模型，ρ≥0且积分1，K(0)=1、K(-t)=K(t)*；衰减需要额外条件（如绝对可积连续谱），不可同时令同历史K(t≤0)=0。源历史保护另设方向选择掩码/通道拓扑，不由该谱核推出。观测噪声需归一化或给出量纲；时间晶体不自动意味着时间接口。

## 3. 能力梯级（互不自动推导）
L0 常规测量与数值验证 → L1 统计异常与地址 → L2 单向读取经核验的公共记录 → L3 双向消息及写入目标未来（消息接收方可以不同意）→ L4 物质交换 → L5 自愿成年访问 → L6 多世界网络与特定自洽叶。L4/5不是信道容量增大就证明可穿越；单独新增物质接口公设、守恒账、身份连续性、返回、不可重复复制、双方许可。考虑控制场/装置/两侧储能和动量交换；不强迫另一个人交换，不写“以死亡为入场券”。模型不支持源历史回到已发生的私人瞬间。纯梦、模拟人格、独立重生幻想可写完整，不假装它们是实证，也不让机制证明真实人物的思想。
DeepSeek的钟隙可成为特殊设备长期累积的不确定度 σ_t 或有限记录分辨率（可校准/可维护，只有经情节明确新公设才不可逆），不是每次访问永久删除主角记忆。GLM的0.7秒、Kimi的17分钟仅作为候选观测与两世界坐标对时差，不硬塞为万能常数。特殊自洽叶与梦保持不同性质。

## 4. 实验方案：从异常到真正通信
- 预先写清实验、空假设、信号窗口、统计量、排除项、多重比较修正、样本数/检验功效及停止规则；校准温漂、机械、供电、缓存、随机源、时钟、软件版本和人为选择。对照组盲化、数据不可事后调整。
- 用相互独立的团队与物理装置做盲复核。零点节庆峰若采用，采用预定时间窗、邻近对照、不同日期/地域、多台装置、可控锚；人群规模与电磁/电网/授时等高度混杂，不能一次地下复现就证明新物理。
- Claude示例每秒10^4次、单次噪声1e-3 rad；假设独立白噪声，60秒 N=6e5，标准误约1.29e-6 rad，3e-7 rad信号只有约0.23σ。若全窗1小时恒定才约1.67e-7，约1.8σ，不能用于短峰。不考虑漂移、多重比较、相关噪声时，5σ需 N≈(5e-3/3e-7)^2≈2.78e8，约7.7小时有效独立测量或约463个60秒等价窗。现实相位读数可能相关，改用实际噪声协方差、匹配滤波及独立装置；不随意宣称5σ。
- 哈希只是承诺，公开旧信的hash与两个分支共享的旧信文本都可能来自普通渠道。首次实验使用高熵随机挑战、事先明确编码、隔离并记录双方生成时序、独立证人、重复随机条件；不把完整SHA匹配误当2^-256的跨域后验概率。只有理想随机盲猜m个独立位才有2^-m。完整信的换行错误必须在预注册规范或公开二次实验处理，不事后挑选最佳编码。第一次真正通过可有明确庆祝。
- 真实Lanaduer（Landauer）原理：在相应理想条件下，复位未知均匀经典bit的热下限kBT ln2；300K约2.87e-21 J/bit。1e6个独立未知bit约2.87e-15 J；1GHz×1ms只是1e6采样点，不等于1e6独立bit。下限小不代表设备或跨域物质能耗小。Qwen“改写每bit必耗”不成立，删除唯一副本不是科学必要条件。参考Bennett逻辑可逆计算及 https://plato.stanford.edu/entries/information-entropy/ 。
