## 这一轮的三个发现

1. **他一生的称呼就是一份平行人生的名单**：毛毛、佑霖（没被选中的字）、小林子、主席、竹席、刘总、林哥。
2. **四个梦里的一个元素已经在现实里自己发生了**：两位母亲真的联系上，三个人去了西安五天，他仍然没有加她的微信。遗憾不是封存在高一的旧伤，而是十九岁这一年每天在重新做的选择。
3. **这段关系几乎全部由别人传递。** 所以第八部里，她的故事最适合由梦和别人的眼睛来讲。
