# 第八部总体方案｜《复数》

Claude 独立设计｜2026-11-24｜基线 `main@3f79d2a`｜候选，不冻结任何章表

> 这一页回答一个问题：如果由我来决定，第八部应该是一部什么样的书。我读过 GPT-6.2 的八套架构与 V2、Claude 上一轮的 PR #93，也读过作者的四个梦。它们都是我的材料，不是我的边界。下面的方案保留了八套架构的全部题材，但几乎每一套都换了实现方式。

## 一、一句话

**一个十九岁的物理系学生把留数题的第二个圈画大了，圈进去一个奇点；二十年后，他用这个错误打开了时间的虚部，看见了所有没有发生的人生，唯独看不见自己的过去。**

## 二、卷名

| 候选 | 理由 | 我的判断 |
|---|---|---|
| **《复数》** | 全书书名《时间的复数人称》的核心词。复数是“不止一个”，是 a+bi，也是皇帝自称的“我们” | **首推**。两个字，三层意思，一层比一层大 |

| 连载名：《我在所有世界都叫刘佑林》 | 给网络连载、给爽文读者 | 作者若要发网连载，可以用这个当副标题，正式卷名仍用《复数》 |

## 三、为什么是这一个方案

我在读完前七部、事实仓和全部旧设计之后，得到四个判断。

**1. 第八部需要一个只能属于这本书的发动机。** GPT-6.2 的 RCD（关系时域）是一个合格的科幻接口，但它可以装进任何一本小说。复联4有莫比乌斯带，蚁人有量子领域。《时间的复数人称》第八部的发动机应当从这本书自己身上长出来。我找到了它：书名里的“复数”。前七部的书名页写过“正文不讲复变函数”。第八部讲。它从刘佑林真实上过的那门课、真实画错的那个圈开始（第七部 012），一路长成一套可计算、可证伪、可以一级一级升级的物理（详见 `02-science-bible.md`）。

**2. 所有世界需要一个相交的地方，那个地方应该是家。** `log z` 的所有叶在 z=0 处相交。中国人把除夕子夜叫“零点”。十几亿人在同一秒数到零。我的原创公设“共时锚”让这件事成为物理：**除夕零点是地球上最强的共时锚，各叶在那一刻几乎重合。** PR #93 的《年夜饭》因此不再只是一个梦的设定，它是全卷宇宙论的中心。主人公第一次看见信号，是在奶奶家的饭桌上，全家人在数倒计时。

**3. 爽感要来自真实的赢，赢完还要过日子。** 作者要的不是被吹捧，而是看见他真的做成：科学、财富、帝位、爱情、救世、家人过上好日子。我设计的每一次胜利都有可见的过程（假阳性被一个个排除、等质交换的秤被一点点调平、帝国的合法性被一次次投票确认），也都有胜利之后的生活（买房、回村、宫里的早晨、跨世界的年夜饭）。

**4. 最深的问题要留给读者。** 他能看见所有别的人生，唯独看不见自己的过去。第一部 018 结尾那句“她听清没有”，科学给了他整个多元宇宙，偏偏不给这个答案。后来另一张叶上的自己替他读了：五十四分贝。分贝够不够算“听清”？物理不回答，小说也不回答。这一处空白同时守住了真实人物的边界：任何世界的任何技术，都读不出她当时的心。

## 四、全卷结构：一张黎曼面

第八部不按“世界一、世界二”排，而按“叶”排。叶用绕行地址命名（数学上是自由群里的一个字）；读者不需要懂，但重读的人会发现地址本身就是剧透。

| 叶 | 地址（后台） | 一句话 | 承担的架构 |
|---|---|---|---|
| **主叶** | e（第〇叶） | 物理学家刘佑林：从留数题到打开叶门；与闻栖迟的成年爱情；财富、名望、家人 | C 智源、E 诸界、A 成年爱情、F 家庭 |
| **我们** | a（大二下退学创业那一圈） | 刘总的那一叶长成了帝国：AI 大停摆之后，他把算力与能源收归公有，被各国陆续推举为“共主”，宪法规定君主自称“我们” | B① 现代帝国、G 时间的朝廷的中枢 |
| **交换生** | 宋·熙宁（经主叶叶门，2041↔1076） | 他按等质交换去了北宋，和沈括一起量地磁、修历法；每年除夕回益阳过一次年。一个宋代女子同时来到二〇四〇年代的成都 | B② 穿越、C 的古代版、A |
| **启明** | 另一张宋叶，现在是 2041 年 | 一个九百年前就有过“刘公”的文明，已经航行到木星。他看见了自己的雕像，可他还没去宋朝 | D 星际文明、G、E |
| **岁朝** | 梦联 | 他在梦里是晏朝的皇帝，只在每年元正大朝会出现一天。朝廷为一个一年上一天班的皇帝建起了整套制度 | B③ 梦境 |
| **太子已死** | 空锚 | 全卷尾声：八十岁的他在主叶临终，睁开眼，有人喊殿下 | B③ 重生、开放结局 |
| **负三** | n=−3 | 2039 年打了核战争、进入核冬天的一叶。2040 年除夕，从那一叶传来的第一串比特是求救 | D 救世、社会 |
| **四梦** | 文学并置 | 作者的四个梦：礼堂、同一盏灯、回益阳、两座大学之间 | A 愿望圆满 |
| **佑霖 / 主席 / 零** | PR #93 原有 | 普通的、权力的、不存在的人生；在零点的饭桌上出现 | F 一个一个来 |
| **闻** | 主叶的镜像 | 发现时间虚部的是闻栖迟，他是她一直没毕业的学生 | 喜剧、谦逊、爱情 |
| **宿命** | 诺维科夫世界 | 一切回路自洽的一叶：他在那里试图改变历史，每次都发现自己本来就是历史的一部分 | 惊悚、《暗黑》式结构 |

H《万世之我》是整张黎曼面。它不需要每一叶都连通，也不需要每一叶都走到老。

### 叶之间怎样联系

四种联系，按情节需要用：

1. **物理连通（HCH）**：主叶、我们、交换生、启明、负三之间。规则见 `02` 第四节。
2. **梦联**：岁朝、四梦。梦有梦的语法，不必解释。
3. **零点同席**：在枝心（所有叶相交处）的年夜饭上，平时互不相通的叶也能坐到一张桌上。
4. **互不相通**：佑霖可以一辈子不知道有别的叶。他的那一叶照样完整。

## 五、篇、章、节

第八部由若干**篇**组成，每篇是一本可以独立阅读的书；篇下分章，章下分节，节数不限。

| 篇 | 暂名 | 内容 | 节奏 |
|---|---|---|---|
| 序 | 零点 | 2036 年除夕，奶奶家的饭桌，信号第一次在倒计时里出现 | 冷开场，一章 |
| 第一篇 | 第二个圈 | 主叶：2026 江安的留数题 → 2041 第一个人穿越 | 连续顺叙为主，硬科幻发现史；每章多节 |
| 第二篇 | 我们 | 帝国：从刘总的退学到共主登基，再到宫里的日子与继承问题 | 长篇权谋与建设；可独立成书 |
| 第三篇 | 交换生 | 北宋与成都两条线对剪 | 穿越爽文 + 镜像喜剧 |
| 第四篇 | 一个人换一袋米 | 负三叶救援；主叶社会因“叶民”而分裂与重组 | 灾难、救援、社会 |
| 第五篇 | 启明 | 去九百年后的宋文明；诸界议会成立 | 星际与政治 |
| 第六篇 | 四梦 | 作者的四个梦，按 PR #93 的伦理方案写（梦、第三方视角） | 抒情与圆满 |
| 第七篇 | 零点 | 枝心年夜饭；五十四分贝；多个结局同时成立 | 交汇 |
| 尾声 | 太子已死 | 临终与重生，未完待续 | 开放 |

**横穿全卷的一条细线**：每到除夕，不论正在哪一篇，都插一节《岁朝》：他在梦里上一天朝。读者会发现，第八部的每一个除夕都有两个春节，一个在益阳，一个在晏朝。

**章内分节的写法**：节标题可以用叶地址加时间地点，例如“〔a〕二〇四四年，资江宫”。读者前三次只觉得是装饰，第四次会突然看懂地址的规律。这一手法只在交汇篇大量使用，其余篇章用普通的一、二、三。

**不设章数和字数。** 我估计第一篇需要十到十五章才能把发现史写透，第二篇是全卷最长的一篇；但我不预定数字。每一篇写到故事真正兑现为止。

## 七、我认为现有设计里最值得保留、重构、舍弃的

**保留**
- GPT-6.2 V2 的“科学阶梯”分层法（实证 / 理论 / 公设），以及它对复联4“不复制装置”的判断。
- PR #100 的十二种爽感清单和“胜利之后的生活”原则。
- PR #93 的三条发现：称呼即平行人生的名单；西安让梦一的元素在现实里自己发生；这段关系几乎全部由别人传递。还有《礼堂》《房东》《佑霖》《年夜饭》四场试写。
- R3 的世界账字段，作为后台工具。
- 作者四个梦的核心命题：“这一次，我有没有向前走一步？”

**重构**
- RCD 换成 HCH：它从主人公自己的课程长出来，有更强的可证伪预言（除夕峰、元旦时区潮），也有更锋利的情感规则（己史封闭）。
- 岚朝换成真实北宋 + 原创晏朝：真实历史给知识型爽感更硬的地面（沈括、毕昇活字、汝窑、熙宁变法），原创王朝给帝位以自由。
- GPT 的原创人物表（沈知衡、许澄等）我没有沿用，另起一套（见 `05`）。不是因为它们不好，是因为三方各出一套，最后整合时选择会更多。
- PR #93 的“只交汇一次”改为“零点可以多次交汇，但最大的一次在终篇”。
- PR #93 的结尾“真实的回家”保留为结局之一，不再是唯一结局。

**舍弃**
- 25—35 万字、36—48 章、40 章 43 万字等一切旧容量。
- “每个圆满世界必须有代价”的残余逻辑。HCH 的等质交换是对称，不是惩罚。
- 用大段“这不是真的”的声明保护边界。边界在结构上一次说清（卷首一页 + 叶的语法），正文放开写。

## 十、结局：多个同时成立

1. **真实的回家**（PR #93）：现实的二〇二七年春节，梅城，他数椅子，数一遍就对了。
2. **零点**：枝心的年夜饭，所有的他一起倒数，数到“一”时，节尾停住。
3. **王冠**：我们叶的继承抽签，签筒里抽出一个名字，节尾不写是谁。
4. **启明**：交换生叶的他在宋朝老去，最后一次除夕没有回益阳。
5. **太子已死**：主叶的他八十岁临终，画对了最后一个圈，睁眼，有人喊殿下。全书不在这里结束，在这里开始下一本。

我推荐 1 + 5 + 2 的组合：先回家，再死，再重生，最后一页是倒数。这个组合同时给出圆满、史诗和未完待续。

## 十一、怎样在写作中动态调整

1. **先写第一篇的前三章和序**，用它们检验 HCH 在小说里是否好读。如果物理压住了人，就削减公式，保留数字的身体。
2. **第二篇和第三篇可以并行开写**，因为它们几乎不依赖彼此。哪一篇写得更好，就让哪一篇更长。
3. **每写完一篇，更新一次叶表**：增加的叶、废弃的叶、改了规则的叶。规则只在故事需要时改，改了就在后台登记。
4. **四梦最后写**，等作者读过前面的篇章，再决定哪个梦写成梦、哪个写成第三方视角。
5. **如果某一叶写不动，就放下它。** 黎曼面不要求每一叶都被走过。
