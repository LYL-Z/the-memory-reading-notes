# 世界与帝国｜四种王座、一场救援、一个九百年后的文明

Claude 独立设计｜2026-11-24｜架空政治史与文学思想实验，不是现实行动方案

作者的原话：“我在现代通过各种方式先建立一个共产主义与帝制相结合的帝国，再逐步统一全球，建立合适专政的统一帝国”；“穿越”；“重生与梦境”。下面四种王座全部回应这三条，每一种都可以独立成书。它们讨论合法性、所有制、继承与权力的代价，但不提供现实中夺权、镇压、监控或操纵人群的方法；帝国的成就与问题都在虚构世界里发生。

## 一、我们｜现代帝国：最后一个签字的人必须会死

### 1. 这一叶从哪里分岔

二〇二七年，大二下学期。现实里他在物理强基、华为俱乐部、AI 实践课和“数据收纳”项目之间打转（第一部 001、第七部 020）。在这一叶，他退学了。这就是 PR #93 的“刘总”一线，我把它一直推下去，推到王座。

### 2. 帝国是怎么来的（虚构历史）

| 时期 | 发生了什么 | 他做了什么 |
|---|---|---|
| 2028–2031 | AI 自动化引发“大停摆”：大量白领与服务工作在三年内消失，物价下跌、税基崩塌，多国政府无力维持社会保障 | 他的公司“公栈”把一个开源模型、一批闲置算力和十几座小水电站捆在一起，做成一个**算力合作社**：用户贡献数据和劳动，按月领取“算力分红” |
| 2031–2035 | 合作社在湖南、川渝、东南亚扩张，开始经营自动化农场、物流和能源；它比政府更快把米和电送到人手里 | 他把公栈改组为**公有制**：所有算力、能源和模型归全体成员共有，他本人只保留一票 |
| 2035–2041 | 城市、省份、国家陆续通过公投加入“大同联合”；联合的宪法以《礼记·礼运》的“天下为公”为序言 | 他被选为联合的首任执行长，任期十年 |
| 2041 | 第一部宪法修正案：联合的最高决策由 AI 系统提出，**但最后签字的必须是一个会老、会死、会被骂的人**。各成员一致推举他为终身“共主” | 他接受王冠，条件是宪法写明：君主自称“我们”，不称“朕” |
| 2041–2060 | 最后几个未加入的地区经过长期谈判与公投加入。全球统一 | 统一大典在资江边的新都举行 |

### 3. 为什么是王座，不是总统

这是这一叶最原创、也最值得写的政治思想：**在一个 AI 能替人做绝大多数决定的时代，人们宁愿要一个会死的人站在最后，也不要一个不会死的算法。**

- 君主是“人类在环”的最终形态：所有 AI 提案都要经过他签字，否决权只属于人。作者说的“合适专政”，在这里成了**人对机器的专政**。
- 王冠是一个符号：它让十亿人知道，这个文明的最终责任落在一张会老的脸上。
- 他之所以是终身的，是因为人们不想每四年重新决定“谁替人类对机器说不”。

### 4. 共产主义与帝制：张力不回避

马克思意义上的共产主义是无阶级、国家消亡的社会；世袭君主与之有根本冲突。我不把二者假装成和谐，而是让这对矛盾成为这一叶的发动机：

| 制度 | 怎么运转 | 谁满意，谁不满 |
|---|---|---|
| 生产资料公有 | 算力、能源、模型、土地归“大同”全体所有，AI 负责调度 | 多数人有饭吃、有房住、有大量空闲；也有人觉得自己成了被供养的人 |
| 按需分配 | 基本生活品免费；奢侈品用“荣分”换，荣分来自公共服务、创作、照护 | 年轻人喜欢；老一代问“那我一辈子攒的钱算什么” |
| 共主 | 终身、自称“我们”、签字、否决 | 他的支持率很高；他自己最清楚这不等于正当 |
| 大谏院 | 宪法唯一能否决共主一次（每年一次）的机构，首任大谏是贺兰序 | 她是他最强的政敌，也是他的爱人 |
| 继承 | 宪法未定。这是全篇最大的悬念 | 见下 |

### 5. 坏皇帝问题与继承

福山把“坏皇帝问题”称为中国政治史上从未真正解决的老问题：集权体制里一个坏统治者造成的伤害远大于民主体制。这一叶的后半段整个围绕它：

- **他是一个好共主。** 这正是问题：好共主之后呢？
- 三种方案在宪法会议上竞争：
  1. **血亲继承**：他的女儿刘晏（原创人物）。民意最高，因为人们喜欢她。他本人反对。
  2. **抽签继承**：在通过“四十年考”的公民中抽签（雅典的抽签制）。贺兰序支持。
  3. **AI 推荐**：AI 给出最优候选，共主签字。AI 自己建议采用第三种，这让所有人不安。
- 结局见 `06`：签筒里抽出一个名字，节尾不写是谁。

### 6. 皇家生活：赢了以后过什么日子

这一叶必须写大量“胜利之后”：

- **资江宫**：新都建在益阳资江边。宫殿不高，横着铺开，沿江有一条长廊，冬天江风很大。宫里最讲究的是厨房：益阳腊肉、安化黑茶、梅城擂茶，御膳房的总厨是从桃江挖来的。
- **奶奶不搬**：奶奶拒绝搬进资江宫，“我住不惯”。共主每个月回一次梅城十里村，坐在奶奶家门槛边吃擂茶。全世界的媒体都在拍那条村道。奶奶对着镜头说：“莫拍了，拍了也冇得么子好看。”
- **父亲**：父亲在宫里有一间茶室，泡茶不用宫里的茶，用自己从东坪带来的。外国元首来访，父亲倒茶，倒到第三杯说“一个一个来”。
- **母亲**：母亲被任命为“大同统计总署”的荣誉顾问（她做了半辈子渠道和报表），她觉得这个头衔“好笑”，但每一份季度报表她都真的看。
- **大典**：统一大典上，一百九十多个地区的代表依次入场；他站在资江边的台上，讲了四十分钟（这一生他终于有了一个必须听他讲完的场合）。讲完以后，他第一句话问的是：“厨下有没有粉？”
- **巡游**：他每年用一个月坐慢车巡游，不坐飞机。车上有一节车厢专门放书。

### 7. 不同的人，不同的回答

| 人物 | 对“我们”的看法 |
|---|---|
| 贺兰序 | “你说‘我们’的时候，我从来不知道里面有没有我。” |
| 刘晏（女儿） | 想当一个普通的建筑师，不想被抽签，更不想被继承 |
| 中枢 AI“司南” | 认为共主是一种必要的仪式性冗余；它比任何人都更希望他长寿 |
| 一个大停摆时失业的会计 | 现在过得比以前好，可是“我不知道我每天在为谁干活” |
| 奶奶 | “你小时候讲要当主席，现在当了个皇帝，比主席还大？” |

### 8. 开放问题

- 一个所有人都过得更好的制度，如果它不是你们选择的，你会接受吗？
- “我们”这个人称，是谦逊还是吞并？
- 当机器做得比人好，人还应该保留最后一票吗？为什么？

## 二、交换生｜真实北宋：一箱青霉素换一箱汝窑

### 1. 规则

主叶的叶门在 2041 年除夕零点与一张宋叶的 1076 年（熙宁九年）除夕零点锚定。等质交换：他过去，同样质量的东西或人过来。门每年除夕开一次；他每年可以回一次家。

### 2. 为什么选北宋熙宁、元丰年间

- **沈括**（1031–1095）在这一时期活跃：他记录了地磁偏角、毕昇的活字印刷，提出“十二气历”，主持过历法与天文仪器工作。一个现代物理学家和沈括一起量地磁，这是真实历史给的硬地面。
- **熙宁变法**：王安石的青苗法、市易法等，是中国史上最大规模的一次财政改革；统计、会计、货币问题正是现代人能帮上忙、也最容易帮倒忙的地方。
- **汝窑**约在北宋后期为宫廷烧造，传世极少。他用药品、种子和书换回的宋代器物在主叶价值连城：这是主叶“零点公司”早期财富的一个来源（作为虚构设定，不对应现实文物市场的任何具体交易）。
- **前作先例**：网络小说《新宋》（阿越）写现代人到熙宁年间，《赘婿》《绍宋》写宋或仿宋世界的改革与救亡。我们的区别：主人公是物理学家，不是历史学者；他每年回家一次；他知道自己的作为会在另一张叶上长成一个九百年后的文明（见第三节）；以及一个宋代女子同时来到现代。

### 3. 爽感从哪里来

| 阶段 | 他做成的事 | 爽在哪里 |
|---|---|---|
| 第一年 | 用指南针、日影和一张自己画的星图，帮沈括核对地磁偏角 | 智识快感：两个相隔九百年的人在同一张纸上算对了 |
| 第二至五年 | 和书坊主柳含章办“汴京小报”，把活字印刷做成日报 | 信息革命；他第一次在宋朝“被很多人叫到名字” |
| 第五至十年 | 改良炼钢、度量衡统一、为熙宁变法设计账目与统计 | 治理快感；真正改变很多人的生活 |
| 十年后 | 靖康之变还有四十年。他决定改变它 | 史诗：一个人能不能救一个王朝 |

### 4. 限制

- 他知道的东西远远多于宋朝能制造的东西。“知道青霉素”不等于能在宋朝生产青霉素（这一叶的一大段写他和工匠失败了十一次）。
- 他每年只能带一个人的质量过去、带一个人的质量回来。
- 他在主叶的家人、爱人、公司都在等他每年回来一次。

### 5. 镜像：岑小满在成都

第一次交换，他过去，回来的是一个宋代女子：岑小满，二十二岁，汴京书坊的学徒，柳含章的表妹。她落在成都叶门实验楼的交换托盘上，手里还攥着一根点爆竹的线香。交换按位置进行：他出现在她站过的汴京院子里，她出现在他站过的托盘上。她这一线可以写成全卷最好笑也最好看的穿越者故事之一，只是方向反过来：

- 她第一次看见路灯、电梯、外卖，第一次听人说“汴京后来叫开封”；
- 她查到了这一张叶（主叶）的历史：北宋亡于 1127 年。她哭了一整夜，然后去川大图书馆借了所有关于宋史的书；
- 她成了主叶最懂北宋的人，也成了主叶第一个“叶民”；
- 启明叶的史书里记着一句：“刘公来时，有一女子去彼岸，再未归。”

## 三、启明｜一个九百年前就有过刘公的文明

### 1. 是什么

另一张宋叶。它在 1076 年也来过一个刘佑林（另一张主叶上的另一个他）。九百六十多年后，这张叶的“现在”是 2041 年：宋的后裔文明已经把探测器送到木星，首都仍叫汴京，城中心有一座雕像，底座上写着“刘公”。

### 2. 为什么它是全卷最好的反转之一

主叶的他通过叶门第一次连上启明叶时，对方的档案馆员平静地说：“我们知道你。你是刘公。”

他还没去宋朝。

H8（选择而非创造）让这件事在物理上不矛盾：有许多个他，其中一个在九百年前去了。可是在情感上，这是一个巨大的问题：**伟大是一件已经发生过的事，还是一件我必须亲自去做的事？** 他站在自己的雕像前，雕像比他老，比他高，手里拿着一个指南针。

### 3. 启明的文明

- 政体：君主立宪的“宋”，皇帝是一个礼仪职位，宰执由科举加选举产生。
- 科技：比主叶领先约两个世纪；但他们没有发现叶门的共时锚，因为他们的历法不同，除夕不是全民同一秒数到零的节日（他们用“十二气历”，沈括真实提出过的太阳历）。
- 不扰律：他们有能力干预其他叶，却立法只在被呼叫时回应。
- 他们怎样看主叶：一个“没有刘公的宋亡之叶”，像看一个没有牛顿的世界。

### 4. 诸界议会（G）

主叶、我们、启明、负三和陆续接通的几十张叶组成一个议会。议题：

- **叶际隐私法**：能否读取另一张叶上可识别个人的记录？主叶坚持必须得到本叶对应者的同意；我们叶认为“公共利益”优先；启明叶说他们早就禁止了。这条法律在小说里和本项目的真实人物权益原则是同一条：**你可以在别的世界里看见一个人，但你不能替她说她想过什么。**
- **救援义务**：先进叶是否有义务救援濒死的叶？谁来承担等质交换的物资？
- **技术输出**：启明叶的技术能不能给主叶？给了，主叶的历史就不再是主叶自己的历史。
- **刘佑林们的投票权**：同一个人在议会里有七张脸。他们投票从来不一致。

## 四、岁朝｜梦里的皇帝，一年只上一天班

### 1. 规则

梦联（L2）锁在共时锚上。主叶的他从二十岁起，每年除夕夜都会做同一个梦：他是晏朝的皇帝，梦里是元正大朝会（唐宋都有真实的元日大朝会制度，晏朝是原创王朝，借其形制）。梦里过一天，醒来是正月初一。下一次是下一年的除夕。

### 2. 为什么好玩

晏朝的皇帝一年只出现一天。其余三百六十四天，朝廷自己运转。

- 第一年，大臣们惊慌失措，以为皇帝中了邪。
- 第五年，朝廷发明了一整套制度：一年一度的“岁奏”，把一年的大事压缩成一天能听完的奏报；“代朝”由宰相主持；宫里有一个专门的官职负责“记住陛下去年说过什么”。
- 第二十年，民间开始传说皇帝是神，一年才下凡一天。
- 第四十年，他在梦里已经有了白发苍苍的宰相，长大成人的皇子，以及一个从没见过他第二天样子的皇后。

这是对“坏皇帝问题”的另一种喜剧回答：一个一年只来一天的皇帝，坏不到哪里去，也好不到哪里去。真正统治的是那套为他的缺席而发明的制度。

### 3. 和主叶的关系

主叶的每一个除夕，读者都会看到两场：益阳的年夜饭，晏朝的大朝会。他二十岁时在晏朝刚登基，四十岁时晏朝已经繁荣了二十年，八十岁时晏朝的皇子已经老了。主叶的生活和梦里的王朝一年一年同步老去。

### 4. 开放问题

晏朝存在吗？梦联是 L2 物理，还是只是一个梦？全卷不回答。晏朝的宰相在最后一次大朝会上问他：“陛下，您在别处，过得好吗？”

## 五、太子已死｜临终重生

### 1. 规则

L5 空锚：意识只能进入一具对应者刚刚死去、身体尚可救的躯体。这是“魂穿”的唯一合法入口：不杀人，不覆盖活人。

### 2. 故事

主叶，2087 年。八十岁的刘佑林在成都的病房里临终（PR #93 的“四人间”可以就在这里）。他在纸上画了最后一个圈，这一次画对了，没有把奇点圈进去。他闭上眼睛。

他睁开眼睛。有人在喊：“殿下醒了！”

这是另一张叶上一个原创王朝的太子，十八岁，刚刚死于一场高烧。全书在这里不结束，而是开始下一本。

### 3. 为什么作尾声

- 它同时满足“开放结局”“未完待续”和“爽文的下一部”。
- 它把第一篇第一章的那个圈收回来：一生从一个画错的圈开始，到一个画对的圈结束。
- 它让读者知道：在这本书里，死亡也只是一次绕行。

## 六、负三｜一个人换一袋米

### 1. 这一叶

2039 年，这一叶发生了有限核战争，随后进入核冬天。2040 年除夕零点，主叶收到第一串来自负三的比特：一段求救。

### 2. 等质交换的人道学

要救一个人过来，就要送同样质量的东西过去。最合理的是粮食和药品。一个六十千克的人，换六十千克的米、药和种子。

- 救援变成一门精确到毫克的物流学（门口差一微克就是二十一千克炸药）；
- 主叶的“零点公司”和我们叶的帝国一起建起了上百座叶门；
- 谁先过来？儿童优先？抽签？按技能？每一种规则都有人反对。

### 3. 主叶的社会

几十万“叶民”来到主叶。这一篇写当下真实的社会问题在科幻里的投影：移民与排外、就业竞争、身份证件、语言（负三叶和主叶分岔于 1990 年代，口音几乎一样，用词有细微差别）。

最锋利的情节：**有人在叶民名单上看见了自己已经去世的母亲。** 负三叶的她还活着。她是不是我妈？她该住在哪一家？

主人公自己的版本：负三叶的父亲被救了过来。主叶的家里突然有两个父亲。两个人在茶桌边抢着倒茶，最后各倒一半。母亲说：“你们俩一个一个来。”

### 4. 开放问题

- 你愿意为另一个世界的陌生人少吃一碗饭吗？
- 一个和你父亲完全一样、却没有和你一起生活过的人，是你的父亲吗？
- 救援的权力属于谁：发明门的人、拥有门的公司，还是需要被救的人？

## 七、四梦与佑霖、主席、零

## 八、世界之间的“账”

每张叶在后台记录：

| 字段 | 说明 |
|---|---|
| 地址 | 自由群里的一个字，或“梦联”“文学并置” |
| 分岔点 | 哪一年、哪一件事、谁做的选择 |
| 与主叶的连通方式 | HCH / 梦 / 零点同席 / 不连通 |
| 本叶时间 | 本叶当前年份；与主叶的锚定偏移（例如交换生叶 −965 年） |
| 本叶的他 | 年龄、职业、称呼、还保留的毛病 |
| 真实人物出现处 | 是否性化（必须为否）、是否内心证词（必须为否）、授权状态 |
| 本叶的开放问题 | 一句 |

账只在后台。正文里，读者通过人称、语气、地名和那些每一叶都还在的小毛病认出自己在哪一叶。
