# 长期创作计划｜怎样把一张黎曼面写成一部书

Claude 独立设计｜2026-11-24｜不预定总字数与章数

## 一、原则

1. **先写能证明发动机的部分。** 叶理论能不能在小说里好读，只有写出来才知道。所以第一批写序和第一篇前三章。
2. **每一篇都要能独立读完。** 一篇写到它的大高潮和高潮后的生活，才算交付。
3. **篇与篇可以并行。** 第二篇（我们）与第三篇（交换生）几乎互不依赖，可以由不同的写作批次同时推进。
4. **规则只在故事需要时改。** 改了就在后台的叶表与科学圣经里同步，并写明改了什么、为什么。
5. **作者读过之后再写四梦。** 四梦涉及真实人物和作者最私人的愿望，应当在作者读过前面几篇、对第八部的整体语调有判断之后再写。

## 二、阶段

| 阶段 | 内容 | 交付 | 作者需要决定的 |
|---|---|---|---|

## 三、每一批正文的工作方法

1. **读**：本章相关的前七部章节（亲读，不靠摘要）；事实仓相关人物页；科学圣经相关一节。
2. **写**：直接写连续正文。卡住的章节试几种开头，顺畅的直接往下写。一章可以很多节。
3. **核**：物理公式与数值用脚本复算；历史细节查证；前七部的空间、时间、称呼逐项对照（例如江安寝室是左右两张床，不是上下铺）。
4. **读声音**：朗读或通读一遍，删去只有解释、没有生活的段落。
5. **交付**：正文 + 极短的后台记录（叶表变化、新增人物、真实人物出现处、待作者裁定的事）。

## 四、怎样防止越写越散

- **主叶是脊梁。** 不论写到哪一篇，读者都知道主叶的他在哪一年、几岁、在做什么。每一篇开头一节用一个主叶的时间锚（通常是一个除夕）。
- **毛病是指纹。** 每一叶的他都保留抢先、话说满、写规矩补“尽量”、打钩。写着写着失去了这些，说明人物跑偏了。
- **零点是节拍器。** 全卷每一个除夕都是一次可能的交汇。读者会自然地把除夕当成章节的呼吸。
- **一篇一个大问题。** 第一篇：能不能看见别的人生；第二篇：最后签字的人该是谁；第三篇：知道历史的人能不能改变历史；第四篇：救不了的人怎么办；第五篇：伟大是已经发生的还是要去做的；第六篇：这一次有没有向前走一步；第七篇：哪一个是我。

## 五、风险与对策

| 风险 | 对策 |
|---|---|
| 物理压住人物 | 公式只在改变选择时出现；长推导放进章内“研究手记”小节 |
| 爽感变成堆砌 | 每一次胜利都有可见过程；每一次胜利之后至少一节生活 |
| 帝国线变成政治说明书 | 每一项制度都落到一个人身上：会计、奶奶、贺兰序、刘晏 |
| 宋线变成“现代人秒杀古人” | 知道 ≠ 能造；沈括会当场指出他画错了 |
| 世界太多 | 允许某些叶只写一章，甚至只在零点的饭桌上出现一次 |
| 真实人物越界 | 结构解决：梦、第三方视角、记录读数；叶际隐私法让小说内部也遵守这条 |
| AI 腔 | 每一篇交付前，抽查三段：它能不能放进别的小说？能，就重写 |

## 六、与其他模型的协作

- **GPT-6.2**：整合三方方案；独立复核 HCH 的物理与统计；查证北宋与沈括；检查跨篇一致性。
- **Grok**：独立方案；读者体验与爽感评价；专门找叶理论规则的漏洞。
- **Claude**：主创连续正文。
- 三方都不替其他模型越界；最后的取舍由作者做。
