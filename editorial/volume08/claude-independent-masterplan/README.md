## 一句话

一个十九岁的物理系学生把留数题的第二个圈画大了，圈进去一个奇点；二十年后，他用这个错误打开了时间的虚部，看见了所有没有发生的人生，唯独看不见自己的过去。

## 这一轮的四个发现

1. **书名里本来就藏着物理。** “复数”是“不止一个”，也是 a+bi。2026-10-31 的书名页写过“正文不讲复变函数”；第八部讲。它从第七部 012 那个真实画错的圈开始。
2. **书名还预言了皇帝。** “复数人称”也是君主自称的“我们”（royal we）。现代帝国的宪法规定：君主不称“朕”，只称“我们”。
3. **所有世界相交的地方是除夕的零点。** `log z` 的所有叶在 z=0 处相交；十几亿人在同一秒数到零。原创公设“共时锚”让这件事成为物理，并给出可证伪的预言（除夕峰、元旦时区潮、峰形等于全国电视信号延迟的分布）。
4. **能看见所有别的人生，唯独看不见自己的过去。** “她听清没有”这一问，科学最后只给他五十四分贝。物理守住了真实人物的边界：任何技术都读不出她当时的心。
