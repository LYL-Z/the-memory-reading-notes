# 定位与卷名｜《我所有的钟》

## 一、卷名

**主推：《我所有的钟》**

理由有四条，按分量排：

1. **它是标题的下半句。** 全书叫《时间的复数人称》——时间不止一个人称。第八部给出的答案是：**一个人可以同时是好几只钟**，每只走得不一样快，各自记录着不同的历史。第七部结束时他十九岁，桌上只有一个闹钟，定的七点。第八部他有很多个。
2. **它同时是物理的和抒情的。** 钟是仪器，也是钟声。现代线里它是一台铝离子光钟；帝国线里它是观星台上的铜壶滴漏和钟楼。同一个字把科技线、皇家线、古代线缝在一起，不需要任何解释性段落。
3. **它不承诺规模。** 《万世之我：时域纪元》承诺了一个宇宙，而承诺越大越容易兑现不了。《我所有的钟》承诺的是一种关系，这个承诺一定兑现得了。
4. **它自带代价。** "所有的钟"也意味着：钟越多，越难对准。这个双关正是我的代价律（见 [02-physics.md](02-physics.md)）的通俗版。

**备选**（供你选择）：
- 《余隙》——最文学、最冷，适合当分册名而不是全卷名。
- 《校准》——最短、最硬，像一部纪录片的名字；适合做第一部（铰册 I）的书名。
- 《观星台》——只适合帝国线，不能当全卷名。

## 二、定位：这不是"另一种青春"，是一本关于**权力与时间**的书

前七部的权力关系很简单：一个人在名单上找自己的名字，名单是别人写的。

第八部要把这个关系翻过来。他自己写名单：

- 他签一份文件，决定一座城市的供水；
- 他签一份预算，决定一个国家的养老金；
- 他在一份移民名单上写下奶奶的名字；
- 他把一台仪器的校准值写进国家标准，从此全国的表都跟着它走。

**这些签名有一个共同点：它们都是在给别人的时间定刻度。** 这是他这个人从五六岁起就在做的事——给父亲封"资阳区第一厨神"，给客人排日程，给项目写规则，给寝室定分工。前七部里这些动作都失败了或者被笑了。第八部让他真的拥有这个权力，然后问：

> 一个人给别人的时间定刻度的时候，他欠别人什么？

这是全卷的中心，比"他能不能成功"重要得多。

## 三、这本书到底在写什么（三句话版）

1. **前七部**：一个总想当导演的人，一次次发现别人不在他的剧本里。
2. **第八部**：他终于拿到了全部导演权，其中包括给时间本身当导演的权力。
3. **真正的戏**：当所有事都可以重排，那些人**还会不会做出不在他剧本里的事**——以及他为这件事付的账，是不是他付得起的。

第 3 句是我在 Claude 上一轮设计（PR #93）里读到、并且核对自己的理解后认同的判断。我把它推得更狠：Claude 的版本让"别人不听话"成为安慰；我的版本让"别人不听话"成为**代价**——因为在我的物理学里，一个世界越是自己长出自己的记录，你越回不去（真度—通度反比律）。

于是同一件事有了两层：
- 情感层：她有自己的事业、自己的病人、自己的房子，她没有等你。
- 物理层：正因为她有了，你进不去了。

**这两层是同一件事。** 整部第八部的力量，就在这个重合上。

## 四、与七部的具体接口（只列我认为真正能用的七处）

前七部最多的病，是每章找一个旧物件做回响。第八部不需要每章回响，但有几处接口是**天然**的：

| 七部的位置 | 第八部怎么接 | 强度 |
|---|---|---|
| I-001 拍一个陌生女生的背影，"喊了就要有名字，我没有名字可以喊" | 若采用许愿线：让那个背影**回过头**说"你拍的不是我吧"——但不是由他安排的回眸，而是她本来就在看别的东西，转过来只是因为他挡了光 | 极强。这是全书唯一一次可以让"背影"母题闭环的地方 |
| I-007 绝对值题：`|x−1|+|x−3|=a`，a=2 时 1 到 3 之间整段都是解 | 全卷的数学母题：**只有在一个恰好的值上，解才不止一个**。第八部就是那个 a=2 的地方。这句话我不打算写在正文里，只做后台结构 | 强 |
| II-002 在二班名单上找不到自己 | 帝国线：他在一份**移民名单**上签下奶奶的名字。他那年找不到自己，现在他能决定谁能留下 | 强。但需严守：奶奶的迁徙是虚构世界行为，不是现实预言 |
| III-002 紫云山求来的名字，备选"佑霖" | 若采用姓名分叉线：佑霖那条人生不必当主角，可以只出现一次，一次就够 | 中 |
| VI-013 "我保证下次也会记得给你生日礼物的"，回礼一直没来 | **需要一个真正的回礼**。不是她补上，而是他自己在某一年明白：他要的从来不是那件礼物 | 极强，但必须极小心，不能写成索取 |
| VII-014/015 西安五天没加微信；裁掉合照里的陌生人 | 这是全卷离现实最近的地方。我的处理是**不写"如果加了会怎样"**，改写"他现在每天都在做的这个动作"本身 | 极强，风险最高 |
| VII-020 "数据收纳_半成品"，闹钟定在七点 | 科技线的公司从这个半成品长出来。第七章那个"保存按钮的线没接上"的错，在第八部变成一个价值千亿的系统性缺陷 | 强，且技术上极自然 |

## 五、我不打算写的东西（主动放弃，以免堆砌）

这一节比上一节重要。一个方案的价值，一半来自它拒绝写什么。

1. **不写"平行世界的同学都是坏人/好人"的对偶结构。** 真实的人在不同世界里仍是同一个人，只是条件不同。
2. **不写"所有世界最后合成一个"。** 我自己提出三种读法（见 [04-architecture.md](04-architecture.md)），其中"不闭合"是正当结局。
3. **不写"他最后发现一切都是一场梦"。** 这是最廉价的一种取消。
4. **不写"上帝/系统/命运给了他这个能力"。** 能力必须是他在实验室里一年一年挣来的，包括错误的两年。
5. **不写"每个成功都要付代价"的对称报应。** 我的代价律不是道德报应，是**物理成本**，它跟善恶无关：一个坏人跨界也要付，一个好人跨界也要付。
6. **不写"他最终明白平凡的幸福才是真"。** 这是把第八部变成对前七部的道歉。他要的是不平凡，就给他不平凡，并且让他真的活在其中。

## 六、卷内应有的三种"重量"

一本书读起来轻，往往不是因为题材轻，而是因为**没有任何东西有重量**。第八部我认为需要三种重量同时存在：

- **物理的重量**：仪器会坏，数据会被别人推翻，误差不会因为你想通了就变小。
- **制度的重量**：一个决定要通过会议、预算、反对意见、执行偏差，最后才到达一个具体的人。
- **身体的重量**：疲劳、疾病、衰老、怀孕、手术、父母的手开始抖。

三种重量在同一章里同时出现一次，那一章就成了。这是我给第八部定的最高标准，比"爽"更高——因为**爽只有在有重量的时候才爽**。一个没有重量的人打赢了，读者不会高兴，读者只会觉得对方弱。
