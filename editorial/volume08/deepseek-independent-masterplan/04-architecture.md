# 结构｜「册制」：一部可以被重排的长篇

## 一、为什么"章"这个单位不够了

你要求的四件事放在一起，会逼出一个结构问题：

1. 八套架构全部采用；
2. 每章可以分成多个小节；
3. 章与章不必都联动，但巧妙联动更好；
4. 章数、字数、世界数均不设上限。

如果仍以"章"为交付单位，那么"无限扩展"会立刻变成"无限拖"。读者读一个没有边界的东西，会累。

所以我把**交付单位**从"章"改成"册"：

> **一册 = 一个可以脱离全书单独读懂、并且有完整起落的事件群。**
> 一册 8–20 章；一章是一个节拍；一节是一个场景。

这个改变解决三件事：

- 作者可以永远写下去，因为每册自己收口；
- 读者可以随时停下来，因为他读完了一件事，不是读到一半；
- 全书可以"宽"，而不必"长到无法呼吸"。

## 二、三类册

| 类型 | 定义 | 数量建议 | 读者义务 |
|---|---|---|---|
| **铰册** | 推动主线：能力如何增长、代价如何累积、关系如何变化 | 5–8 册，占全卷 40% | 必须按序读 |
| **游册** | 自足世界，自己的人物、自己的问题；与主线只有一丝联系（甚至没有） | 不限，占 45% | 可任意顺序，可跳读 |
| **镜册** | 把前面某一册的**同一事件**从另一个世界、另一双眼睛重写一遍 | 3–5 册，占 15% | 读过被镜的那一册再读 |

**镜册是我最想推荐给你的一样东西。** 它是这本书唯一能合法使用"重复"的地方——因为重复本身就是内容：同一件事在两个世界里真的不一样，而每个人都记得自己那个版本。前七部已经有很好的复调机制（同一件事有不同人的记忆版本），但那个机制在七部里大多用来**承认记错**；镜册把它升级成"**两件事都真的发生过**"。

## 三、三种读法，都在设计之内

这是我认为这份方案最值钱的结构想法：

1. **直读**：只读铰册。得到一部完整的小说，约 60–80 万字。
2. **全读**：铰册 + 游册 + 镜册。得到一部史诗，体量随写作增长。
3. **逆读**：从最晚的一册往回读。因为镜册与游册的时间是交错的，逆读会产生完全不同的意义——一个人先看见八十岁的自己，再看见十九岁的自己。

**因此有一条规定必须遵守：任何一册都不得依赖"只有按顺序读才知道"的信息来完成自己的高潮。** 这是硬约束。它听起来是限制，实际上是解放：它逼你每一册都写出真正的起落，而不是靠"下一册会解释"。

## 四、世界为什么天然是这个分布（不是设定，是推出来的）

按 [02-physics.md](02-physics.md) 的公设 T4（真度—通度反比，`𝒜²·ℛ_W ≤ Λ`）：

| 世界类型 | 记录密度 ℛ_W | 可达性 | 文学后果 |
|---|---|---|---|
| 梦境 | 极低（几乎无档案） | 最好进，最不清晰 | 最亲，最不可靠 |
| 架空王朝 | 低（有史官，但只记国家不记个人） | 可进 | 可久留，可参与 |
| 真实古代 | 低 | 可进 | 需查证，风险高 |
| 远未来 | 极高 | 几乎不可进 | 每一次都是天价 |
| 现代平行世界 | 极高 | 基本不可进 | **否掉廉价方案** |
| 本世界 | —— | —— | 主线 |

**这张表直接决定了全书的形状**：古代与梦境多，现代平行世界少。而这样安排不是因为你喜欢古装，是因为**只有记账少的世界才通得过**。

更妙的是它的反向用法：主角在帝国线里最大的功业之一是**修史、办学、立户籍**。这些功业每完成一样，那个世界就离他远一步。**功业与失去是同一个动作。** 这是我从这条公式里读出来的唯一一个真正的悲剧结构，我认为它足以撑起一整卷。

## 五、八套架构在册制里的位置

你说的 A–H 我全部保留，但重新分配权重。**不是八条等长的线，是三个承重墙 + 四个空间 + 一个容器。**

| 系统 | 在册制里的形态 | 权重 | 说明 |
|---|---|---|---|
| **A 爱情人生** | 2–3 册游册 + 贯穿全卷的关系线 | 承重墙 | 不许压缩。它是全卷唯一能写"活着"的地方 |
| **B 皇家帝国** | 每类 2–4 册（现代／穿越／重生梦） | 承重墙 | 三类各自独立成册，不硬合 |
| **C 科技事业** | 4–6 册铰册 | 承重墙 | 主线骨架，代价律在此显形 |
| **D 文明救世** | 2–3 册游册 | 空间 | 放在中后段，早期不加码 |
| **E 时域机制** | 不单独成册，织进 C 的铰册 | 骨架 | **机制不该有自己的册**，它应该在每一册里做事 |
| **F 家庭复数人生** | 2–4 册游册 + 镜册 | 空间 | 用来写父母、奶奶、另一条自己的普通一生 |
| **G 跨时空治理** | 1–2 册，放在最后三分之一 | 空间 | 早了会变成会议记录 |
| **H 万世之我** | 不是一册，是**整卷的组织原则** | 容器 | 它不占章节，它决定册序 |

**我要特别说 E。** 上一轮的几个方案都给了 E 一套独立的情节（"接收到陌生信号""第一次跨世界握手"）。我认为那是错的：**机制一旦有了自己的章节，它就变成了设定展示。** 机制应该永远作为"手段"出现在别人的故事里——他在修历法时用到它，他在追一个病人时用到它，他在董事会上判断一份报表真假时用到它。

## 六、册序（建议版，非冻结）

```
铰 I《校准》22章 ── 现实线 → 科研线；第一次渡
   ├─ 游《观星台》16章 ── 岚朝；历法与失闰
   ├─ 游《两把钥匙》12章 ── 独立成年关系；日常的重量
铰 II《账单》18章 ── 代价显形；团队分裂；M4 借隙首次被提出
   ├─ 镜《同一天的四个人》10章 ── 重写铰 I 第 20 章，四个视角
   ├─ 游《持股王朝》14章 ── 现代帝国；王冠与章程
   ├─ 游《续梦》12章 ── 梦境世界自行生长
铰 III《真度》20章 ── 他为救一个世界而让它变得不可达
   ├─ 游《普通的一生》14章 ── 佑霖线；不做主角的一生
   ├─ 镜《雨》8章 ── 重写《观星台》的登基前夜
铰 IV《借》22章 ── 向未出生者征税；帝国的选择
   ├─ 游《月背的学校》14章 ── 文明线
   ├─ 游《一年》10章 ── 纯家庭册；不推进任何主线
铰 V《我所有的钟》24章 ── 收束；开放
```

合计：铰册 5 册 106 章；游册 7 册 92 章；镜册 2 册 18 章。**约 216 章，45–65 万字。** 这不是目标字数，是当前结构的自然结果。要不要写到三百万字，取决于你已经写到第几册时还有没有新东西可说——而册制保证了"随时可以停在一个完整的地方"。

## 七、回声规则（防止"每章一个旧物件"的病）

前七部最容易被读者识破的手法，是每隔一段就回响一个旧物件。第八部需要回响，但需要一条纪律：

1. **每册最多一次回声。** 超过一次，它就变成签名，不再是回声。
2. **回声必须是物质的，不能是解释。** 可以是一把钥匙、一个塑料坠子、一句"一个一个来"；不可以是"他想起很多年前……"。
3. **回声必须改变含义。** 同一个物件第二次出现，必须在不同的功能位置上（第一次是工具，第二次是遗物）。
4. **不许在回声处停下来解释。** 出现，然后继续往前走。

## 八、世界账：最小字段

后台每册一页，不进正文。字段沿用 R3 的骨架，加三个我需要的：

| 字段 | 说明 |
|---|---|
| `fascicle_id` / `world` / `type`（铰/游/镜） | 册与世界的编号 |
| `local_calendar` / `age` | 该世界的历法与主角年龄 |
| `T_event` / `T_person_knows` / `T_reader` | 事件、人物知情、读者知情，三者分离 |
| `δ`（隙宽） | 本册结束时，主角所在地点的可分辨度 |
| `ℛ_W`（记录密度） | 本册结束时，目标世界的记录密度（对数标度） |
| `𝒜` | 本册中达到的最大耦合振幅 |
| `debt` | 已欠未付的代价（谁在承担） |
| `echo` | 本册唯一的一次回声 |
| `rights` | 涉及的真人、授权状态、可发表性 |

**`δ` 与 `debt` 是这套账的关键。** 前七部有人物账、事实账，但没有**代价账**。第八部如果没有代价账，写作到中期一定会忘记自己收过什么钱。

## 九、我拒绝的一种结构

**轮流上场制**（每一轮里五条线各出一章，读者横向比较同一个年龄的五个人）。

它在纸面上很整齐，在阅读中会很闷。原因很简单：**读者在意的是"然后呢"，不是"同时呢"。** 当读者正跟着一个人在实验室里等一个数据，你把他切到另一个人的婚礼，他不会有比较的快感，他会有被打断的恼怒。

册制解决这个问题：一册之内不切，一册读完了自然想换。**切换的权力交给读者，不交给目录。**
