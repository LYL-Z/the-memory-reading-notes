## 一句话

前七部写一个人怎样在别人的名单上找自己的名字。第八部写他拿到了给自己计时的权力——然后发现，**每一次跨到另一种人生，代价不是血、不是钱，而是他再也分不清自己身上发生过什么**。

## 我提出的核心，不是世界数量，是一条代价律

GPT-6.2 的 V2 给了一套可用的容器：八个架构全用、硬科幻开篇、皇家三类、章节可含任意小节。这些我全部接受，但容器里装什么，我给出了一套不同的东西。

我提出 **「钟隙理论」**（虚构科学公设）：时间序只在测量它的那只钟的分辨宽度内被定义。真实钟的资源有限，因此每一段短于该宽度的时间里，「哪个先发生」没有事实。要让两个历史世界彼此耦合，必须把自己的钟**变粗**；而粗化是**不可逆**的。于是：

> **跨界不收命，收「可读性」。**
> 每过一次，你的世界永久失去一段可以分辨的时间。

这条律法解决了几件别的东西解决不了的事：

1. **它给穿越定价。** 不是"每次许愿折寿一年"那种道德主义，而是可测量、可累积、可在数据里先于理论被发现的物理代价。
2. **它让叙事本身成为主题。** 全书讲的是不可靠记忆；代价恰好是"不再能确定哪件事先发生"。物理学收的账，就是这个叙述者的老毛病。
3. **它让世界之间不能无限互刷。** 越常往来，两个世界越模糊；想保住一个世界的清晰，就必须少去。
4. **它给帝国线一条骨头。** 岚朝的"薄处"使历法持续漂移；**改历、失闰、颁正朔因此不是文化点缀，是穿越的账单**。皇权的合法性建立在守时上。

配套的第二条律，是我认为全卷最有情感力量的一条：

> **真度与通度成反比。** 一个历史世界内部越清晰、居民越有自己完整的记录，它与本世界的耦合就越弱。
> 你越帮一个世界变得真实，你越回不去。

这一条直接接住前七部那件事：一个人想替别人保管记忆。第八部把这句话变成一个物理事实的残酷版本——**你把她写清楚的那一天，门就关了**。

## 我不同意的三处旧设计

1. **"八套架构全部采用"不等于"八条线都要长。** 我的方案里，A（爱情）、B（皇家）、C（事业科学）是承重墙，D（文明）、E（机制）、F（家庭）、G（治理）是承重墙之间的空间。把八个都写成同等体量，会得到八本中篇拼在一起。见 04。
2. **"每章可以有多个小节"是对的，但"章"作为单位已经不够用。** 我改用「册」作为交付单位，一章只是册内节拍。见 04。
3. **不设总字数上限是对的，但不能没有"完成"的定义。** 我给出一个非字数的验收口径：**一册 = 一个可以脱离全书单独读懂、并且有完整起落的事件群**。见 11。
