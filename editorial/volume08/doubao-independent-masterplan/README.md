## 一句话

第八部应当是一部「得到」之书：一个学会了不问的人，被允许问、拿、说完、赢、爱、统治、拯救，然后发现真正的得到是被人记着。发动机不是世界如何连接（RCD），而是**一个人如何保存他想要的东西**（保存问题）。

- 取 GPT-6.2 的硬科幻雄心、制度松绑、真实人物保护、八架构题材方向；把重心从「治理一部大书」移到「一根欲望脊柱」。
- 取 Claude PR #93 的散文精度、物件承重、真实人物保护；把「无机制·克制收束」换成「硬科幻机制·圆满与代价同帧」。
- 原创：记录一致性物理（R1–R4）、版本控制作为叙事语法、帝国作为开源治理、维护者反转。

## 边界（绝对）

真实人物不虚构私密性史/不色情化；正面回应只在标记虚构层、以用户确认层为上限。未成年人年龄适当/绝不性化。现代帝国是架空思想实验。成熟亲密热烈而非露骨，不跨模型规避限制。不写入事实源仓，不改前七部与第九部，不覆盖 main 制度。

## 给整合者的话

本方案最可贡献的三件：①「保存问题」发动机（从第七部末章已写好的保存按钮长出，零新增设定成本）；②版本控制作为统一叙事语法（硬科幻＋结构＋人物动作三合一）；③维护者反转（爽文与文学在同一反转合流）。最该被质疑的：记录一致性物理是小说公设，须防止读者当真；帝国开源治理类比须防止把政治简化为工程。
