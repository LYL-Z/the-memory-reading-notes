# 这部书已经写成什么样

判断只建立在阅读账里我自己读过的章、章程和四个梦的原文结构上。Claude 的 02 号笔记我读了，它很有用，下面凡是我没有在正文里亲眼看见的情节，都不当作我的证据。

## 他是一个把话说满、又不断被别人纠正的人

第一部 001 里，他一张桌子上同时开着物理、新闻、代码和游戏。曾子沣催他进队列。他把热茶兑淡，喝得很快，还是要坐着喝，因为家里是那样。他拍了一个不认识的女生的背，知道拍的不是赵问竹，还是看了又看。喊了就要有名字，他没有名字可以喊。

第一部 018 里，真心话玩到他面前。他差一点把“我喜欢赵问竹”说成讲给喻翰东听的故事标题。他转过身，对着她说“我喜欢你”。她没有立刻接。他心里只剩一句：她听清没有。然后有人笑，她也笑了。历史老师还在讲别人的过去。

第七部 012 里，他让阻尼曲线变得好看，周期却随着步长改变。曾子沣问他特征时间。他说不知道哪个过程更快。曾子沣说，那你就是在瞎试。后来难看的那张图，他知道它为什么折。他给父亲看，父亲说看不懂，他又改成“像弹簧”，父亲说挺好。氢原子的式子能把实验算到小数点后好几位，他激动，是因为没听懂但知道它重要。留数那一课，他为了把圈画圆，把奇点圈了进去。他怕旁边的人问为什么。晚上他想把漂亮解答粘进笔记，又硬着头皮自己写，漏了解析性条件。纸上第二个圈终于没把奇点包进去。曾子沣叫他吃饭，他说等一下，把线往外挪了两毫米。

第七部 020 里，食堂里有人听完他讲供应链，问：那你做了什么。他做的小工具会弹出“已保存”，写入没有接上。样例数据每次都在，像一对假证人。他把提示删了，去读真正写数据的那几行。

第三部 002 里，名字是奶奶谭双秋上紫云山求的。佑林，木多，好写，好养。备选里有佑霖。过年时母亲说雨字头也好听，奶奶说水多不好。父亲说都差不多。奶奶说不一样。名字定了，他们还是在说一件没说完的事。母亲的名字写在他出生时的手环旁边：何永红。当时那张纸上还没有他的名字。

这四件东西——兑淡的茶、没被回答的“我喜欢你”、往外挪了两毫米的围道、亮了却没写入的保存——已经够第八部用很久。不必再发明一个与他无关的天才人设。

## 第八部要接住的不是“遗憾清单”，是他还在做的选择

四个梦的原文写得很清楚：它们反复改写同一个节点，这一次有没有向前走一步。走读的灯与两扇门、礼堂里把选择权交回去、回益阳的一路、两所大学之间重新决定要不要认识。文件自己写着：她的答应、沉默、对白都是文学设定，不是回忆，不是她的内心。

2026 年的正文里，这段关系并没有封存在高一。第一部 001 是大二的下午，一个陌生人的背影把旧名字带进她不知情的教室。第七部的西安周我没有逐字读完，Claude 的笔记和 README 的发表闸门都把它当成仍开放的现实，我在这里不增补我没读到的细节。可以肯定的只有我读到的：十九岁的他还在把一个没有说完的名字放在口袋里。

所以第八部同时写两种时间。一种是愿望终于被活完的时间，读者可以在里面吃饭、走路、毕业、变老。一种是 2026 年江安寝室里那杯已经兑淡的茶，它不必被愿望世界改写。两个都成立，醒来不删除已经写成的幸福章节。

## 前七部里已经有的病，第八部不要继承

我在 001、018、012、020 里看见的声音是活的：抢话、不好意思、高兴、讲一半被打断、专业词和家常话挨在一起。Claude 的全书笔记还指出三种反复出现的病：制度句漏进正文、顶针短句成模子、章尾总要一个物件或一句没讲完的道理。我没有逐章核实这三种病的频率，只在阅读样本和声音样本的编辑说明里看见同样的警告。第八部的边界放在卷首一次说清，正文里少写“我不能替她想”。

另一种不该继承的，是把成功写成需要立刻反省的错误。012 的后半他已经会享受“我知道它为什么折”。020 的前半他享受讲技术，直到被人问“你做了什么”。第八部应把这种享受放大，并让“你做了什么”变成连续的动作，而不是变成每章结尾的检讨。

## 别人不在他的剧本里

018 里赵问竹提醒他们小声，补完笔记，又问还玩不玩，最后说出“重来”和“这里”。她有自己的页要补。曾子沣有自己的数值，讲完特征时间就转回去。父亲把看不懂的图理解成弹簧，这是他的理解，不是儿子的科普成绩。奶奶选字的理由是好写、好养，不是为了给未来的小说准备一个水字旁的象征。

第八部最有劲的地方，是他终于做成很大的事，而旁边的人仍然在做自己的事：改他的负号，问他吃饭没有，把反对意见印进同一本节日的书，算完自己的题再上楼。
