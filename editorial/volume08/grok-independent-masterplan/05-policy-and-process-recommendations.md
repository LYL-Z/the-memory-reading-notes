# 制度优化建议（独立候选）

## 问题与处理
| 原有问题 | 建议处理 |
|----------|----------|
| 每章必须先写三个开篇 | 改为可选，顺畅时直接写 |
| 形式化冒险强制要求 | 取消强制性 |
| 固定字数/章数限制 | 明确废除作为第八部约束 |
| 必须每条世界联动 | 改为可以独立存在 |
| 过度依赖克制表达 | 允许直接、热烈、细腻的情感 |
| 成功后生活被压缩 | 鼓励完整书写胜利与幸福 |

## 新建议
- 制度服务于故事，而不是相反。
- 历史记录中的“克制”可作为可选技法，但非唯一尺度。
- 多模型协作时，先独立发挥，再比较融合，避免过早共识。
- 成熟题材遵守平台规则，但不设计规避流程。

本建议仅保存在独立分支，不覆盖 main。
