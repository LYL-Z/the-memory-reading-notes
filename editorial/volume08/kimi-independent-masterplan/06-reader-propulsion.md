# 读者推进力：爽文机制、名著容量与去AI味

## 一、爽感不是低级，是承诺被看见地兑现

爽点可以定义为：

**人物长期投入的欲望，经过具体障碍，以读者能感知的方式得到可见进展，并在兑现后产生新的生活。**

因此“他建立帝国”不是完整爽点。完整爽点是：他多年前坚持的一项公共设计，在灾难中救下一座城；曾经反对的人主动承认；庆典之后他回到自己的家，发现伴侣还给他留着饭。

## 二、五类进度条

### 1. 能力进度

会算题 → 会查错 → 会建模 → 会实验 → 会复现 → 会组织团队 → 会开放知识。

### 2. 世界进度

个人终端 → 小组实验室 → 校内平台 → 全球网络 → 多世界公共基础设施。

### 3. 地位与财富进度

被忽略 → 被质疑 → 被承认 → 有议价权 → 能制定规则 → 可以不再依赖地位证明自己。

### 4. 关系进度

注意到彼此 → 明确吸引 → 双向选择 → 协商共同生活 → 经历外部变化仍继续选择 → 保有新鲜感的长期亲密。

### 5. 文明进度

一项小改进 → 一个地区的生活变化 → 多地区采用 → 制度形成 → 后代重新修订。

每一阶段都要有场景兑现。只在旁白宣布“他更强了”不会产生满足。

## 三、信息差：不只用于打脸

- **读者知道未来成功，人物不知道**：读过程时获得“看他怎样赢”的期待。
- **人物知道一项技术，社会不知道**：形成发布、验证和利益冲突。
- **反方知道主人公一个真实缺点**：冲突不再靠降智。
- **两个人都知道彼此相爱，却不知道怎样共同生活**：形成成熟言情。
- **读者知道另一个世界同样真实**：当角色把它当工具时，读者会提前感到伦理压力。

打脸可以用，但最有满足感的不是对方跪下，而是对方不得不用事实修正自己，并在此后成为真正有分量的合作者。

## 四、期待的滚动兑现

每三五个小节至少完成一次小闭环：修好一个错误、完成一次面试、通过一次测试、说清一件事、赢得一个伙伴、解决一个生活问题。

每一大章要完成一个不可逆的变化：理论公开、合作建立、地区加入、关系公开、家庭搬迁、公共制度生效。不能连续几十章只准备。

高潮之后必须有 **兑现窗口**：

- 科学成功后写复现、荣誉、财富、团队和休息；
- 建国成功后写城市、皇宫、婚礼、公共庆典和私人生活；
- 告白成功后写约会、亲密、共同安排和朋友圈反应；
- 救世成功后写重建、饭馆、学校、演出和假期。

兑现窗口不是水字数，而是读者获得满足的地方。

## 五、网络类型机制转化为本书语言

### 序列升级

借“明确阶段、每阶段新能力与新责任”，不照搬九级职业名称。MWC 的阶段由可验证传输对象定义：校验比特、未知比特、量子态、简单结构、活体材料、人。

### 信息与知识优势

借“读者理解主人公为何领先”，不让人物靠背现代百科在古代全知。真正的优势是学习方法、组织实验和承认局部无知。

### 家族多代

借“长期变化与积累满足”，不默认后代必然败家。后代可以更强、更普通、更自由，也可以重新定义家族荣光。

### 反套路经营

借“规则一翻转就产生新机会”，但不能只讽刺旧类型。免费公司真正免费以后怎样赚钱，白日帝国允许退出以后怎样维持吸引力，都要写具体。

### 年度榜单与读者评价

榜单只能证明某个机构、某一年度和某种口径下的选择，不能冒充全民阅读数据。我们吸收机制，不宣称某作品绝对第一，也不编造销量。

## 六、去模板化写作：从句子和场景下手

### 1. 减少万能过渡句

“他不知道的是”“命运的齿轮”“真正的故事才刚刚开始”“此刻他还不知道”不得成为每章默认开门。未来信息应通过具体场景给出。

### 2. 消灭同构段

如果连续三段都是“动作一句＋短句停顿＋哲理一句”，就重写其中两段。对话也不必每个人都先停顿、再抬眼、再轻声。

### 3. 让人物拥有不同的语言经济

- 林见夏谈空间、时间和实际安排，拒绝玄虚安慰；
- 唐见微用条件和反例说话，成功后也不突然煽情；
- 谢南乔可以把亲密说得像一份准确契约，但偶尔故意不严谨；
- 周原关心谁值班、谁拿钱、谁背锅；
- 刘佑林可以复杂，但不必每次都把简单需求说成宇宙问题。

### 4. 感官细节来自场景

实验楼可以有设备声、咖啡、门禁、外卖、错误日志；皇宫可以有食物、织物、园艺、音乐和家庭动线。不要为了“文学感”给每个场景分配雨、冷光和指尖发白。

### 5. 允许幽默和低俗日常

伟大人物也会点错外卖、忘记纪念日、在正式场合想上厕所、因为伴侣一句话暗喜。幽默不等于网络烂梗，日常不等于降低格局。

## 七、轻量场景合同

正式写作前每个场景只写五行：

1. **此刻谁最想得到什么？**
2. **什么具体条件阻止他？**
3. **场景结束时，什么事实或关系不可逆地变了？**
4. **读者获得哪一种满足：发现、升级、亲密、财富、权力、复仇、创造、安心或新奇？**
5. **哪一个细节只能属于这个人、这个地方？**

如果场景没有变化，可以保留为纯粹生活与兑现，但必须明确“这一场就是让读者享受已经得到的东西”。

## 八、章节长度随功能变化

- 科学论证可短而密，避免公式连续压过行动；
- 建设与经营可长，给细节、人物和阶段成果；
- 爱情高潮不必在最热烈处强行切走，也不必机械淡出；
- 皇室日常与庆典可以独立成章，不必每次插入危机；
- 多代家族可用短章群，某些关键日子用长章停留。

不设“每章必须三千字”“每八章必须科研闭环”之类统一尺寸。

## 九、七元素的现场检查

修改一批正文时，只问：

- 有没有一个真正新而非换皮的创意？
- 前面的细节是否在后面变成巧妙答案？
- 人物得到的东西是否被读者看见、摸到、享受？
- 欲望是否具体，而不是抽象口号？
- 他人是否有独立判断？
- 情感是否让人物采取了实际行动？
- 宏大制度是否改变了普通人的一天？

其中任何一项长期缺席，才进入针对性修订；不为了形式每章同时打满七项。
