# 模型官方边界与本轮执行说明

## 官方资料能支持什么

本轮核对了 Anthropic、OpenAI 与 xAI 的官方模型文档、使用政策或帮助页面。官方资料支持：模型与工具各有适用场景、长上下文与推理能力需要结合具体产品、所有平台都有内容与使用边界。官方资料不支持“把某类内容交给另一模型即可合法绕过”的流程设计。

- Anthropic 官方模型页用于了解 Claude 系列定位；使用政策对未成年人性内容、非自愿私密内容等设有明确禁止。
- OpenAI 官方模型文档用于了解 GPT 系列与推理、写作、研究等能力；Usage Policies 与 Model Spec 说明执行边界需要结合具体场景。
- xAI 官方模型页与使用政策用于了解 Grok 系列与内容边界。其文档中的 `nsfw` 审核信号属于内容识别与拦截配置，**不是露骨内容生成许可证**。

官方链接与访问日期见 `10-sources-mla.md`。

## 本轮怎样执行

1. 不生成露骨性描写，不为可识别真实人物虚构私密性史，不把未成年人性化。
2. 原创成年人物可以承担热烈、直接、细腻的吸引、亲密、婚姻与家庭生活；采用非露骨文学表达。
3. 不设计“Claude 起草—Grok 越界描写—其他模型洗稿”一类跨模型规避流程。
4. 现代帝国、权力与社会制度仅作架空政治史和文学思想实验。
5. 长上下文、推理或所谓“创作自由”都不覆盖真实人物权益、未成年人保护和平台规则。

## 对作者制度的建议

不必在制度里反复猜测哪家平台“更敢写”。应把成熟题材拆成可执行的文学目标：明确欲望、双向选择、身体与情感的非露骨描写、共同生活、关系协商与长期亲密。这样既提高作品温度，也避免把创作流程建立在规避限制上。
