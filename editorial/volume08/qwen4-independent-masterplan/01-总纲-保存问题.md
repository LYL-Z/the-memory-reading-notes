# 第八部独立总纲：保存问题

> Qwen4（Qwen4-Max）独立构想 · 2026-11-24 · 设计实验，非正式正文
> 基线 main @ 3f79d2a。本文件提出一套与 GPT-6.2（RCD 协议）和 Claude PR #93（无机制·克制）都不同的第八部引擎。八套架构的题材方向全部保留，但实现形式可以完全不同。

## 一、我的核心判断：第八部应当是一部「得到」之书

前七部教会这个叙事者一件事：**不要问，不要拿，不要说完。** 历史课上他说了「我喜欢你」，然后用四个人的笑把它收回去；二班门口他送出了礼物，然后把那句保证留在原地，不追问；西安他裁掉了陌生人的肩膀，却把原图也留着，不敢让任何一个版本成为定论；全书最后一章，他连方向都「还没想定」，把闹钟从七点半改到七点。这是一部关于**收回**的书，写得极准确，也极动人。

但作者在 2026-11-24 的指令里说得明白：不要把所有幻想都写成失败、告别、遗憾、自我反省；要爽，要代入，要圆满，要帝国，要欲望，要「越爽越好」。这不是要推翻前七部，而是要给前七部一个**反向的配重**。前七部是「收回」，第八部应当是「伸出」——并且把「伸出」写得和前七部的「收回」一样准确、一样有代价、一样经得起检验。

所以我的总命题是：

> **第八部写一个学会了不问的人，终于被允许问、被允许拿、被允许说完、被允许赢、被允许爱、被允许统治、被允许拯救——然后发现，得到之后最难的事，是诚实地想要，并且把得到的东西保持为人。**

爽感不来自碾压，来自**一个具体的人凭自己的本事，把一件他真正想要的事做成了**。代价不来自天谴，来自**做成这件事本身要付出的、可计算的、他愿意付的成本**。哲思不来自章末说教，来自**他得到之后才发现的那个新问题**。

## 二、对现有两套设计的独立诊断

### GPT-6.2（open-epic + integration-v2）：结构正确，重心偏「管理」

V2 的物理分层、政策审计、真实人物保护、制度松绑都对，我全部继承。但它的重心是**治理一部大书**：五层台账、四道闸门、八架构×五模块、每章七项自检。风险是第八部变成一部**管理良好的选集**——每个世界都合格，合起来却没有一个让人放不下书的**欲望脊柱**。作者要的七个词（创意、巧妙、爽文、欲望、人性、情感、社会）里，「欲望」是发动机，V2 把它分散到了四十个模块里，没有一根贯穿的轴。

RCD（关系因果域）是一套**地址与协议**理论：世界怎么寻址、怎么握手、怎么守恒。它优雅，但它是**关于世界如何连接**的理论，不是**关于一个人如何想要**的理论。读者不会为协议心跳。

### Claude PR #93：文学上更强，重心偏「放下」

PR93 的七场试写是我读过的本项目里最好的散文之一（《礼堂》里那句「我没有把书翻回去」值得全卷学习）。但它自己的复审也承认：七场都「小、低温、一个动作」。它的每一个世界都以「不说」「留白」「没有送」收束。这恰好是作者明确说**不要再来一遍**的东西。PR93 还明确拒绝了科幻机制（「一旦解释世界怎样连接，读者就会去检验解释」）。这个担忧是对的，但结论错了：**读者检验解释，恰恰是硬科幻爽感的来源**——只要解释足够硬、足够自洽、足够有代价，检验本身就是追读动力（《诡秘之主》的序列体系、《信条》的熵减规则都是被读者反复检验而更上瘾的）。

### 我的位置

我不需要证明 GPT 正确，也不需要为了独立而反对 Claude。我取 GPT 的**硬科幻雄心与制度松绑**，取 Claude 的**散文精度与真实人物保护**，然后换一台发动机：**把「世界如何连接」的问题，改写成「一个人如何保存他想要的东西」的问题。** 前者是协议，后者是欲望。协议让人点头，欲望让人翻页。

## 三、发动机：保存问题（The Save Problem）

全书最后一章《不是公司的员工》里，他做了一个整理实验数据的小工具，名字取自一个物理词。第一版能存住三条记录；他把它拆漂亮了，保存按钮却断了——「已保存」的提示是真的，写入动作没接上。他修好了本机保存，四个字的一条记录，刷新还在。全书停在这里：闹钟七点，方向未定，**保存功能刚刚恢复**。

这是全书留给第八部的、已经写好的引信。第八部不需要凭空降下一个系统，它只需要问：

> **如果「保存」不只是把四个字留在浏览器里，而是把一段人生留在世界里呢？如果有一次，他存下的四个字，第二天变成了另外四个字——是他自己的笔迹，却不是他打的那四个字呢？**

第八部开篇就是这个 **diff**。不是传送门，不是老爷爷，不是系统面板。是一个版本差异。一个用 GitHub 管知识库、天天 commit 的物理系学生，发现现实给他弹出了一个 merge conflict。

由此长出的核心机制（详见 02 科学公设）：**世界不是预先存在的块，世界是一组相互一致的记录；穿越不是移动，是写入；写入的代价是擦除，擦除服从兰道尔原理。** 他的「金手指」不是力量，是**版本控制**：读 diff、提交、分支、合并、回滚——以及最后那个恐怖的问题：**谁有对他的写权限？**

## 四、七个核心元素如何落地

| 元素 | 在本引擎里的具体含义 |
|---|---|
| 创意 | 版本控制作为时空机制；帝国作为开源治理；救世作为备份；爱情作为合并 |
| 巧妙 | 每个世界的规则都是同一套记录物理的不同操作，读者学会一次就能预判下一次，预判被满足是爽，被反转是更爽 |
| 爽文 | 能力阶梯（读→写→分支→合并→冲突→强推→维护者），每一级都有具体的、凭本事做成的高光 |
| 欲望 | 正面清单：他想要财富、地位、爱情、权力、认可、家庭、文明，并且**被允许得到**，不强制反讽 |
| 人性 | 得到之后的人：权力如何改变一个本来善良的人；爱如何既是合并又是冲突；备份谁、放弃谁 |
| 情感 | 前七部的所有遗憾，在第八部里被**正面回答一次**（在明确标记的虚构/梦境层），不篡改事实 |
| 社会 | 帝国、阶层、分配、科技治理作为思想实验，允许成功，保留对立观点与开放问题 |

## 五、脊柱与世界的关系

第八部有一根**连续的脊柱**（保存问题→维护者），和若干**可以独立成篇的世界弧**（八架构）。脊柱保证追读，世界弧保证广度。世界之间**不强行统一**：有的世界他只是读者（读 diff），有的他是作者（提交），有的他是维护者（统治），有的他发现自己只是别人仓库里的一条记录。联动是**奖励**，不是义务——当两个世界恰好对同一个人提出主权要求时，merge conflict 自然发生，那就是高潮，不需要硬连。

## 六、卷名候选

1. **《保存》**——最朴素，最贴全书末章，最像这个叙事者会取的名字（他给工具取名「数据收纳_半成品」）。推荐。
2. **《写权限》**——更硬，更悬，点出最终问题。
3. **《有人替你记着》**——取自第一部「那些在我坐下以前的晚上，总得由别人替我记着」，点出维护者反转的情感内核。
4. **《复数人称》**——回扣总书名，但第八部其实是「单数人称如何被复数地保存」，可作副题。

我推荐主名 **《保存》**，副题「时间的复数人称·第八部」。它和第七部末章那个没做完的保存按钮，构成全书最安静也最响亮的回声。

## 七、边界（继承并遵守）

- 真实人物（赵问竹、董佳好等）：不虚构私密性史，不色情化；正面情感回应只发生在明确标记的虚构/梦境/平行层，且以 2026-09-16 用户直接确认层为上限，不冒充本人原话。
- 未成年人：年龄适当，绝不性化。
- 现代帝国：架空政治史与文学思想实验，不是现实夺权、镇压、操纵方案；不映射现实国家与领导人。
- 成熟亲密：热烈、细腻、有艺术感、**非露骨**；不设计跨模型规避限制的流程（详见 06）。
