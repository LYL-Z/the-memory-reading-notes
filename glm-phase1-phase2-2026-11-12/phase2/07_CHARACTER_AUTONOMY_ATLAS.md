# GLM 位第 2 阶段｜人物自主行动与证据边界图

# r2｜05 人物证据图

> 本图只登记**r2 从 42 章正文读到的**人物行动与信息边界，不把作品推断写成对现实人物的心理诊断，不根据外貌识别个人，不建立真人外貌／神态档案。证据等级沿用 `02_canon_and_authority_matrix.md` §三；本轮**未逐字重读事实库人物页**，所有「待核」一律指向 `PENDING_FACT_CHECK`，不冒充已核。

## 一、方法：三条登记规则

1. **只写行动，不写人格判词**。人物的「性格」在本图里一律还原为可回查的动作／句式／在场方式。
2. **区分四层信息**：`当时知道` / `回望才知道` / `他人告知` / `始终不知道`。凡第三人未确认的内心、原话、关系名称，一律留在「始终不知道」。
3. **区分作品人物与现实人物材料**。交付物中出现的姓名均为现行正文已公开出现的写法；涉及现实人物的隐私、问卷、聊天、照片原件，不进入本图。

## 八、声口规律：「有文本证据的人物才有直接引语」

r2 从 42 章读到的最稳定的分配原则：

- **有原文／问卷／评语／聊天记录支撑者**才有直接引语：父亲的短句、向睿馨「向睿馨！！！」、夏恺宪「二弟生日快乐」、郑森评语、刘弈帆「包记得的」、宋俊豪的批评、符雄辉／李文静／王代良的评语、董佳好的反向快照。
- **几乎只有转述与动作者**：赵问竹（V1 全卷仅少量短句，且多为指令式）、王麒皓、王培森、曹卓雅、戴教练、李霞、奶奶。
- **好处**：不伪造他人原话，符合 L1／L2 的证据纪律。
- **代价**：大多数人物不说话，叙述者一个人把话讲完。006《轮到谁说话》题名即说话权，全章却没有一句对白——这个反讽可能是无意的，也可能是全卷最锋利的自我暴露。**该项登记为编辑判断，须真人冷读才可下读者效果结论。**
