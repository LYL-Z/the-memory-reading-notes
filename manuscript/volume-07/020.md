# 不是公司的员工

电脑上有三个窗口。

一个是物理课要看的材料，一个是昨晚没有调通的程序，还有一个停在我正在阅读的技术文章。它们都没有关闭的意思。我把鼠标从左移到右，又移回来，最后先点开了文章。

那天我原本打算复习。

我知道只要看完眼前这两页，后面的推导就能接着往下做。可技术新闻里出现了一个新模型，我很想知道它究竟怎样实现，和之前那一代相比有什么区别。页面上有几项指标，我看懂一半，剩下一半要继续查。查着查着又找到别人的项目演示，界面做得漂亮，我打开视频看了一段。

过了很久，我发现自己还停在那两页课本上。

这种事不是第一次发生。

我喜欢华为，也关注芯片、操作系统和AI的发展。这个喜欢是从高中开始的，起初只是因为手机好用，后来慢慢变成看它的发布会，看它怎么在被限制的条件下做自己的东西。

跟同学讨论时，我一兴奋就容易把话题讲到企业路线、供应链和算力，仿佛那些事与我天天有关。别人若也感兴趣，我们可以谈很久；若不感兴趣，我仍然会想多解释两句，好让他知道这个技术变化为什么值得注意。

这份热情是真的。

可我并不在那些公司的研发团队里，也不能因为我认真使用过某个产品，就把工程师的工作说成自己的经历。我有时候介绍技术时很像在介绍一项亲手完成的成绩，讲完以后才想起来，自己负责的课程和项目还放在桌面上，等着我去做。

有一次在食堂，我跟一个同学讲这些。

我讲了大概十分钟：算力怎么堆，供应链怎么绕，一个公司怎么在被卡住的地方自己啃下来。讲的时候我很兴奋，筷子一直没动。

他听完，问了一句：“那你做了什么。”

我愣了一下。

“什么。”

“你讲了这么多他们做了什么。”他说，“你做了什么。”

我说我在做一个小工具。

“做完了吗。”

“快好了。”

“那挺好。”

他没有再问。我低头吃饭，饭有点凉。

我当时的第一反应是想把已经做过的项目一个个报出来，最好连 GitHub 地址也附上。哪怕那些项目还停在初版，仓库上总归有提交，有页面，有截图。我很清楚自己不是在那家企业工作的人，可被同学这么问了一句，我还是有点难堪。

我挑了一样最接近“做成”的东西给他讲。他低头把饭拌匀，问了一下要不要服务器，我便把后面那段自己准备好的技术路线也讲了。他听了一阵，点点头，说吃完得赶下一节课。

我还有一句没说完，只好和着饭咽下去。凉掉的油浮在汤面上，我去窗口要了一点热水，回来时发现他已经把盘子端走了。

那天我回去就想把项目弄得更像样。打开那个漂亮界面，输入框还在，菜单也齐，光标刚放上去我便想起自己答应过的保存功能，原来仍只有一个没有接好的按钮。

我曾为未来写过好几份计划。

物理研究、AI应用、软件开发，甚至创业。每条路线看起来都有吸引我的地方。我给项目取名，画界面，设计功能，有时把说明写得特别响亮，发给朋友看，期待他们一眼就明白我想做的东西多有意思。

那些项目里，有一个我做得最久。

起因很简单：我做实验的时候，数据总是散在好几个地方。手机拍的照片、电脑上的表格、纸上的记录、聊天记录里发给自己的数字。找一次要翻半天。

我想做一个东西，把这些东西收到一处。表格式的界面，左边一栏是项目，右边是内容，可以打标签，可以搜索。

我给它取了个名字。名字取得很讲究，取自一个物理里的词，听起来像是有点来头。

第一版做出来的时候我很兴奋。

能新建条目，能输入文字，能保存。我在里面录了三条记录，关掉，重新打开，三条都在。

那一版简单得可笑：输入框和保存按钮挨在一起，按下去便把数据写进浏览器本地存储。要管理的东西也只有我自己电脑上的几条测试记录。我没有想过换一台机器还在不在，只知道同一台电脑关掉再开，字确实没丢。

那天晚上我截了图发给朋友，说“我做了个东西”。

他回：“不错。”

我等了一会儿，没有下文。我又发了一句“可以管理实验数据”，他回了个“哦”。

我把手机放下，回去继续改。改到一半，把截图缩小看了一遍，发现先前挺满意的一个布局现在看着很别扭。

那几天我一直在改界面。

改字体，改间距，改按钮的圆角。改到一个地方，我觉得左边的列表太宽，就往右挪了一点；挪完发现右边的内容区不够了，又把整体缩了一点。

后来我干脆把页面拆成几个组件。原来的保存按钮不够好看，我另做了一个，把提示和图标一起包进去。为调试列表，我预先放了两条样例记录，每次打开都会显示。我看着它们在页面里排得规整，忘记拿新写的一条做真正的关机重开测试。

样例总在那里。我每次重新打开都能看见它们，心里便把“页面能显示内容”和“刚才输入的内容真的留住了”混成了一件事。

真正的问题是在一个星期以后发现的。

那天我又录了五条记录，关掉程序去吃饭。回来重新打开，只剩先前预置的那两条样例。

我以为自己记错了，又录了两条。关掉，打开。还是没有。

我把问题重现了三次。

第一次，我以为是程序没关好。第二次，我以为是自己点错了保存。第三次，我盯着屏幕，看着那行“已保存”的提示跳出来，然后关掉程序，重新打开，内容不在了。

我坐在那里，看着空掉的那一栏。

提示是真的。它确实跳出来了。可它只是跳出来，什么也没有做。

我想立刻去问模型怎么修。手指已经放到键盘上，又停住。

我先拿了一张纸，把操作顺序写下来：打开页面，新建，输入，点保存，关掉，重新打开。写完，按这个顺序又做了一遍。

错误每次都出现。

我低头查了一会儿，才发现新按钮把“保存成功”这几个字显示得很顺，写入数据的动作却没有真正接上。最早那版能在本地存住三条；我把它拆开重写，竟然把最要紧的连接弄断了。

那两条样例还在。它们固定得像一对证人，替我作证的却完全是另一回事：页面每次都会把它们放出来，无论刚才有没有成功保存新数据。

而我曾经把这样的截图发给别人，告诉他们功能已经实现。

现在再看，那张截图很像一张我为自己拍的成绩单：最漂亮的一部分在画面里，没拍到的地方暂时没人追问。

那天晚上我把那行提示删了。

删完以后，按钮按下去没有任何夸张的反馈。页面甚至显得简陋了些。

我坐在那里看了很久那个按钮。原本想把它做成会在完成时轻轻亮一下的样子，亮得漂亮一点，截图也好看。如今光剩下一个没有反应的边框。我把手放在鼠标上，还想先改改它的边角，终于把鼠标移走，去读那段实际写入数据的代码。

真正要把它交给别人用，时间全花在看不见的地方：数据到底存在哪儿，断电以后会怎样，输入错误时该怎样提示。调一套颜色和间距，只要我自己觉得漂亮就能收工；这些问题却不会因为我不想碰便自动解决。

我那天晚上没有修好它。我只做了一件事：把项目文件夹里的名字改了。

原来那个名字很好听。我改成了“数据收纳_半成品”。

改完以后，我在文档的第一行写了一句：目前不可用，保存功能未完成。

这句话我写得很慢。

第二天有人问我那个东西能不能用。

是班上的一个同学。他说在群里看到我发过截图，问能不能给他也装一个。

我打了一句“可以”，看着它，删掉。

“现在还不能用。”我重新打。

“什么时候能用。”

“不知道。”

“那你做好了叫我。”

“好。”

这段对话很短。发完以后我坐在椅子上，心里空了一下，又松了一下。

空的是因为我承认了它不能用。松的是因为我不用再想怎么解释。

我以前遇到这种问题，会先说“基本能用”，然后补一句“还有一些小问题”，再补一句“等我修一下就好”。这三句话说完，对方会觉得东西快好了，我会觉得自己没有失败。

可它没有变好。它只是被三句话盖住了。

那天晚上父亲发了一条消息，问我最近在做什么。

我把改了名字的那个项目截了图，发给他。

“这是什么。”

“一个整理数据的东西。”

“做完了吗。”

我看着这四个字，停了很久。

“没有。”我回。

“哪一步没做完。”

“保存。存了以后关掉就没了。”

“那不就是最要紧的。”

“是。”

他没有再说别的。

过了一会儿他发：“先把最要紧的做完。”

这句话听起来像废话。可我当时确实没有先做最要紧的。我先做了界面，做了名字，做了截图，做了介绍，最后才碰到保存。

因为保存做出来没有成就感。它不会让任何人“哇”一声。它只是一个开关，按下去，数据还在，就这么简单。可没有它，前面所有漂亮的东西都是空的。

那晚我把三个窗口全关到只剩一个。

屏幕上是最简单的一页，按钮旁边空着一个位置。本来应该能保存的信息，在刷新以后就不见了。

我又按了一次。

没有任何提示跳出来。那行字已经被我删了。光标在输入框里闪着，和最早的第一版差不多，只是现在我知道，下一步还得有一段能把数据真正留下来的程序。

我把写入函数单独放到一边，准备第二天先用最简单的一条记录试。它能不能成功，我那晚还不知道。

第二天中午，我把第一版从旧文件夹里翻出来。最先做的不是改外观，而是把那三条当年确实能留住的测试记录重新录一遍。新版照旧弹出“已保存”，一刷新，全没了。旁边两个样例仍好端端地占着位置。我关掉它，又打开第一版；三条都在。

我给之前问什么时候能用的同学补发了一句：“先别装。我上次发的只是界面。”消息发出去以后，我把手机扣在桌上，没有再等一句“那挺好”。我原本预备了一整段解释：重新拆了组件，按钮跟数据没有接上，样例又误导了我。那段话最后只留在自己的草稿里。

下午我把写入动作重新接回去，用一条只有四个字的记录反复试。刷新，关标签页，整个浏览器退出，再打开——这次都还在。我在测试记录后面打了一个勾，又停住。它只能说明这台机器暂时留得住四个字，不能说明别人拿去就能管理实验数据。

我在首页那行“目前不可用”下面补了第二行：“本机保存已恢复；导出、跨设备和错误提示未完成。”之前我会急着把前半句单独发出去。这次我把后半句也留在那儿。

寝室里很安静。曾子沣在右边，他的屏幕上是一段代码，我看不清是什么。他有时候会在半夜突然开始算一个东西，算到一两点。我们两个人各占一边，中间一条过道，谁也不打扰谁。

我躺在床上，想到一年前刚来的时候。

那时候我想把自己的电脑放在最顺手的位置，父母整理箱子，我急着摆好设备，仿佛桌面一旦属于我，接下来的学习和项目就会照着安排往前走。

过了一年，桌子确实归我使用，也被我堆过一阵阵没收好的东西。茶杯在一边，课程资料在另一边，项目文件夹里有好几个名字写着“最终版”的版本。

我有能力决定今晚做什么，也有能力把整晚用在一项并不重要的调整上，第二天再因为课业来不及而着急。

这份自由不够浪漫。

我躺了没多久便又爬下来，把白天那张截图找出来。旧图片缩成聊天框里的一小块，边角圆得很舒服，两个预置样例排得齐整。要不是我自己知道，几乎可以拿去当一个已完成的小作品介绍。

我把鼠标移到它上面，想删。朋友对它回过一句“不错”，除此之外没别人提起。留着好像也没什么用。可删掉又显得我正在跟那时的自己赌气。

我最后没删截图，只把它从“成果”文件夹拖进“过程”。拖完发现“成果”里面本来也没几个文件。有一份是我高兴时导出的演示视频，进度条跑得特别平稳；还有一份是某次生成的设计图，样子比真正运行的程序好看得多。我关上文件夹，突然有点饿，下楼买了个面包。

有一段时间我特别喜欢看招聘页面。

不是为了投简历，就是想看。看那些岗位写什么要求：熟悉什么框架，做过什么项目，有几年代码经验。看完以后我会在心里对照一下自己：这个不会，这个见过，这个我做过一点。

对照的结果通常是：差得远。

差得远这件事我没有跟任何人讲过。讲出来像是在自我贬低，而且我也知道，一个大二学生跟一个有五年经验的工程师比，本来就没有可比性。

可我还是会看。看了以后有一种奇怪的感觉：我被排除在一个房间外面，而那个房间里有我很想要的东西。

有一个招聘网页我反复看过。岗位要求里写着维护线上服务、排查故障、和其他人协作。我其实看不太懂其中几条，鼠标停在“故障”两个字上很久，又把页面往下滚。

我没有要去应聘。一个大二学生连自己的小工具都没交付，去看那种要求，更多是想提前尝尝自己有一天可能变成什么人的味道。看到最后，我忍不住开了一个空白文档，把自己会用的技术一个个列出来。列到第五行，前面好几项都只能写“接触过”。

那天夜里我终于去找先前答应给同学的那个东西。聊天记录里还有他最初说的“那你做好了叫我”，下面是我后来补的“先别装”。我想发新截图，又想起自己只有本机保存做过最简单的测试，别人真正需要的导出和跨设备使用都没完成。

我又写了一条最短的记录，只有四个字。按保存，刷新，记录还在。我把整个浏览器退出，重新打开，还是在。屏幕上那四个字并没有因为我高兴就变得能导出、能检索，甚至还不能和另一台机器上的记录放在一起。右边传来椅子滚轮的一声响。曾子沣拿着水杯从我身后走过去，问我还不睡。我说快了，自己也不知道还要弄到几点。

我把此前失败的步骤与今天通过的步骤放进同一份小文档，附上两组截图：旧版刷新以后是空白，新版重开以后还能看见记录。文档很丑，连标题都懒得美化，只写“复现”。几分钟以后，我又想把它改成一个看起来像项目报告的东西，打开字体菜单，挑了半天，终于没改。

同学当然不知道我做了这一番折腾。他等的只是一个能用的工具。那条“做好了叫我”一直留在聊天记录末尾；我点开看过几次，也没有说自己快好了。

大二开学以后，课表上多了一门人工智能基础。

周一晚上，三节课连上。教室在综合楼，坐满了人。老师讲的东西有一半我听过，一半没有。听过的那些我听得很快，没听过的那些我抄得很慢。

有一节课讲到一个模型的训练过程。老师放了一张图，横轴是时间，纵轴是误差。曲线往下掉，掉到某个位置开始平。

他问：“为什么平了。”

没有人回答。

我心里有一个答案：因为容量到顶了。可我没有说。我不确定自己的答案对不对，也不确定该用哪个词。

后来他讲了原因。跟我想到的差不多，但他用了另外两个词。

我坐在那里，有点后悔，又有点安心。

后悔是因为我本来可以答。安心是因为我至少想到了。

开学后我给自己定了一个很小的目标：每门课至少问一个问题。

到现在还没完成。有的课我问过了；另一些课到这一天为止一次也没举过手。后面还有课，我当然可以继续问，但当初制定计划时那股笃定的劲已经过去了。

后来还有人问我是不是决定往人工智能方向走。我那天正从教室出来，嘴里便顺着讲了好几种可能，讲到云端服务、物理计算，又讲到未来自己或许会做什么。

说着说着我突然想起桌上那张写着“复现”的纸，四个字的数据还没能存住。我很想把这个失败也讲进去，却又嫌这件事太小，讲了像故意谦虚。

“还没想定。”我最后说。

对方说他也一样，刚好有人叫他，便走了。

我站在楼梯口把手机摸出来，今天的待办还有一道光学题。我向右滑了两页才找到那道题，当时用荧光笔画过的一个条件还在。我按住手机上的通知，先把实验数据那边的提醒推到明天，然后上楼。

我重新打开课本，把刚才准备复习的那两页翻过去。

屏幕上的待办还在：补导出和错误提示，给不同设备的记录安排去处，把那两条预置样例与真正保存的数据彻底分开。

明天可以继续。

明天也有课。

我把台灯关了，躺下。右边的屏幕还亮着，过了一会儿也灭了。

黑暗里我伸手摸到手机，把闹钟改到七点。改完想再改回七点半，最后没有改。

屏幕的光在脸上停了一下，然后灭了。
